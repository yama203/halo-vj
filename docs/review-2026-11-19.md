# 点検と提案（2026-11-19、v0.6.4 の時点）

コードを読んだだけの点検。動かして確かめたものは無い。「確」は、点検のあともう一度コードを読んで同じ結論になったもの。

## A. 不具合（重い順）

### 本番で事故になるもの

1. **確** 壊れた OSC 1 つで落ちる — `OSC.swift:380` の `n()`。`/halo/layer/-9223372036854775808/clip/1` のような番号で `Int.min - 1` があふれて止まる。OSC の受信がオンのとき、同じネットワークの誰でも送れる。→ 1 以上のときだけ番号にする。
2. **確** 段・列・デッキの数が変わる操作を ⌘Z すると全部止まる — `Undo.swift:110-128` → `Engine.swift:2047` の `stopAll()`。出力が黒になり、素材も読み直す。→ 再生中のクリップを引き継ぐ。

### たまに困るもの

3. **確** 往復のクリップを消すたびに、デコードのスレッドとコマが残る — `ClipSlot.swift:737` の deinit が `reverseStandby` と、ジャンプ待ちのストリームを cancel しない。1 回で 1080p なら約 66MB。→ deinit に足す。
4. **確** プリセットが全部消えることがある — `EffectPresets.swift:48-51, 72`。1 件でも読めないと全体が空になり、次の保存で上書きする。`swift run` は開発用の実行に入らないので、新しい種類を本物のファイルに書ける。→ 1 件ずつ読み、読めない分は残す。
5. **確** 音声が読めないだけで、映像も使えない — `ClipSlot.swift:763` の `try await AudioCache.file`。→ 音の失敗は音なしで続ける。
6. **確** 同じ動画が 2 つの枠にあると、初回に片方が読めない — `AudioOutput.swift:321-344`。同じ `key.tmp.caf` を取り合う。→ tmp の名前を別々にするか、作るのを 1 回にまとめる。
7. 新しい種類のジェネレーターが 1 つあるだけで、古い版でプロジェクト全体が読めない — `Engine.swift:1804, 1847`（1 つだけの `Effect?` は救われない）。
8. 自動操縦の間隔が短いと、人の変更が Undo の 1 歩にならない — `Autopilot.swift:308`、`Undo.swift:80`。⌘Z で自動操縦の前まで一気に戻る。
9. フェードのタイマーが、⌘Z やプロジェクトを開いたあとも値を書き続ける — `Undo.swift:144`、`Cues.swift:137, 158`。
10. シーンのフェード中にクリップのキューを出すと、不透明度が半端なまま残る — `Cues.swift:76-95, 133`。
11. 往復用の逆再生の音を作る間、全クリップの音が遅れる — `AudioOutput.swift:127, 146-192`（共通の直列キュー）。
12. オーディオインターフェースを抜き差しすると、Mac のスピーカーから鳴ったまま — `AudioOutput.swift:29-33, 97-116`。
13. カメラやキャプチャを抜くと、最後の絵のまま戻らない — `Camera.swift:92-120`。
14. ほかのディスプレイを抜き差ししても、出力ウィンドウが作り直されて一瞬切れる — `Output.swift:112-135`。
15. 読み込み中のクリップを押すと、そのレイヤーが黒のまま始まらない — `Engine.swift:832-848`、`ClipSlot.swift:842`。

### 小さいもの

16. **確** 壊れた保存ファイルの四隅で落ちる — `Engine.swift:2091`、`Undo.swift:161`（中の配列の数を見ていない）。state.json だと起動のたびに落ちる。
17. Art-Net の start/end の範囲を見ずに `Int` へ直す — `ArtNet.swift:69`。
18. 開発用の `--panel-preview` が `Engine.shared` を使い、利用者の state.json を読み書きしうる — `App.swift:57-71`。
19. 音のキャッシュが消されず増え続ける（10 分で約 115MB）— `AudioOutput.swift:285-345`。
20. 録画が失敗しても「録画中」のまま — `Recorder.swift:354-360`。

### かもしれない（筋道を確かめきれていない）

- Undo の記録と自動保存が、シーンの小さな絵を含む全体を毎回メインスレッドで JSON にする。シーンが多いと引っかかるかもしれない。
- プロジェクターが寝ているとき、`nextDrawable()` が最大 1 秒待ち、全出力が止まるかもしれない（`Metal.swift:2529, 2600`）。
- `AudioClip.deinit` の `engine.detach` が、メイン以外のスレッドで動くことがある。
- あとから足した Codable の項目や、enum の新しい値で、古い版がファイルを読めないかもしれない。

## B. UI の改善案（効き目の大きい順）

1. 空き枠のクリック 1 回でレイヤーが止まる。サムネイルは押した瞬間に出る（`Views.swift:1063-1091`）→ 止めるのはダブルクリックか長押しに。「＋」の当たりを広げる。止めた直後に知らせ。
2. 列番号が見出しに見えるのに、全レイヤーを一斉に出す（`Views.swift:600-607`）→ ▶ を付けてボタンの見た目に。
3. ソロ（S）は出力にも効くのに、出力モニターに印が無い（`Views.swift:251-262`）→「ソロ中 L2」の札と黄色い枠。
4. 出力先が無くても、出力モニターの枠が緑（`Views.swift:288`）→ 灰色の破線と「出力先なし」。
5. Esc が「閉じる」の手癖とぶつかる。メイン以外のウィンドウでもブラックアウトになる（`App.swift:529-547`）→ メイン以外では横取りしない。⇧Esc は長押し。
6. 上のバー：四隅のリセットとテストパターンが 1 クリックで、ブラックアウトの隣（`Views.swift:378-397`）。13 インチで収まらないかも（推測）→「出力の設定」メニューにまとめる。
7. 色の意味がぶつかっている：オレンジ＝次・編集中・値を変えた・コンポジション。今出ているシーンは水色 → 緑＝出ている、青＝選択、オレンジ＝次、黄＝編集中、赤＝消している、に固定。
8. 1280×800 で文字が切れる：キューの名前が「…」だけ、ライブのテンポの行、FX パッドの下 →「シーンの設定（1 秒）」を短く。狭いときは 2 段に。
9. ウィンドウが前でないと「次へ」やブラックアウトの色が抜けるかも（推測。画面外の書き出しで灰色になった）→ 状態のボタンは自前で塗る。
10. 暗い所で読めない 7〜9pt の文字が 22 か所。再生中かどうかは小さな点の色だけ → 11pt 以上に。点を ▶ / ■ の形に。
11. ライブパネルの見出しが「再生中 — L1」なのに下に「停止中」（`Views.swift:1526-1535`）→「選択中のレイヤー」に。
12. キーボードだけで進められない。キューの行はダブルクリックで即出る（`Cues.swift:480`）→ クリック＝「次」に指定、矢印と Enter。
13. 大事な設定が右クリックの奥：キューの「ほかのレイヤーはそのまま」、枠の「終わったら」、パッドのキー → 行にボタンを出す。
14. 空の状態と説明文：空のグリッドは小さな「＋」だけ。説明文が長い。説明書どうしで ⌥ の説明が食い違う。
15. シーン編集中は同じクリックの意味が変わる（`SceneEdit.swift:107`）→ 背景の色を変え、「出力には出ない」を常に出す。

## C. 新機能の案

### ポン出し・進行
- **0 になったら次のキューへ**（小）：時計のジェネレーターに「0 になったら：何もしない／次のキュー／シーン」。
- **キューの自動送り**（中）：終わったら次へ／○秒後に次へ。残り時間の表示。
- **時刻で発火**（小〜中）：キューに「19:00:00 に実行」。「あと 12:30」の表示。
- **キューで文字を差し替える**（中）：名前出し・テロップ。OSC でも文字を受ける。
- **進行表の書き出し・取り込み**（小／中）：CSV・印刷。
- **予備機との同期**（小〜中）：今のキュー番号を OSC で送り、予備機が追う。

### VJ の表現・操作
- **FX パッドのラッチ**（小）：押すと入り、もう一度で切れる。
- **拍・小節に合わせて出す**（中）。
- **押している間だけクリップを差し込む**（小〜中）。
- **2 つのシーンの間をフェーダーで混ぜる**（中〜大）。

### 本番の安心
- **落ちたあとの復帰**（中）：黒で始めて「前回の出力に戻す？」。
- **本番前の点検**（中）：無い素材、キューの行き先、重いコーデック、出力先。
- **本番ロック**（中）：ドラッグ・削除・値の編集を止める。
- **リハーサル用の時計ずらし**（小）と、次のキューの下見（中）。
- **負荷の記録と警告**（小）：今あるステータスバーの延長。

今あるもの（案から外した）：負荷の表示（右下のステータスバー）、スリープ止め、OSC でのキュー操作。
