# サイコロ 第 2 弾：ジェネレーターにも・ホバーの説明・音や拍で自動に振る

前の設計は `docs/dice-presets-design.md`。今の作りは `Sources/VJPlayer/EffectDice.swift`（`Effect.diced(using:slight:)`、`EffectDiceButton`、`EffectCardStep`）と `AnimationViews.swift` のカードの見出し。

## 1. ジェネレーターにもサイコロ（とプリセット）

- 今、クリップのジェネレーターは `Inspector.swift` で `EffectCard(…, isBlendSettings: true)` として出していて、見出しが無いのでサイコロもプリセットも出ていない。
- 見出しの無いこの形でも、説明文の行（今 `resetButton` がある所）に、**元に戻す・サイコロ・プリセット** を並べる（`kind.hasDice` のときだけサイコロ。カメラ・Syphon・NDI・テキスト・時計は今までどおり出さない）。重ね方の設定（本当の isBlendSettings の使われ方）には出さないので、ジェネレーター用かどうかを見分ける引数を足す（`showsCardButtons` など）。
- 何を変えないかは今のサイコロと同じ（toggle・動かしている値・`noDice`・画質・中心・元の絵など）。ジェネレーターで振ると絵が壊れる値（粒の数のような重さに効くもの、真っ黒になる明るさ 0 など）は、第 2・3 弾で `noDice` を付けてあるはず。全部のジェネレーターを 1 回ずつ振って書き出し（下の 4 章）、真っ黒・真っ白・極端に重くなるものがあれば `noDice` を足すか、サイコロ用の範囲（`animRange`）を直す。

## 2. ホバーの説明

- 今の `.help(L("値をランダムに（⌥：少しだけ）"))` が出ていない（見出しの `.onDrag` か、外側の `.help` に負けている可能性）。原因を確かめて、出るようにする。
- 文は「値をランダムに変える（⌥ を押しながら：少しだけ）。右の ▾ で、拍や音に合わせて自動で振る」のように、自動で振る（3 章）があることも分かる文に。自動で振っている間は「自動：4 拍ごと・少しだけ」のように今の設定も出す。
- `.help` がどうしても出ない場所なら、`KindPreview` のホバー（遅れて出る小さなパネル）と同じ仕組みで小さな説明を出してもよい。

## 3. 音・拍で自動に振る

### 操作
- サイコロのボタンを `Menu(primaryAction:)` の形にする：**押すと今までどおり 1 回振る**、横の ▾（か長押し）でメニュー：
  ```
  自動で振る：  しない ✓ / 拍ごと ▸ (1/4・1/2・1・2・4・8・16 拍) / 音のアタックで（キックなど）
  ──────────
  少しだけ ✓（自動のときも手で押すときも、⌥ と同じ「少しだけ」）
  つなぎ：すぐ / 1/4 拍 / 1/2 拍 / 1 拍 / 2 拍
  音の感度 ▸ 低い・ふつう・高い（「音のアタックで」のときだけ）
  ```
- 自動で振っている間は、印を `dice.fill` にして色を付ける（カードを閉じていても分かるように、見出しの名前の横にも小さな印を出すと親切）。
- 1 回振るのも、自動の設定を変えるのも、元に戻す（⌘Z）の 1 歩。**自動で振った結果は元に戻すに積まない**（1 秒に何回も積まれて ⌘Z が使えなくなるので）。

### 保存
- `Effect` に `var autoDice: AutoDice? = nil`（`decodeIfPresent`。無ければ nil＝しない。古い保存はそのまま読める）。
  ```swift
  struct AutoDice: Codable, Equatable {
      enum Mode: Int, Codable { case beats, attack }
      var mode = Mode.beats
      var every = 4.0          // 拍（beats のとき）
      var slight = false
      var glide = 0.0          // つなぎ（拍）。0 はすぐ
      var sensitivity = 1      // 0 低い・1 ふつう・2 高い（attack のとき）
  }
  ```
- プリセットに入れるか：入れる（値の組と一緒に、動き方も呼び出せるほうが便利）。`EffectPresets` の写す項目に足す。

### 動かし方
- **拍ごと**：`BeatClock`（`stack.beat`）の拍の位置が `every` の区切りをまたいだら振る。BPM・拍の位置は今のアニメーション（BPM の動き）と同じものを使う。
- **音のアタック**：`AudioReactive` の立ち上がり（`onsets` の低い帯。キックで大きくなる）を使って、しきい値を超えた瞬間に振る。しきい値は感度で決め、続けて振らないよう最短 0.12 秒あける。音の入力が無い・止まっているときは振らない。立ち上がりを取り出す口が `AudioReactive` に無ければ足す（音のスレッドではロックやメモリ確保をしない今の決まりを守る。取り出しはメインから最新の値を読むだけ）。
- **どこで振るか**：メインスレッドの小さな見張り（`AutoDiceDriver`。60 回/秒の Timer か、今あるメインの定期処理に乗る）が、今のプロジェクトの全部の `Effect`（クリップのエフェクト・クリップのジェネレーター・レイヤー・コンポジション・FX パッドなど、`autoDice != nil` のもの）を見て、時が来たものを `diced(slight:)` で書き換える。書き換えは undo に積まず、保存は今の自動保存（まとめて 0.5 秒後）に任せる。`autoDice` を持つ Effect が 1 つも無いときは何もしない（見張りを止める）。
  - 「今出ていないクリップ」のエフェクトも振るか：**出ているもの（再生中のクリップ・レイヤー・コンポジション・押しているパッド）だけ**。見えない所が変わり続けると、出したときに驚くので。
- **つなぎ**：振った瞬間に値が跳ぶのではなく、`glide` 拍かけて前の値から新しい値へなめらかに移る。メインで 60 回/秒書き換えると重いので、**描画側で補間する**：`Effect` に保存しない項目 `diceFrom: [Double]?`・`diceAt: Double`（振った時刻。`value(_:at:beat:origin:)` と同じ時計）・`diceGlideSec` を持たせ、`value(i, at: t, …)` が `t - diceAt < diceGlideSec` の間は `diceFrom[i]` から今の値へ smoothstep で補間して返す（toggle・choices は補間しない＝半分で切り替え）。Codable・Equatable に入れない（保存しない・比べない）。
- choices（形など）や色も「少しだけ」でなければ変わる＝絵が大きく変わる。拍ごとの自動は、初めは「少しだけ」をすすめる（メニューの並びで少しだけを上に・説明書に一文）。

## 4. 守ること・テスト・確かめ方

- 文章は日本語、やさしい言葉で。訳（`Localizable.strings`、末尾に、キーの二重なし、`python3 tools/i18n_check.py`）、説明書（`site/docs/ja|en/parameters.md` のサイコロの節に、ジェネレーター・自動・つなぎ）。
- テスト（新しいファイル `SelfTestDice2.swift`、`SelfTest.swift` に呼び出し 1 行）：
  - `AutoDice` を含む Effect の保存と読み直し、古い JSON（項目なし）が読める、プリセットに入る。
  - 拍ごと：BPM 120・4 拍ごとで、ちょうど区切りをまたいだときに 1 回だけ振る（同じ区切りで 2 回振らない）。
  - アタック：立ち上がりの列を与えて、しきい値を超えた所だけ・最短間隔を守って振る（純粋な関数に分けてテスト）。
  - 出ていないクリップのエフェクトは振らない。
  - 自動で振っても undo に積まれない。手で押すのは 1 歩。
  - つなぎ：振った直後の `value` は前の値、`glide` 後は新しい値、途中は間の値。choices は補間しない。
  - 全部のジェネレーターを種を変えて 5 回ずつ振り、`--gen-preview` 相当で 1 枚描いて、真っ黒・真っ白・NaN が出ない（輪から湧く粒などの状態を持つものは少し進めてから）。重さが極端に増えない（初期値の 3 倍以内）。
- 見た目：`--card-preview <kind>` で、エフェクト（kaleidoscope）とジェネレーター（plasma・ringEmitter）のカードを書き出し、ボタンの並び・自動の印を自分の目で見る。メニューは画像にしにくいので、テストで中身を確かめる。
- 利用者の設定（defaults `local.yama.vjplayer`、`~/Library/Application Support/Halo VJ/`）に確認・テストで書かない。窓を出す起動はしない。キーやクリックを送らない。コミット・push はしない。

# 5. 自動で振るの設定を、メニューから「小さなパネル」に（見た目で分かるように）

利用者の声：▾ のメニューは、チェックの印だけで「今、有効か・無効か」「音のときに何が起きているか」が分かりにくい。値の動かし方のパネル（波形のボタンから開く、固定／秒／BPM／音／OSC・MIDI の切り替えと、拍のボタンが並ぶ紫の枠）と同じ見た目の、グラフィカルなパネルにする。

## 形

▾ を押すと、メニューの代わりに **ポップオーバー**（`.popover`）を開く。幅は値の動かし方のパネルと同じくらい。上から：

```
┌ サイコロ ─────────────────────────────┐
│ [🎲 今すぐ振る]                           │  ← 大きめのボタン。押すとその場で 1 回（下の「変え方」で）
│                                            │
│ 自動で振る  [ オフ | 🥁 拍 | 〰 音 ]       │  ← ChoiceButtons（大きい切り替え。選んでいる所が青く塗られる）
│                                            │
│ （拍のとき）                               │
│   [1/4][1/2][1][2][4][8][16] 拍ごと        │  ← 値のパネルの拍のボタンと同じ見た目
│   ●○○○  ← 今の拍の位置（次に振るまで）   │  ← 区切りまでの進み具合を、点か細い棒で。振った瞬間に光る
│                                            │
│ （音のとき）                               │
│   ▁▂▅█▃▁▁▂▇▂  ─── しきい値の線            │  ← 立ち上がりの強さの、流れるグラフ（最近 2〜3 秒）
│   ↑ 線を上下にドラッグして感度を変える     │     しきい値を超えて振った所に小さな印（光る点）
│   感度 [────●────]                        │  ← スライダーでも同じしきい値（グラフの線と連動）
│   音の入力がオフのときは「音の入力がオフです（上の帯でオンに）」と出す
│                                            │
│ 変え方      [ 大きく | 少しだけ ]          │  ← 今の「少しだけ」を、どちらかを選ぶ形に
│ つなぎ      [すぐ][1/4][1/2][1][2] 拍      │
│                                            │
│ 状態：● 4 拍ごとに振っています  / ○ オフ   │  ← 色付きの丸と文。振るたびに丸が一瞬明るく
└────────────────────────────────────────────┘
```

- 「オフ」のとき、拍・音の行は出さない（か薄くする）。オンとオフが、塗られたボタンと状態の丸ではっきり分かること。
- 部品は今あるもの（`ChoiceButtons`、値の動かし方のパネルの拍のボタン、`ValueDrag` など）を使い回して、見た目をそろえる。新しい色は足さない（自動の印は今のオレンジ）。
- グラフ・拍の進み具合・状態の丸は、パネルが開いている間だけ動く（`TimelineView(.animation)` などで。閉じたら止まる）。
- ⌥ を押しながら見出しのサイコロを押すと「少しだけ」で 1 回、は今のまま。見出しのサイコロ（`primaryAction`）も今のまま 1 回振る。
- ホバーの説明（`HoverTipPanel`）も今のまま。

## 保存の変更

- 感度を 3 段から連続の値に：`AutoDice.threshold: Double`（0.05…0.95。初期 0.5）。古い保存の `sensitivity`（0/1/2）は読むときに 0.7/0.5/0.3 に直す（`decodeIfPresent`）。書くのは `threshold` だけでよい。
- 「少しだけ」は今の `slight` のまま（「変え方」の切り替えはこれの見た目）。

## 振ったことの知らせ

- 見張り（`AutoDiceDriver`）が振ったとき、その Effect の id と時刻を、パネルが読める所（小さな `ObservableObject` か、パネルが TimelineView で読む静的な辞書）に置く。パネルの状態の丸・グラフの印がそれを見て光る。グリッド全体を描き直さないこと（前に MIDI の `@Published` で全部描き直していた問題と同じことを起こさない）。
- 立ち上がりの強さの列（グラフ用）は、見張りが判定に使っている値を、短い輪の配列（120 個くらい）に残して、パネルが読む。

## テスト・確かめ方

- テスト（`SelfTestDice2.swift` に足す）：古い `sensitivity` が `threshold` に直る／`threshold` の保存と読み直し／しきい値を変えると、同じ列で振る所が変わる。前のメニューの中身のテスト（`menuEntries`）は、パネルの中身を決める純粋な関数のテストに置き換える。
- 見た目：パネルを窓の外に描いて PNG に（`CardPreview.writeView` の形。オフ・拍・音（グラフに値を入れた状態）・音の入力オフ の 4 枚）、自分の目で見て、オンとオフが一目で分かるか、値の動かし方のパネルと並べて違和感がないか確かめる。
- 守ることは前と同じ（利用者の設定に書かない・窓を出さない・キーやクリックを送らない・コミットしない）。
