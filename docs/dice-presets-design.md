# サイコロ（値のランダム化）とエフェクトのプリセット 設計

エフェクト・ジェネレーターのカード（パラメーターパネルの 1 枚）に、2 つの小さな機能を足す。

## 1. サイコロ（値をランダムに）

カードの見出しの右側（今ある「元に戻す」やメニューのボタンの並び）に、サイコロのボタン（`dice`）を足す。

- 押すと、そのエフェクトの値を **1 回の操作で** ランダムにする（⌘Z で 1 回で戻る。今の undo の仕組みに乗せる）。
- 値ごとの決め方：
  - ふつうの値：`animRange` があればその中、無ければ `range` の中で一様に。`step` があれば丸める。
  - choices：等しい確率で 1 つ。
  - toggle：**変えない**（「透明にする」「鏡にする」などは絵の性格が変わりすぎる）。
  - 色：色相をランダムに（彩度・明るさは今の値を保つ）。白・黒・灰（彩度 0）の色は変えない。
  - アニメーション（LFO・音・拍の割り当て）が付いている値は **変えない**（動きの設定はそのまま）。
  - 画質・不透明度・混ぜる量（Mix に当たるもの）・位置や大きさの変形・文字（テキストの文面・フォント）・ファイルやデバイスの選択は **変えない**。どの値が「形を決める値」かは `EffectParam` に `noDice`（初期 false）を足して、要る所だけ印を付ける。
- ⌥を押しながら：「少しだけ」。今の値から、範囲の ±15% の中で動かす（choices は変えない）。
- カメラ・Syphon・NDI・テキスト・時計はボタンを出さない。
- ツールチップ：「値をランダムに（⌥：少しだけ）」。
- ランダムの素は `SystemRandomNumberGenerator`。テスト用に、乱数を渡せる純粋な関数 `Effect.diced(using:slight:) -> Effect` に分ける。

## 2. プリセット（値の組を名前で保存）

カードのメニュー（無ければサイコロの隣に `bookmark` のボタンでメニュー）に：

```
プリセット ▸  （この種類のプリセットの一覧。選ぶと値が入る）
              ─────
              今の値を保存…   → 名前を聞く小さなシート／アラートの入力
              プリセットを消す ▸ （一覧）
```

- プリセットは **エフェクトの種類ごと**（`EffectKind` の名前がキー）。中身は「名前」と、その時の `Effect` のうち **値・choices・toggle・色・アニメーションの割り当て**（＝別のカードに入れて同じ絵になるもの）。id、有効/無効、開閉、不透明度などカード固有のものは入れない。`Effect` をそのまま Codable で持ち、当てるときに「入れるもの」だけを写すのが簡単。
- 当てるのは 1 回の操作（undo できる）。
- 保存先は **プロジェクトではなくアプリ共通**：`~/Library/Application Support/Halo VJ/effect-presets.json`（どのプロジェクトでも使える）。`VJ_STATE_PATH` が指定されているときは、その隣（同じフォルダの `effect-presets.json`）を使う（テスト・確認が利用者のファイルに触らないように）。読むのは起動時と保存時、書くのは変えたときだけ。壊れたファイルは無視して空から（上書きは次に保存したときだけ）。
- 同じ名前で保存したら上書き（確認なし）。名前が空なら「プリセット 1」のように番号を振る。
- 値の数が今の種類の値の数と合わないプリセット（将来、値が増えたとき）は、足りないぶんを今の値のまま・多いぶんは捨てる。
- 型：`struct EffectPreset: Codable, Identifiable { id, name, effect }`、`final class EffectPresets: ObservableObject { static let shared; func list(for kind) ; save(name:effect:) ; delete(id) ; apply(_:to:) -> Effect }`。新しいファイル `EffectPresets.swift` に。

## 3. 守ること

- 文章は日本語、やさしい言葉で（今の UI・コメントの言い方に合わせる）。英語の訳も `Resources/en.lproj/Localizable.strings` に（`python3 tools/i18n_check.py`）。
- カードの見出しが窮屈にならないこと（狭い幅でも名前が読める。今あるボタンの大きさ・間隔に合わせる）。`--card-preview <kind> out.png` と `--panel-preview` で絵を書き出して自分で見る。
- 今ある保存データは今までどおり読める（`EffectParam` に足す項目は保存しない定義側の項目。`Effect` に項目を足さない）。
- テストは **新しいファイル** `SelfTestDice.swift` に extension で書き、`SelfTest.swift` には呼び出し 1 行だけ足す：
  - `diced`：toggle・アニメ付き・noDice の値は変わらない／ふつうの値は範囲の中／step に乗っている／choices は範囲の整数／同じ種の乱数で同じ結果／slight は ±15% の中。
  - プリセット：保存 → 読み直し → 当てると値が同じ／別の種類には出ない／上書き／削除／値の数が違っても落ちない／壊れた JSON で落ちない。一時フォルダを使う。
- 説明書：`site/docs/ja/parameters.md`（と `en`）に短い節を足す。
- 利用者の設定（defaults `local.yama.vjplayer`、`~/Library/Application Support/Halo VJ/`）には **確認・テストで書かない**。画面を乱さない（窓を出すなら音なし・キーやクリックは送らない・撮るのは窓だけ）。コミット・push はしない。
