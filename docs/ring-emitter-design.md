# ジェネレーター「輪から湧く粒」（ringEmitter）設計

参考：TouchDesigner の作例。細かい粒が大きな円の縁にびっしり並び、ところどころ縁から外へはがれて、煙のように渦を巻きながら流れ出し続ける。

## 1. 絵

- 粒は **円周の上で生まれ**、外向き（設定で内・両方）に少し押し出される。
- 動きは **カールノイズ**（3D の値ノイズか simplex のポテンシャル場の curl。時間で z を進めて場がゆっくり変わる）。乱流のように渦を巻きながら流れていく。
- 空気抵抗で遅くなり、**寿命** に近づくと薄く・小さくなって消える。消えた粒はすぐ円周のどこかで生まれ直す（数は一定。ずっと出続ける）。
- 生まれたばかりの粒は、縁に沿ってしばらくとどまる（「縁にとどまる」の値。とどまる間は外へ押す力を弱める）ので、縁がびっしり明るい帯に見える。参考の絵の「明るい縁＋はがれて流れる粒」はこれで出す。
- 描き方は小さな光る点の **加算**。重なると明るくなる。残像（前のコマを薄めて重ねる。今の `drawDots` の fadeK）も使える。背景は透明。

## 2. 作り（今の仕組みに乗せる）

- 前のコマを覚えて動かす種類（`isStateful`）。手本は `Life.swift` の `ParticleLifeSim`（状態のバッファ 2 つを入れ替え、compute で 1 歩ずつ進め、`LifeRenderer.drawDots` で点を描く）と `FireflySim`。新しいクラス `RingEmitterSim` を新しいファイル `RingEmitter.swift` に（シェーダーも同じファイルか、今の作りに合わせて）。
- 粒の数は最大 **120,000**（`maxCount`）。1 粒は `float4 p`（x, y, 年齢, 寿命）＋ `float4 q`（速度 x, y, 種, 生まれた角度）くらい。compute は 1 粒 1 スレッドで O(n)（粒どうしの力は無い）。1920×1080・初期値（40,000 粒）で **1.5 ms 以内**、最大でも 4 ms 以内。
- 生まれ直しは compute の中で：年齢 ≥ 寿命なら、`hash(id, 回数)` で角度を決めて円周上へ。全部が同時に生まれ直さないよう、初めの年齢は寿命の中でばらす。最初のコマから「出続けている途中」の絵になるように（初めに何歩か空回しするか、初めの位置を流れの途中にばらまく）。
- 座標は高さを 1 とする（縦横比でつぶれない）。円の大きさ・位置も高さ基準。
- 時間：`dt` で進める（今のシムと同じく、大きな dt は歩に分ける）。止まっている間は描き足さない（今のシムと同じ）。ノイズの時間は Double で持って、Float にする前に十分小さい周期で折り返す（長く動かしても崩れないこと。ノイズは周期的なものにするか、折り返し点で跳ばない作りに）。
- 「速さ」0 で止まる。

## 4. 入れる所・守ること

- `Effects.swift`：`EffectKind` に `ringEmitter` を **足すだけ**（今ある行は書き換えず、第 3 弾のジェネレーターの case 行の下に新しい行）。`isStateful` の並び、`generators` の並びにも足す。`MoreKinds.swift` の第 3 弾のジェネレーターの最後（fire）のすぐ下に名前・印・分類・値・説明。描き分け（`drawLife` など今のシムを呼んでいる所）に 1 か所。
- 見本（マウスを乗せたときの `KindPreview`）・カード・一覧に自然に出ること。見本は 512×288 なので、見本では粒の数を減らしてよい（今のシムに見本用の扱いがあれば合わせる）。
- 訳（`Localizable.strings`、末尾に。同じキーを二重に足さない。`python3 tools/i18n_check.py`）、説明書（`site/docs/ja|en/generators-more.md` と一覧の表）。
- テスト（新しいファイル `SelfTestRingEmitter.swift`、`SelfTest.swift` に呼び出し 1 行）：定義がそろう・保存して読める／何コマか進めると絵が出る・真っ黒でない・透明な所がある／円の外に粒が出ている（中心から半径の 1.1 倍より外に明るい画素がある）・円の内側の中心付近はほぼ暗い（出る向き「外へ」のとき）／速さ 0 で絵が変わらない／粒の数を最大にしても落ちない／1920×1080 の重さ。
- 絵は必ず書き出して自分の目で見る：時間を進めた何コマか（`--gen-preview` は 1 コマなので、シムを何歩か進めてから書き出す口が無ければ足す。今のシムの書き出しがどうしているかを先に読む）。参考の雰囲気（明るい縁＋はがれて渦を巻く粒）に近いか、初期値を調整する。
- 利用者の設定（defaults `local.yama.vjplayer`、`~/Library/Application Support/Halo VJ/`）に書かない。窓を出す起動はしない。キーやクリックを送らない。コミット・push はしない。
