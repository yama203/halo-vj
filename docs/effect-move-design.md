# エフェクトを別の場所へ付け替える（設計）

## ねらい

クリップ（動画・画像・ジェネレーターのクリップ）、レイヤー、コンポジションに付けたエフェクトを、
**値を保ったまま** ドラッグでほかの場所へ付け替えられるようにする。向きは自由（クリップ → レイヤー、レイヤー → コンポジション、コンポジション → クリップ、クリップ → 別のクリップ…）。

今は、カードの名前の行をドラッグすると **同じ並びの中の並べ替え** だけができる（`EffectReorderDrop`、文字列 `vjeffectmove:<id>`）。
一覧（エフェクトのパネル）からのドラッグは「新しく足す」で、値は最初の値。

## 何が動くか

`Effect` をまるごと動かす：値（params）・動かし方（anims）・不透明度（mix と mixAnim）・オン／オフ・サイコロの自動（autoDice）・そのほか `Effect` が持つもの全部。

- **移す**（ふつうのドラッグ）：元から外して、先へ入れる。`id` はそのまま（カードの開閉などが続く）。
- **写す**（Option を押しながら）：元は残して、先へ同じものを入れる。`id` は新しくする（中に `id` を持つものがあれば、それも新しく）。
- 同じ並びの中へ落としたら、今まで通りの並べ替え（Option なら、その位置に複製）。

動かせないもの（今までも並べ替えできないもの）：クリップのジェネレーター本体のカード、レイヤーの重ね方（特殊合成）の設定。これらは対象外。

## 落とせる所

ドラッグ中、落とせる所は紫の枠で光る（今の `effectDropTarget` と同じ見た目）。

| 落とす所 | 結果 |
|---|---|
| グリッドのクリップ | そのクリップの最後に付く |
| グリッドのレイヤーの見出し（今、一覧からエフェクトを落とせる所） | そのレイヤーの最後に付く |
| コンポジションの落とし先（今、一覧から落とせる所があればそこ） | コンポジションの最後に付く |
| パラメーターの上のタブ（コンポジション／レイヤー／クリップ） | そのタブの相手（選んでいるレイヤー・クリップ）の最後に付く。タブの上で 0.6 秒止めるとそのタブに切り替わり、カードの間へ落として位置を決められる |
| ほかの並びのカードの上（別ウィンドウに出したパラメーターなど） | その位置に入る |
| 「＋ エフェクト」の点線の枠 | その並びの最後 |

今ある「一覧からエフェクトを落とせる所」は全部、付け替えも受ける。探して揃える（`EffectDrop.handle` / `effectDropTarget` / グリッドの枠の `onDrop` / `EffectReorderDrop` / FX パッドは除く）。

落とせない所・断る場合（ビープ音、何も変えない）：

- 空のクリップ枠。
- 相手がその種類を受けられないとき（今、一覧から落として断っている条件と同じ。調整レイヤーの決まりなど）。断る条件は今のコードに合わせ、1 か所の関数にまとめる。
- 元と先が同じで、位置も変わらないとき（何もしない。ビープ音も鳴らさない）。

落としたあと：

- **選択は変えない**（本番中に出力やプレビューが変わらないように）。ただし「グリッドのクリップへ一覧から落とすと選ぶ」今の動きは、新しく足すときだけのもので、付け替えでは選ばない。
- 落とした先を 0.4 秒ほど紫に光らせる（どこへ行ったか分かるように）。
- カードが開いていたら、移した先でも開いたまま（`EffectUIState.expanded` は `id` で持っているので、移すならそのまま）。

Option のとき：`DropProposal(operation: .copy)` を返して、カーソルに「＋」が付くようにする（`DropDelegate` で `NSEvent.modifierFlags` を見る）。ふつうは `.move`。

## 右クリックでも

カードの名前の行を右クリック：

- 「移す」▸ コンポジション／レイヤー「（名前）」…（全部のレイヤー）／クリップ「（名前）」（今選んでいるクリップ、再生中のクリップ）
- 「写す」▸ 同じ並び
- 今いる所は選べない（灰色）。受けられない相手も灰色。

ドラッグに気づかなくても使えるようにするため。

## 作り

### 置き場所

```swift
/// エフェクトの置き場所
enum EffectPlace: Equatable {
    case composition
    case layer(Int)
    case clip(UUID)        // ClipSlot の id
}
```

### エンジン

```swift
extension Engine {
    /// id のエフェクトが今どこにあるか（コンポジション・全部のレイヤー・全部のデッキのクリップから探す）
    func effectLocation(_ id: UUID) -> (place: EffectPlace, index: Int)?
    /// 置き場所の持ち主（無ければ nil）
    func effectHolder(_ place: EffectPlace) -> (any EffectHolder)?
    /// その種類を、その置き場所に付けられるか（今の断る条件を 1 か所に）
    func canHold(_ kind: EffectKind, at place: EffectPlace) -> Bool
    /// 付け替える。index が nil なら最後。copy なら元を残して新しい id で入れる。変えたら true
    @discardableResult
    func transferEffect(_ id: UUID, to place: EffectPlace, at index: Int? = nil, copy: Bool = false) -> Bool
}
```

- `transferEffect` は画面なしで試せるようにする（`Engine(persistent: false)`）。
- 同じ並びの中なら、今の `moveEffect(_:to:)` と同じ結果にする（落とす位置の決まりを変えない）。
- **元に戻す（Undo）は 1 回で両方戻る** ようにする。今の Undo の作り（`Undo.swift`）に合わせる。
- シーンを編集している最中（`sceneDraft`）や、エフェクトのクリップ（調整レイヤーのクリップ）でも、今カードが見えている所なら同じように動くこと。持ち主の探し方は今のコードを読んで決める。分からない持ち主（見つからない `id`）は何もしない。
- 描画スレッドとの兼ね合い：今 `effects` を書き換えている所（`removeEffect` / `insertEffect`）と同じやり方で書き換える。新しい鍵や別の経路は作らない。

### ドラッグの受け口

- ドラッグの文字列は今の `vjeffectmove:<id>` のまま使う（Option かどうかは落とした時に見る）。
- `EffectDrop` に、付け替えも受ける入口を足す。今の「種類を受ける」入口と並べて、落とす所ごとに `EffectPlace` を渡すだけで両方受けられる形にする。
  例：`.effectDropTarget(place: .layer(i)) { kind in … }`（付け替えは中で `engine.transferEffect`、新しく足すのは今まで通りの closure）。
- `EffectReorderDrop`：ドラッグしてきた `id` がこの並びに無ければ、`transferEffect(id, to: この並び, at: index)`。
  線の出る向き（上か下か）は、よその並びから来たときは「上」。
- `EffectUIState.shared.dragging` は、落としたとき・ドラッグが終わったときに必ず nil に戻す。

### タブの上で止めると切り替わる

パラメーターの上のタブ（`Inspector.swift` の `Picker`、`engine.inspectorTab`）は、今は `Picker(.segmented)`。
`Picker` の 1 つずつには落とせないので、ドラッグ中（`EffectUIState` に `@Published` の「ドラッグ中」を足す。今の `dragging` は `@Published` でない）だけ、
タブの上に同じ大きさの 3 つの受け口を重ねる。受け口は、重なると紫に光り、0.6 秒で `engine.inspectorTab` を切り替える。落とせばその相手の最後に付く。

- ドラッグが終わったことは、システムのドラッグでは確実には分からない。受け口を出しっぱなしにしないため、マウスのボタンを離したら消す見張りを付ける（`NSEvent.pressedMouseButtons`。前に `DockDragState.begin` でやっていたのと同じやり方）。
- 「ドラッグ中」を見るのは、この受け口の小さな View だけにする（カードやパラメーター全体を描き直さない）。

## 試す

### セルフテスト（新しいファイル `SelfTestEffectMove.swift`、`SelfTest.swift` から呼ぶ）

`Engine(persistent: false)` で：

- クリップ → レイヤー、レイヤー → コンポジション、コンポジション → クリップ、クリップ → 別のクリップ。値・動かし方・不透明度・オン／オフ・`id` が保たれ、元から消えている。
- 写す：元に残り、先のものは `id` が違い、値は同じ。
- 位置：`at:` で途中に入る。nil なら最後。
- 同じ並びの中：今の `moveEffect(_:to:)` と同じ結果。
- 断る：受けられない種類、空の枠、無い `id`。何も変わらない。
- `effectLocation`：別のデッキのクリップも見つかる。
- Undo 1 回で両方戻る（Undo が画面なしで試せる作りなら）。

### 見た目

今ある `--card-preview` などの入口で、カードが崩れていないことだけ確かめる。
ドラッグ中の見た目は、開発用の入口を無理に足さなくてよい（足せるなら、タブの受け口が光っている絵を 1 枚）。
