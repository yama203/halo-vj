# 出力のマッピング（Arena の Advanced Output 相当）設計

今ある「出力の分割」（`Sources/VJPlayer/OutputMap.swift`）を伸ばして、プロジェクションマッピングに使えるようにする。
作り直しではなく拡張。今のプロジェクト（保存済みの `outputMap`）はそのまま読めて、同じ絵が出ること。

## 1. 考え方

スライス 1 つの絵の流れ：

```
元の絵（source） → 取る所（input の四角＋回転） → スライスの中の座標 (u,v) 0…1
  → 切り抜き（crop の多角形・任意） → メッシュ（warp・任意。(u,v)→(u',v')）
  → 四隅（corners の射影変換） → 出力の画面
出力ごとに最後にマスク（多角形で黒く塗る）
```

- 四隅とメッシュは両方かかる（Arena と同じ）。メッシュの点は「スライスの中の座標」で持つ。四隅を動かすとメッシュごと動く。
- スライスは並び順に上へ重ねる（後ろのものが手前）。今の「足し算」はやめる（下の「描き方」）。

## 2. データ（すべて Codable・Equatable。古い保存データを読めること）

**古い JSON に無い項目は必ず `decodeIfPresent` で初期値に**（`init(from:)` を自分で書く。合成された Codable は項目が無いと失敗する）。

```swift
enum SliceSource: Codable, Equatable {      // 元の絵
    case composition                        // 全体（今まで）
    case layer(UUID)                        // このレイヤーだけ（レイヤーのエフェクト込み。コンポジションのエフェクト・変形は無し）
}

struct SliceMesh: Codable, Equatable {      // メッシュ
    var cols = 2, rows = 2                  // マスの数（1…8）
    var points: [[Double]]                  // (cols+1)*(rows+1) 個。行ごとに左→右、上→下。スライスの中の座標（初めは等間隔）
    var smooth = true                       // 点の間をなめらかに（Catmull-Rom）。false は折れ線
    static func regular(cols:rows:) -> SliceMesh
    func resized(cols:rows:) -> SliceMesh   // 今の形を保ったまま点の数を変える（今の面を新しい格子で取り直す）
    func position(u:v:) -> SIMD2<Double>    // (u,v) → 動かした先
}

struct OutputSlice {                        // 今の項目はそのまま
    // 追加
    var source = SliceSource.composition
    var inputRotation = 0.0                 // 度。取る所の四角を、その中心で回す
    var flipH = false, flipV = false
    var mesh: SliceMesh? = nil              // nil ＝ メッシュなし
    var crop: [[Double]] = []               // スライスの中の座標の多角形（3 点以上で有効。三角・多角形の面）
    var cropInvert = false
    var opacity = 1.0
    var brightness = 0.0                    // -1…1
    var contrast = 0.0                      // -1…1
    var gain: [Double] = [1, 1, 1]          // 赤・緑・青
}

struct OutputMask: Codable, Identifiable, Equatable {
    var id = UUID(); var name = "マスク"; var enabled = true
    var output = 0
    var points: [[Double]]                  // 出力の画面の座標（0…1）。3 点以上
    var invert = false                      // true：形の外を黒く
}

struct OutputMap {
    var enabled, slices                     // 今のまま
    var masks: [OutputMask] = []
    var blendGamma = 2.2                    // 端をなじませるときのガンマ
    var backdrops: [String: String] = [:]   // "0"…"2" → 下敷きの写真のパス（合わせる画面だけ。出力には出さない）
    var backdropOpacity = 0.5
}
```

`active` は今のまま（enabled かつ有効なスライスがある）。

## 3. 描き方（`SliceRenderer`）

今は全画面の四角 1 枚でフラグメントがスライスを回している（16 個まで）。これを **スライスごとに網（三角形）を描く** 形にする。

- スライス 1 つ：`mesh` のマスごとに 8×8 に割った三角形の網（メッシュなしは 1 マスを 8×8…ではなく 1×1 でよい。射影は頂点の w で正しく出す）。
  - 頂点：`(u,v)` と、位置 `H * (u',v',1)`。**クリップ座標に w を残す**（`pos = float4(x*2-w, w-y*2, 0, w)` のように。x,y は H をかけた後の同次座標）ので、GPU が射影を正しく補間する。`w <= 0` の頂点を含む三角形は捨てる。
  - フラグメント：`(u,v)` から、切り抜き（多角形の内外。点は 32 個まで uniform で渡す）、端のなじませ（今の式）、取る所（回転・反転込みの 2×3 行列で元の絵の UV へ。0…1 の外は黒）、色（明るさ・コントラスト・ゲイン・不透明度）。
  - 重ね方：`rgb = c * g, a = g`（`g = pow(w, 1/blendGamma)`。w ＝ なじませ × 切り抜き × 不透明度）で、`src = one, dst = oneMinusSourceAlpha`。黒の上なら光の量が w 倍になり、下にスライスがあれば上が覆う。
- マスク：スライスを全部描いたあと、その出力のマスクを黒で描く。多角形は耳切り（ear clipping）で三角形に（へこんだ形も）。`invert` は「画面全体 − 形」を黒く（ステンシルを使うか、形を穴にした三角形分割。簡単な方で）。
- テストパターン：今の格子とふちを、スライスごとの網の上に（メッシュのゆがみが見えるように）。
- master は最後にかける（今と同じ見え方）。全部を 1 回の描画パスで。
- 頂点バッファは、スライスの形が変わったときだけ作り直す（`OutputSlice` を比べる）。数の上限は 64。
- **元の絵がレイヤー**のスライス：`RenderLoop.tick`（`Metal.swift`）で、そのレイヤーだけを合成した絵を用意する。`engine.layerGroups()` の中の `key` がレイヤーの番号。必要なレイヤーごとに `Compositor` を 1 つ持ち、コンポジションと同じ大きさで `composite([そのグループ（blend は .normal）], effects: 空)`。`Engine` に「UUID → 今のレイヤー番号」を描画スレッド用に引ける口を足す（`renderLock` の中で）。そのレイヤーが無ければ黒。
- 合わせる画面のガイド（6 章）も同じパスの最後に描く。

今までと同じ設定（メッシュなし・切り抜きなし・重ならない）なら、今までと同じ絵になること（テストで確かめる）。

## 4. 合わせる画面（`OutputMapEditor` を作り直す）

窓の名前とメニューは「出力のマッピング…」（⌘⇧M のまま）。

```
┌ 上の帯：［マッピングを使う］ ひな形▾  テストパターン  出力にガイド  くっつく  ｜ 読み込む… 保存… ┐
│ 出力 1 ▾  出力 2 ▾  出力 3 ▾                                                                    │
├──────────┬──────────────────────────────────────────────┬───────────────┤
│ 一覧      │ ［取る所］［映す所］   出力 1|2|3   拡大 −＋ 合わせる │ 選んだものの設定  │
│ ▸ スライス │                                              │                  │
│ ▸ マスク   │            大きな 1 枚の舞台                    │                  │
│ ＋▾ 複製 − │                                              │                  │
└──────────┴──────────────────────────────────────────────┴───────────────┘
```

- **一覧**：スライスとマスク。ドラッグで並べ替え（下ほど手前）。目のボタンで出す／出さない。＋のメニュー：スライス（四角）／三角のスライス／多角形のスライス（切り抜き付きで作る）／マスク。複製・削除。
- **舞台**：タブで「取る所」（コンポジションの絵の上に、取る四角）と「映す所」（選んだ出力の絵の上に、面とマスク）。スクロールで拡大、何もない所のドラッグで移動、「合わせる」で元に戻す。
- **映す所の編集モード**（選んだスライスに対して、舞台の上のボタン）：
  - 「四隅」：4 点。面の中をドラッグで全体を動かす。
  - 「メッシュ」：格子の点。設定側に 横・縦のマスの数（1…8）、なめらかに、メッシュを元に戻す。メッシュが nil なら、このモードに入ったときに 2×2 を作る。
  - 「切り抜き」：スライスの中の多角形の点（面の上に重ねて描く）。
  - マスクを選んだとき：多角形の点。
  - 多角形（切り抜き・マスク）：辺の上をクリックで点を足す。点を選んで Delete で消す（3 点は残す）。
- **点の扱い**（共通）：クリックで選ぶ、⇧クリックで足す、何もない所から囲んで複数選ぶ。矢印キーで出力の 1 ピクセルぶん（⇧で 10）。「くっつく」が入っていれば、ほかのスライス・マスクの点と画面の端・中央に 8 pt 以内で吸い付く。
- **取る所**：四角のドラッグ・四隅と辺で大きさ・上の丸で回転。数値でも（設定側）。
- **設定**（スライス）：名前、出す、出力、元の絵（全体／レイヤー名）、取る所（X・Y・幅・高さ・回転・左右反転・上下反転）、端をなじませる（左右上下）、色（不透明度・明るさ・コントラスト・赤緑青）、四隅を元に戻す。（マスク）：名前、使う、出力、内と外を入れ替える。
- **下敷きの写真**：映す所の舞台に、写真を薄く敷く（出力ごとに選ぶ・外す・濃さ）。出力には出ない。
- **保存・読み込み**：マッピングだけを `.halomap`（JSON）に書き出す・読み込む。
- 元に戻す（⌘Z）は今の `outputMap` の仕組みのまま効くこと。ドラッグ中は 1 回の操作としてまとまること（今の仕組みを確かめる）。

## 5. 守ること

- 文章は日本語、やさしい言葉で（今のコードのコメント・UI の言い方に合わせる）。
- 分割を使わないとき（enabled = false）の動きは変えない。
- 利用者の設定（defaults `local.yama.vjplayer`、`~/Library/Application Support/Halo VJ/`）には書かない・消さない。確認は `VJ_STATE_PATH` に写しを使う。
- 画面を乱さない：起動して確かめるなら音なし（`VJ_AUDIO_SOURCE=off`）、キーやクリックは送らない、撮るのは窓だけ（`screencapture -x -o -l <窓番号>`）。絵の確認は、できるだけ画面に出さない書き出し（`CardPreview.writeView` の形）で。
- コミット・push はしない。

## 6. 出力に出すガイド

合わせる窓が開いていて「出力にガイド」が入っているとき、実際の出力に：選んだスライス（かマスク）の輪郭（黄色）、点（選んだ点は大きく）、メッシュの線。保存しない状態として `Engine` に持ち（`mapGuide`）、`RenderParams` で描画スレッドへ。窓を閉じたら消す。

## 7. テスト（`SelfTest.swift`。`--selftest` で通ること）

- 古い形の JSON（追加の項目なし）が読めて、書いて読み直しても同じ。
- 今までの設定で、今までと同じ絵（四隅だけ・なじませあり・テストパターン）。
- メッシュ：等間隔のままなら四隅だけと同じ絵（差がほぼ 0）。点を動かすと、その辺りの絵がずれる。`resized` で形が保たれる。
- 切り抜き：三角の外が黒。反転で内が黒。
- マスク：形の中が黒。反転で外が黒。へこんだ形でも正しい。
- 取る所の回転 90° と反転。
- 重なり：後ろのスライスが手前。
- 色：不透明度 0.5 で光の量が約半分。
- レイヤーが元の絵：そのレイヤーの絵だけが出る。
- `.halomap` に書いて読める。
