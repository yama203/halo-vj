# Halo VJ

ライブでのポン出し用の、自分で保守できる macOS 用 VJ ソフト。（ソースコードの中の名前は VJPlayer のまま）

Swift + SwiftUI + Metal + AVFoundation。取り込んでいるもの：Syphon（BSD）、Sparkle（自動アップデート、MIT）。NDI は入っている NDI ランタイムを実行時に読み込む。

## 使い方

| 操作 | 内容 |
|---|---|
| 空きスロットをクリック | そのレイヤーを停止（Arena と同じ。シーンの編集中は、シーンのそのレイヤーを「なし」に） |
| 空きスロットの右上の＋ / 右クリック / 動画をドロップ | クリップを読み込む（HAP の動画も：Hap・Hap Alpha・Hap Q・Hap Q Alpha・Hap R。AVFoundation では読めないので、圧縮されたまま取り出して Snappy をほどき、GPU で絵にする。4K を何枚も重ねても軽い。複数選ぶと右隣に順番に入る。その段の右端まで）。静止画も置ける：PNG・JPEG・HEIC・TIFF・GIF・WebP・PSD（重ねた結果の 1 枚）・PDF と AI（1 ページ目。AI は「PDF 互換ファイルを作成」で保存したもの）・SVG。透明な所は透明のまま。GIF・APNG・WebP のアニメーションは動く（コマの表示時間どおりにくり返す。クリップの速度・コンポジション速度が効く。大きいものはメモリに収まるよう縮めて読む） |
| スロットをクリック（押した瞬間に再生） | 頭から（イン点から）再生。キーボード・MIDI のボタンでも出せる（右クリックの「MIDI・キーで出す（覚える）…」） |
| `Esc` | ブラックアウトの切り替え（クリップは裏で再生を続け、出力の映像と音だけ消える） |
| `⇧Esc` | 全レイヤーを停止 |
| ファイルメニュー「素材をまとめて保存…」 | 選んだ場所に、その名前のフォルダを作り、プロジェクトと「素材」フォルダ（使っている動画・画像のコピー）を入れる。フォルダごと別の Mac へ持っていける（プロジェクトには素材の場所を「素材/名前」で書く）。同じ素材は 1 回だけコピー、別の場所の同じ名前の素材は「名前 2」のように番号を付ける。もう一度同じ所にまとめると、前にコピーした（大きさが同じ）ものは使い回す。見つからない素材は知らせる。コピーは裏で進め、終わったら、まとめた方を開き直す |
| `⌘Z` / `⌘⇧Z` | 元に戻す・やり直す（編集メニューにも）。BPM と見ているデッキは数えない（本番中に動かす値なので）。値・エフェクト・クリップの追加・削除・移動・名前・レイヤー・シーン・キュー・パッドなど、保存される中身すべて。変更が 0.6 秒落ち着いたら 1 歩（ドラッグして動かした値はまとめて 1 歩）。最大 60 歩。段・列・デッキの数が同じなら、クリップは作り直さずに設定だけ戻すので、再生中のクリップは止まらない（段・列を足す・消すのを戻すときは、全体を作り直す）。見ているデッキを変えただけでは歩にならない。文字を打っている間は、その欄の取り消し。プロジェクトを開く・新しく作ると、戻す歩は空になる |
| `⌘R` / 上部の「録画」 | コンポジションの録画を始める／止める（録画中はボタンが赤く点滅し、経過時間が出る） |
| `⌘,` | 設定（ブラックアウトのフェード時間など） |
| 「ライブ」パネルの進行バーをドラッグ | スクラブ（離すとその位置から再生、音声も追従） |
| クリップの名前の帯（サムネイルの下）をドラッグ | 別の枠へ落とすと移動（レイヤーをまたいでも可。`⌘` を押しながらサムネイルのどこからでも同じ）、`⌥` を押しながらだと複製。「キュー」パネルの一覧へ落とすとキューに足す |
| スロットを `⌘` を押しながらドラッグ | クリップを移動（レイヤーをまたいでも可。移動先にクリップがあれば入れ替え。再生中でも止まらない） |
| スロットを `⌥` を押しながらドラッグ | クリップを複製（同じ設定の別クリップ。レイヤーをまたいでも可。複製先にクリップがあれば置き換え。再生中のクリップの上には置けない） |
| スロットを `⇧` を押しながらクリック | クリップを複数選択（もう一度で外す。再生はしない）。選んだクリップの 1 つを `⌘` ドラッグでまとめて移動（並びはそのまま。行き先に別のクリップがあれば動かない）、Delete キーまたは右クリックでまとめて削除、右クリックで別のデッキの同じ場所へ移動。普通のクリックやデッキの切り替えで選択は外れる |
| レイヤー欄の S・重ね方 | S：ソロ。ソロのレイヤーだけが出る（映像と音。いくつでも。ほかは薄く表示。確認用で保存しない）。下の段の「通常」などのボタン：押すと重ね方をその場で選べる（通常以外は紫） |
| レイヤー欄の「L1」をダブルクリック | レイヤーに名前を付ける（右クリック「名前を変える…」でも）。番号 L1 などはそのまま目印に使い、名前はレイヤー欄の下の段とパラメーターパネルのタブに出る（名前が無ければ下の段は再生中のクリップ名）。レイヤーを動かしても名前は付いていく。シーンには入らない。プロジェクトに保存される |
| レイヤー欄を上下にドラッグ | レイヤーの順番を変える（クリップ・再生中のもの・設定ごと動く。右クリックの「上へ移動」「下へ移動」でも）。シーンの中身も一緒に並べ替わる（レイヤーを足す・消すときも） |
| レイヤー欄の右の縦のバー | そのレイヤーの音量（上下ドラッグ、⇧で微調整、ダブルクリックで 100%）。上のスピーカーで音だけミュート |
| サムネイル下の名前の帯をクリック（または `⌥` クリック） | クリップを選択するだけ（出力しない）。クリッププレビューで再生しながら編集できる |
| グリッドのサムネイルの見え方 | 出力と同じ黒地に描く。透明のある素材は右下に市松の印。暗い透明の素材（黒いロゴなど）は灰色の地にして見えるように。大きな透明の中に小さく描かれた素材は、描かれた範囲に寄せて大きく見せる（虫めがねの印）。サムネイルの上にマウスを乗せている間は、市松模様の上に全体を出して透明の範囲を見せる |
| クリップの名前を変える | クリップの右クリック「名前を変える…」、またはパラメーターパネルのクリップタブのいちばん上の「名前」。動画・静止画・ジェネレーターどれにも付けられる（ファイル名やジェネレーターの種類はそのまま）。名前は枠の名前の帯・クリップタブ・再生中の表示・キューに出る。空にする（× ボタン）と元の名前に戻る。複製しても付いていき、プロジェクトに保存される |
| クリップの枠にマウスを乗せる | 上の絵の所：▶（再生中のクリップは ↺ = 頭から出し直す）が出る＝押すと出力に出す。下の名前の帯：帯が明るい灰色になり上に線が出る＝押すと選ぶだけ（出力しない）。選択中の帯は青のまま少し明るくなる |
| 下のパラメーターパネル | どのタブも「トランスフォーム」に位置・スケール・角度・不透明度をまとめる（位置は小さな画面の上の点、スケールは画面の枠とクリップの四角、角度は文字盤で、今の状態が値の左に絵で出る）。コンポジション（マスター：音量・速度）／レイヤー（ミックス：調整レイヤー・重ね方・音量・切り替えフェード）／クリップ（音・再生：音量・速度、再生範囲＝イン点・アウト点、終わったら＝ループ／往復（アウト点で逆再生、イン点で順再生に戻る）／最後で停止／ブラックアウト）。それぞれプレビュー付き。値はドラッグで調整、ダブルクリック／右クリックで初期値。パネルを細くすると 1 列に並び替わり、タブ名は短く（コンポ／L1／クリップ）、イン点・アウト点は 2 段、「終わったら」はアイコンだけ、ジャンプのボタンは 2 段になる（横スクロールなしで使える） |
| 左端のレイヤー欄 | 不透明度、停止、重ね方・再生中のクリップ名の表示。クリックで下のレイヤータブの対象に |
| 数値欄の色 | 初期値から変えた値は橙。プラスにもマイナスにもなる値（位置・角度・速さ・傾きなど）は、プラスが橙・マイナスが水色で、欄の下に 0 の所から今の値まで細い線が出る（どちら向きにどれだけか） |
| 数値欄の右の波形ボタン | 動かし方（アニメーション）：固定／秒（1周の秒数）／BPM（1周の拍数）／音（下の「音の入力」）。動き方は 順・逆・往復・ランダム、範囲（から・まで）を決める。位置・スケール・角度・不透明度（クリップ・レイヤー・コンポジション）とマスター不透明度に付けられる。動かしている間、欄は今の値を表示し続ける |
| 上部の「音の入力」と、動かし方「音」 | 音に反応させる。音は、アプリの音（クリップの音。マスター音量・ミュートに関係なく届く）か、入力デバイス（マイク・ライン入力。DJ ミキサーやほかのアプリの音は、ライン入力や BlackHole などの仮想デバイスで入れる。はじめてのときマイクの使用の許可を聞かれる）。音を 音量・低音（〜150 Hz）・中音（150〜2500 Hz）・高音（2500 Hz〜）・アタック（低音が急に大きくなった瞬間＝キックの頭に 1 になって、すっと戻る）の 5 つに分けて、自動で合わせる（最近いちばん大きかった音を 100% に。入力の音量に関係なく動く）。音が止んだときに戻る速さ。ボタンの横と設定の中に今の値の棒が出る。どの数値も、波形ボタンで動かし方を「音」にすると、選んだ部分 × 感度で「から」〜「まで」の間を動く（逆：大きいほど「から」へ）。エフェクト・ジェネレーターの値、位置・スケール・角度・不透明度、重ね方の値などすべて。音の入力の設定は Mac ごとで、プロジェクトには入らない（動かし方は入る） |
| BPM の欄の「自動」 | 音（上部の「音の入力」で選んだ音）から BPM と拍の頭を合わせ続ける。立ち上がりの強さ（低音と全体）を 1 秒に約 190 回取り、最近 8 秒のくり返し（自己相関）から BPM、その長さごとに足していちばん強くなる位置から拍の頭を求める。1 秒ごとに見て、3 回続けて 2% 以内なら合わせる（緑の数字＝合っている）。少しの違い（0.4 BPM・30 ms 未満）は動かさない。78〜160 BPM の間で探す（それより速い曲は半分で取る。DnB の 174 は 87）。自動で変わった BPM は保存・元に戻すには数えない。タップ・「頭」はいつでも使える |
| 上部の「連携」：Syphon | **出す**：コンポジション（四隅の調整の前・パッドのエフェクト込み）を Syphon で公開する（名前は変えられる。はじめは「Halo VJ」）。TouchDesigner では Syphon Spout In TOP で受け取る。出力・コンポジションの画面と同じ大きさ（画面が無ければ 1920×1080 か、決めた解像度）。受け取られているかが出る。**受け取る**：ジェネレーター「Syphon から」（分類「ほかのアプリから」）を枠に置き、クリップタブの「映像」で、公開されている映像を選ぶ（アプリ名とサーバー名で覚える。いなくなっても、また公開されれば続きから出る）。合わせ方（収める・いっぱいに・引き伸ばす）・濃さ。透明はそのまま。自分の出力は一覧に出さない |
| 上部の「連携」：NDI | **出す**：コンポジション（Syphon と同じもの）を NDI で出す（名前は変えられる。はじめは「Halo VJ」）。同じネットワークの別の Mac・PC で受け取れる（TouchDesigner の NDI In TOP・Resolume・OBS など）。不透明（BGRX）・60 コマ/秒の扱いで、前の 1 枚を送り終わっていなければ飛ばす。何か所で受け取られているかが出る。**受け取る**：ジェネレーター「NDI から」（分類「ほかのアプリ・カメラから」）を枠に置き、クリップタブの「映像」で、見つかった送り手を選ぶ（2 秒ごとに探し直す。名前で覚える）。合わせ方・濃さ。透明はそのまま（BGRA のとき）。自分の出力は一覧に出さない。NDI の本体（libndi）は起動中に読み込む。探す順：アプリに同梱したもの（`Contents/Frameworks`）→ NDI ランタイム・NDI SDK・Resolume などに入っているもの。`tools/make_app.sh` は、NDI SDK for Apple（ndi.video から落として使用許諾に同意したもの。`/Library/NDI SDK for Apple` か、`NDI_SDK_DIR` で場所を指定）があれば、libndi とライセンス文書（`Contents/Resources/NDI`）を同梱する。無ければ同梱しない（ほかのアプリの libndi はコピーしない）。どの NDI を使っているかは「連携」の NDI の欄に出る。見つからなければそう出る（ndi.video から NDI Tools を入れる）。NDI を使う所と About の窓に「NDI® is a registered trademark of Vizrt NDI AB」と ndi.video へのリンク |
| ジェネレーター「音の形」 | 音（上部の「音の入力」）の、周波数ごとの大きさ（スペクトラム。30 Hz〜16 kHz を耳に近い間隔で 128 の帯に）と波形を、そのまま絵にする（分類「線・模様」）。形：棒・線（なめらかな曲線）・波形・円（棒）・円（波形）。帯の数・高さ・太さ・色の付け方（1 色・虹色・パレット（高さで））・上下対称・なめらかさ（下がるときゆっくり）・明るさ・円の大きさ。自動で合わせるなら、最近いちばん大きかった所を 100% に。まわりは透明 |
| ジェネレーター「カメラから」 | Web カメラ・HDMI キャプチャ・iPhone（連係カメラ）の映像を、クリップとして置く（分類「ほかのアプリ・カメラから」）。クリップタブの「カメラ」で機器を選ぶ（抜き差しすると一覧が変わる）。はじめはカメラの使用の許可を聞く。合わせ方（収める・いっぱいに・引き伸ばす）・左右反転（鏡）・濃さ。同じカメラを何枚の枠に置いても 1 回だけ開き、10 秒使わなければ閉じる |
| 上部の「連携」：OSC | **受け取る**（ポートはじめ 9000）：iPad（TouchOSC など）・TouchDesigner から操作する。送り先に入れる この Mac の IP アドレスが出る。届いたメッセージの最近 6 つが出る。決まったアドレス（番号は 1 から）：`/halo/layer/L/clip/C`（クリップを出す）・`/halo/column/C`・`/halo/layer/L/stop`・`/halo/layer/L/opacity 0〜1`・`/halo/stop`・`/halo/master/opacity`・`/halo/master/volume`・`/halo/blackout [0/1]`・`/halo/bpm 数`・`/halo/tap`・`/halo/resync`・`/halo/pad/N 1/0`（押す・離す）・`/halo/cue/next`・`/halo/cue/back`・`/halo/cue/N`・`/halo/scene/N`・`/halo/deck/N`・`/halo/record [0/1]`。ボタンの 0（離した）は、出す・止める などをしない。**どの値も OSC で**：波形ボタンで動かし方を「OSC」にしてアドレスを入れるか「覚える」を押してフェーダーを動かすと、その値（0〜1）で「から」〜「まで」を動く（逆もできる。まだ届いていなければ元の値のまま）。**送る**（送り先はじめ 127.0.0.1:7000）：1 秒に 30 回 `/halo/bpm`・`/halo/beat`（拍の数）・`/halo/beat/phase`・`/halo/bar/phase`（0〜1）・`/halo/audio/level`・`low`・`mid`・`high`・`attack`、クリップを出したとき `/halo/layer/L/clip`（名前）。TouchDesigner では OSC In CHOP で受け取る。設定は Mac ごと（プロジェクトには入らない。動かし方は入る） |
| 上部の「連携」：MIDI コントローラー・キー | つないだ MIDI の機器は全部自動で聞く（抜き差しも追う）。**ボタン**：クリップ・FX パッドの右クリック「MIDI・キーで出す／押す（覚える）…」を押してから、コントローラーのボタン（ノート・CC）かキーボードのキーを押すと割り当たる（Esc でやめる。画面の上に案内が出る）。クリップは「段・列」で覚える（デッキを変えると、そのデッキの同じ場所）。パッドは押している間だけ効く。キューを次へ・戻す・ブラックアウト・タップ・今を 1 拍目に・全部止める・録画は「連携」の「操作を選ぶ」から。同じボタンに覚えさせ直すと前の割り当ては外れる。割り当てたボタンの名前がクリップ・一覧に出る（× で外す）。ノートで割り当てたクリップ・パッド・ブラックアウト・録画は、今の状態をコントローラーのボタンの光で返す（出しているクリップが光る）。**つまみ・フェーダー**：値の波形ボタンで動かし方を「OSC・MIDI」にして「覚える」を押し、つまみを回すと、その値で動く（アドレスは /midi/チャンネル/cc/番号）。割り当ては Mac ごと |
| クリップタブの「再生範囲」 | バーの両端をドラッグしてイン点・アウト点を決める（ダブルクリックで端に戻す）。バーの後ろにクリップのコマが並び、使わない所は暗くなる。上に「最初のコマ」（イン点）と「最後のコマ」（アウト点の直前、最後に映るコマ）が出るので、黒などが残っていないか見ながら決められる。イン・アウトの横の ◀ ▶ で 1 コマずつ（⇧で 10 コマずつ）動かせる。長さはコマ数でも出る |
| クリップタブの「速度：手動 / BPM 同期」 | BPM 同期にすると、再生範囲（イン点〜アウト点）を決めた拍数でちょうど 1 周する速さで再生（音も同じ速さ）。BPM・タップに付いていく。クリップ速度・コンポジション速度は効かない。速さは 0.05〜8x の範囲 |

| 上部の「録画」（`⌘R`）と右の ▾ | コンポジションを動画ファイルに録る。録るのは合成した絵（四隅の調整の前・パッドのエフェクト込み。ブラックアウトは入らない）と、クリップの音（音声ミキサーの出口。マスター音量・ミュートの手前）。画面が隠れていても録れる。▾ で設定：形式（H.264・HEVC・ProRes 422・ProRes 422 HQ）・大きさ（出力と同じ・720p〜4K。縦横比は出力）・フレームレート（24〜60 fps。決めた回数のコマ番号で時刻を付けるので、描画が遅れてもコマが飛ぶだけで時間はずれない）・音も録るか・保存先（はじめは ムービー/Halo VJ 録画。ファイル名は日時）。止めると「保存しました」と Finder で表示が出る。設定は Mac ごとで、プロジェクトには入らない |
| 上部の「音声」 | 音声の出力先（ヘッドホンなど） |
| 「四隅」 | プレビュー上の黄色い点をドラッグしてコーナーピン調整 |
| 「テスト」 | テストパターンを出力（四隅合わせ用） |

グリッドの1段が1レイヤー（最初は 4 段 × 8 列。レイヤーは 16 段、列は 64 列まで増やせる。入りきらなければスクロール）。
段ごとに1クリップずつ同時に再生でき、上の段ほど手前に重なる。同じ段の別クリップを再生すると、その段のクリップだけが切り替わる。
レイヤーや列を途中に足したり消したりしても、再生中のクリップは止まらない（消した段・列のクリップだけ止まって外れる）。

設定とスロットの中身は `~/Library/Application Support/Halo VJ/state.json`（以前の VJPlayer フォルダは初回起動時に引き継ぐ） に自動保存される。

### プロジェクトファイル（.halovj。以前の .vjproj も開ける）
「ファイル」メニューの 新規（⌘N）／開く…（⌘O）／最近使ったプロジェクト／保存（⌘S）／別名で保存…（⇧⌘S）。
グリッド・クリップ（範囲・速度・エフェクト・動き・ミュート）・レイヤー・コンポジション・BPM・四隅が入る。出力先・音声の出力先・ブラックアウトのフェード時間は Mac ごとの設定なので入らない。
プロジェクトファイルと同じフォルダ（またはその下）の動画は、そこからの場所でも記録するので、フォルダごと動かしても開ける。
動画が見つからないときは「見つかりません」のクリップとして設定ごと置かれ、フォルダを選ぶと同じ名前のファイルを探して付け直す（「見つからない動画を探す…」、またはクリップを右クリック →「動画ファイルを付け直す…」）。
Finder ではプロジェクトファイルに専用のアイコンが付き、ダブルクリックで Halo VJ が開く。
自動保存はそのまま続くので、次に起動したときは前回の状態（開いていたプロジェクトも）から始まる。

## インストール・アップデート

- [Releases](https://github.com/yama203/halo-vj/releases) から `Halo-VJ-x.y.z.zip` を落として開き、「Halo VJ」をアプリケーションに入れる。Apple シリコンの Mac・macOS 14 以上。
- Apple の公証を通していないので、初めて開くときは止められる。システム設定 → プライバシーとセキュリティ →「このまま開く」で一度許可する。
- そのあとは、アプリが自分で新しい版を確かめる（1 日 1 回。アプリのメニュー「アップデートを確認…」でも）。起動したときに見つけたら窓が出る。動いている途中に見つけたら、上部に「新しい版」の小さなボタンが出るだけ（本番中に急に窓は出ない）。押すと変更点を見て、入れるか決められる。入れると入れ替えて開き直す。設定の「アップデート」で、自動で確かめるかを切り替えられる。
- 中身は Sparkle が、公開鍵（Info.plist の SUPublicEDKey）で署名を確かめてから入れる。

## リリースの作り方

```bash
tools/release.sh 0.2.0 --dry-run   # build/release に zip と appcast.xml を作るだけ
tools/release.sh 0.2.0             # タグ v0.2.0 を付けて push し、GitHub Releases に zip と appcast.xml を置く
```

- 先にコミットしておく（変更が残っているとやめる）。変更点は前のタグからのコミットの題名（`HALO_NOTES=ファイル` で書いたものにできる）。
- 版の番号は `CFBundleShortVersionString`、ビルド番号はコミットの数（Sparkle はビルド番号で新しいかを比べる）。
- アプリは `https://github.com/yama203/halo-vj/releases/latest/download/appcast.xml` を見る。いちばん新しい Release に appcast.xml があればよい（リポジトリは公開にしておく）。
- 署名の秘密鍵：ログインキーチェーン（Sparkle の `generate_keys` で作ったもの）と、その書き出し `~/.halo-vj/sparkle_ed25519`。**無くすと、今入っているアプリに新しい版を届けられなくなる**ので、どこか安全な所にも控えておく。リポジトリには入れない。
- NDI SDK for Apple が入っていれば、libndi も同梱される（「映像（NDI）」の行を参照）。

## 構成

- `ClipSlot.swift` … 1クリップの再生。自前の再生時計（速度を変えても位置が連続）で映像と音声を同じ時刻から動かす
- `FrameStream.swift` … 映像の先読みデコード（AVAssetReader）。先頭からデコード済みの待機ストリームを差し替えてポン出しする。逆再生は後ろから数コマずつ読んで逆順に渡す
- `AudioOutput.swift` … AVAudioEngine。音声はタイムストレッチ（AVAudioUnitTimePitch）で速度変更しても音程維持。PCM を ~/Library/Caches/Halo VJ/audio にキャッシュ（往復モードの逆再生用に、区間を逆順にしたファイルも作る）
- `Engine.swift` … スロット・レイヤー管理、フレーム取得、コーナーピン、保存
- `Inspector.swift` … パラメーターパネル（コンポジション／レイヤー／クリップ）と、数値をドラッグで変えるフィールド
- `PreviewPlayer.swift` … 出力せずにクリップをプレビュー再生（音なし）
- `Layer.swift` … レイヤーの設定（重ね方・不透明度・音量・切り替えフェード）、フェード計算
- `SettingsView.swift` … 設定ウィンドウ（⌘,）
- `Effects.swift` … エフェクトの種類と値（足すときは `EffectKind` に追加し、シェーダー `feffect` に処理を書く。一覧には自動で並ぶ）。`EffectBrowser.swift` … エフェクト一覧とドラッグ＆ドロップ。処理は `Metal.swift` の `feffect` シェーダーと `EffectProcessor`（クリップ → レイヤー → コンポジションの順）
- `Animation.swift` / `AnimationViews.swift` … パラメーターのアニメーション（時刻から値を計算するので描画スレッドで毎フレーム求める）、BPM の時計とタップテンポ、その UI
- 描画は専用スレッド（CVDisplayLink）で vsync ごとに行う。画面操作でメインスレッドが重くても出力は止まらない
- `Metal.swift` … 描画。レイヤーを合成（Compositor）→ 合成した画に射影変換でコーナーピン、テストパターン
- `Output.swift` … 出力ウィンドウ
- `SpeedControl.swift` … 速度コントロール
- `Views.swift` / `App.swift` … 画面・キーボード操作
- `tools/make_icon.swift` … アプリとプロジェクトファイルのアイコンを描く（作り直すときは `Resources/*.icns` を消してから `tools/make_app.sh`）
- `Project.swift` … プロジェクトファイルのメニュー操作（開く・保存・見つからない動画）
- `Sources/ObjCSupport` … AVFoundation の例外を Swift からつかまえるための小さな補助（音声の再生開始で落ちないように）
