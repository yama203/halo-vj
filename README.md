# Halo VJ

ライブでのポン出し用の、自分で保守できる macOS 用 VJ ソフト。（ソースコードの中の名前は VJPlayer のまま）

Swift + SwiftUI + Metal + AVFoundation（外部ライブラリなし）。

## 使い方

| 操作 | 内容 |
|---|---|
| 空きスロットをクリック / 動画をドロップ | クリップを読み込む（複数選ぶと右隣に順番に入る。その段の右端まで） |
| スロットをクリック（押した瞬間に再生） | 頭から（イン点から）再生。キーボードの割り当ては今はなし（あとで手動で割り当てられるようにする予定） |
| `Esc` | ブラックアウトの切り替え（クリップは裏で再生を続け、出力の映像と音だけ消える） |
| `⇧Esc` | 全レイヤーを停止 |
| `⌘,` | 設定（ブラックアウトのフェード時間など） |
| 右下の進行バーをドラッグ | スクラブ（離すとその位置から再生、音声も追従） |
| スロットを `⌘` を押しながらドラッグ | クリップを移動（レイヤーをまたいでも可。移動先にクリップがあれば入れ替え。再生中でも止まらない） |
| スロットを `⌥` を押しながらドラッグ | クリップを複製（同じ設定の別クリップ。レイヤーをまたいでも可。複製先にクリップがあれば置き換え。再生中のクリップの上には置けない） |
| サムネイル下の名前の帯をクリック（または `⌥` クリック） | クリップを選択するだけ（出力しない）。クリッププレビューで再生しながら編集できる |
| 下のパラメーターパネル | コンポジション（マスター不透明度・音量・速度・トランスフォーム）／レイヤー（重ね方・不透明度・音量・切り替えフェード・トランスフォーム）／クリップ（位置・スケール・角度・不透明度・音量・速度、再生範囲＝イン点・アウト点、終わったら＝ループ／往復（アウト点で逆再生、イン点で順再生に戻る）／最後で停止／ブラックアウト）。それぞれプレビュー付き。値はドラッグで調整、ダブルクリック／右クリックで初期値 |
| 左端のレイヤー欄 | 不透明度、停止、重ね方・再生中のクリップ名の表示。クリックで下のレイヤータブの対象に |
| 数値欄の右の波形ボタン | 動かし方（アニメーション）：固定／秒（1周の秒数）／BPM（1周の拍数）。動き方は 順・逆・往復・ランダム、範囲（から・まで）を決める。位置・スケール・角度・不透明度（クリップ・レイヤー・コンポジション）とマスター不透明度に付けられる。動かしている間、欄は今の値を表示し続ける |
| クリップタブの「速度：手動 / BPM 同期」 | BPM 同期にすると、再生範囲（イン点〜アウト点）を決めた拍数でちょうど 1 周する速さで再生（音も同じ速さ）。BPM・タップに付いていく。クリップ速度・コンポジション速度は効かない。速さは 0.05〜8x の範囲 |
| クリップタブの「ジャンプ」 | 決めた拍ごと（1/4〜16拍）に、BPM の拍の頭で再生範囲の中のランダムな位置へ飛ぶ（音も一緒に。飛び先は先読みしておくので拍ちょうどで切り替わる） |
| 右下「エフェクト」タブ | エフェクトの一覧（色・形・時間に分類、検索あり）。付けたい所へドラッグ：クリップのサムネイル → クリップ、レイヤー欄 → レイヤー、出力モニター → コンポジション、パラメーターパネルのエフェクト欄 → そのタブ。ダブルクリックで今開いているタブに付く。今あるのはミラー／カラーライズ／レベル／ポスタライズ（色の段数・ディザ・ドット）／ポスタライズ時間（コマを間引くフレームレート）／ストロボ／エコー（残像）／マスク（形）／マスク（自由な形） |
| ジェネレーター（エフェクト一覧のいちばん上） | 動画の代わりにクリップとして置く絵：単色・グラデーション（パレット・直線／円／回転）・ストライプ・チェッカー／格子／ドット・ノイズ（なめらか／砂嵐）・図形（円・リング・四角・枠・三角、並べられる）。クリップの枠へドラッグ、ダブルクリックで選択中のレイヤーの空きへ、空きスロットの右クリックからも置ける。設定はクリップタブ（値は秒・BPM で動かせる）。すき間・まわりは透明。保存される |
| マスク | マスク（形）：四角・丸で切り抜く（位置・大きさ・角度・ぼかし・反転）。マスク（自由な形）：カードの「形を編集」で、左のプレビューの上でクリック＝点を追加、ドラッグ＝移動、中をドラッグ＝形ごと移動、右クリック＝削除。重ね方「マスク（白で見せる／白で隠す）」：そのレイヤーの明るさで下のレイヤー全部を切り抜く（そのレイヤー自体は見えない。単色・図形のジェネレーターと組み合わせると便利） |
| パラメーターパネルのエフェクト欄 | 付いているエフェクト。上から順にかかる。オン/オフ・並べ替え・削除・値の調整。数値には波形ボタンで秒・BPM の動きを付けられる。カラーライズは Resolume と同じく「カラー（色 1 つ・明るさを保つ／保たない）」と「パレット（明るさをパレットの色に置き換え、ひな形あり）」、色相をずらす |
| ミュート（目のボタン） | 再生は続けたまま、映像と音を出さない（もう一度押すと戻る）。レイヤー欄・レイヤータブ → そのレイヤー、クリップタブ・サムネイルの右クリック → そのクリップ（サムネイルに赤い印）、出力モニターの上・コンポジションタブ → 出力全体（フェードなしですぐ消える）。保存される |
| 音量の欄の横のスピーカーボタン | 音だけを消す（映像はそのまま）。クリップ・レイヤー・マスターそれぞれ。消している間は赤。保存される |
| px の値（にじみ・波紋の広がり、ドット） | 1080p の出力での大きさ。プレビューやほかの解像度では絵の大きさに比例させるので、どこで見ても同じ見え方 |
| 重ね方「オーバードライブ加算」 | 下のレイヤーに加算して 100% を超えた分（あふれ）を、にじみ（ハレーション）・色相ずれ・波紋（あふれた所から同心円の波が外へ広がる。強さ・細かさ・速さ・広がり）・白飛びの抑えに変える特殊合成。値はレイヤータブに出る（秒・BPM で動かせる）。下の絵を読んでシェーダーで混ぜる仕組みなので、同じ形で特殊合成を増やせる |
| 「調整レイヤーを追加」 | 一番上に調整レイヤーを足す。そこに付けたエフェクトが、下のレイヤーを重ねた絵全体にかかる（上のレイヤーにはかからない）。不透明度がかかり具合。レイヤー欄の右クリックやレイヤータブのスイッチでも切り替えられる |
| グリッド上の「デッキ」タブ | グリッドを何枚も持てる（Resolume のデッキのようなもの）。タブのクリックで表示するデッキを切り替える（再生中のクリップはそのまま続く。別のデッキのクリップを再生中のレイヤーには橙のマーク）。＋で空のデッキ、右クリックで名前・複製・削除。シーンは保存したときのデッキを覚えていて、呼び出すとそのデッキの表示になる（シーンの右クリック「デッキ」で変えられる）。同じデッキを何個のシーンで使ってもよい |
| 右下「シーン」タブ | お気に入りの組み合わせを保存して切り替える。「今の状態をシーンに保存」で、再生中のクリップ（レイヤーごとの列）とレイヤー・コンポジションの設定（不透明度・重ね方・位置・エフェクト・ミュートなど）を出力のサムネイル付きで保存。サムネイルの絵をクリックでそのシーンへ。下の名前の帯をクリックすると、出力はそのままでそのシーンの編集になる（グリッドの上に橙の帯）。編集中はグリッド・レイヤー欄・下のパネルがそのシーンの中身になり、クリップを押すとシーンで流すクリップになる（出力中のクリップには「出力中」の印）。不透明度・エフェクトなども同じ操作で直せて、左下のプレビューにシーンの絵が出る。変えるとすぐシーンに入り、サムネイルも撮り直す。クリップ自体の設定は全シーン共通。「編集を終える」または名前の帯をもう一度クリックで戻る。フェード時間（すぐ〜8秒）はシーンごとで、クリップはクロスフェード、不透明度・位置・エフェクトの値はなめらかに動き、混ぜられないもの（重ね方・違う種類のエフェクト）は途中で切り替わる。同じクリップは頭から出し直さない。右クリックで上書き・名前・フェード時間・削除。「空のシーン」で何も流さないシーンを足してすぐ編集できる。右上の「大／中／小／最小」でシーンの大きさ（1 行の数）を変えられる。プロジェクトに保存される（グリッドの中身は共通。シーンは「どの列を再生するか」を持つので、クリップを動かすとその場所のクリップが出る） |
| 右下「テンポ」 | BPM（ドラッグで変更）、TAP（拍に合わせて何回か押す。押した瞬間が拍の頭になる）、頭（今を 1 拍目に）、拍の表示 |
| 下の速度コントロールを左右ドラッグ | コンポジション速度（再生中の全クリップに掛かる。Shift で微調整）。クリップ自体の速度はクリップタブで |
| 速度コントロールを右クリック / ダブルクリック | 1.000x に戻す |
| スロットを右クリック | 終わったときの動き・差し替え・削除 |
| 「レイヤーを追加」 / 列番号の右の `＋` | 一番下にレイヤー、右端に列を足す |
| レイヤー欄・列番号を右クリック | 上下（左右）に足す・削除（クリップが入っていれば確認） |
| 上部の「出力」 | 出力先ディスプレイ（またはテスト用ウィンドウ） |
| 上部の「音声」 | 音声の出力先（ヘッドホンなど） |
| 「四隅」 | プレビュー上の黄色い点をドラッグしてコーナーピン調整 |
| 「テスト」 | テストパターンを出力（四隅合わせ用） |

グリッドの1段が1レイヤー（最初は 4 段 × 8 列。レイヤーは 16 段、列は 64 列まで増やせる。入りきらなければスクロール）。
段ごとに1クリップずつ同時に再生でき、上の段ほど手前に重なる。同じ段の別クリップを再生すると、その段のクリップだけが切り替わる。
レイヤーや列を途中に足したり消したりしても、再生中のクリップは止まらない（消した段・列のクリップだけ止まって外れる）。

設定とスロットの中身は `~/Library/Application Support/Halo VJ/state.json`（以前の VJPlayer フォルダは初回起動時に引き継ぐ） に自動保存される。

### プロジェクトファイル（.halovj。以前の .vjproj も開ける）
「ファイル」メニューの 新規（⌘N）／開く…（⌘O）／最近使ったプロジェクト／保存（⌘S）／別名で保存…（⇧⌘S）。
グリッド・クリップ（範囲・速度・エフェクト・動き・ミュート）・レイヤー・コンポジション・BPM・四隅が入る。出力先・音声の出力先・ブラックアウトのフェード時間は Mac ごとの設定なので入らない。
プロジェクトファイルと同じフォルダ（またはその下）の動画は、そこからの場所でも記録するので、フォルダごと動かしても開ける。
動画が見つからないときは「見つかりません」のクリップとして設定ごと置かれ、フォルダを選ぶと同じ名前のファイルを探して付け直す（「見つからない動画を探す…」、またはクリップを右クリック →「動画ファイルを付け直す…」）。
Finder ではプロジェクトファイルに専用のアイコンが付き、ダブルクリックで Halo VJ が開く。
自動保存はそのまま続くので、次に起動したときは前回の状態（開いていたプロジェクトも）から始まる。

## ビルド

```bash
./tools/make_app.sh        # build/Halo VJ.app を作成
swift run                  # 開発中の起動
```

## 再生エンジンのセルフテスト

画面を出さずに、ポン出しの遅延・速度変更・切り替えを検証する（音量 0）。

```bash
.build/debug/VJPlayer --selftest a.mov b.mov
.build/debug/VJPlayer --od-preview out.png 0.8 40 80 0.8 24 0.4 1.5 300   # オーバードライブ加算の見え方を 1 枚書き出す（値はレイヤータブの並び）
```

## 素材の変換（DXV → ProRes）

```bash
tools/convert_to_prores.sh clip1.mov clip2.mov          # ProRes 422
PROFILE=1 tools/convert_to_prores.sh clip1.mov          # ProRes 422 LT（軽量）
```

## 構成

- `ClipSlot.swift` … 1クリップの再生。自前の再生時計（速度を変えても位置が連続）で映像と音声を同じ時刻から動かす
- `FrameStream.swift` … 映像の先読みデコード（AVAssetReader）。先頭からデコード済みの待機ストリームを差し替えてポン出しする。逆再生は後ろから数コマずつ読んで逆順に渡す
- `AudioOutput.swift` … AVAudioEngine。音声はタイムストレッチ（AVAudioUnitTimePitch）で速度変更しても音程維持。PCM を ~/Library/Caches/Halo VJ/audio にキャッシュ（往復モードの逆再生用に、区間を逆順にしたファイルも作る）
- `Engine.swift` … スロット・レイヤー管理、フレーム取得、コーナーピン、保存
- `Inspector.swift` … パラメーターパネル（コンポジション／レイヤー／クリップ）と、数値をドラッグで変えるフィールド
- `PreviewPlayer.swift` … 出力せずにクリップをプレビュー再生（音なし）
- `Layer.swift` … レイヤーの設定（重ね方・不透明度・音量・切り替えフェード）、フェード計算
- `SettingsView.swift` … 設定ウィンドウ（⌘,）
- `Effects.swift` … エフェクトの種類と値（足すときは `EffectKind` に追加し、シェーダー `feffect` に処理を書く。一覧には自動で並ぶ）。`EffectBrowser.swift` … エフェクト一覧とドラッグ＆ドロップ。処理は `Metal.swift` の `feffect` シェーダーと `EffectProcessor`（クリップ → レイヤー → コンポジションの順）
- `Animation.swift` / `AnimationViews.swift` … パラメーターのアニメーション（時刻から値を計算するので描画スレッドで毎フレーム求める）、BPM の時計とタップテンポ、その UI
- 描画は専用スレッド（CVDisplayLink）で vsync ごとに行う。画面操作でメインスレッドが重くても出力は止まらない
- `Metal.swift` … 描画。レイヤーを合成（Compositor）→ 合成した画に射影変換でコーナーピン、テストパターン
- `Output.swift` … 出力ウィンドウ
- `SpeedControl.swift` … 速度コントロール
- `Views.swift` / `App.swift` … 画面・キーボード操作
- `tools/make_icon.swift` … アプリとプロジェクトファイルのアイコンを描く（作り直すときは `Resources/*.icns` を消してから `tools/make_app.sh`）
- `Project.swift` … プロジェクトファイルのメニュー操作（開く・保存・見つからない動画）
- `Sources/ObjCSupport` … AVFoundation の例外を Swift からつかまえるための小さな補助（音声の再生開始で落ちないように）
