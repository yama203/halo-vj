# Decks and Grid Display

“Decks”, which let you have several grids, and the display size of the grid.

## Decks

With the “Deck” tabs above the grid, you can have several grids (like decks in Resolume).

- Click a tab to switch the displayed deck. Playing clips keep playing.
- Layers playing a clip from another deck show an orange mark.
- “＋” adds an empty deck.
- Right-click to rename, duplicate or delete.

### Scenes and decks

- A scene remembers the deck it was saved with and switches to that deck when recalled (change it with “Deck” in the scene's right-click menu).
- The same deck can be used by any number of scenes.

## Display size (L / M / S)

Use “L / M / S” to the right of the deck tabs to change the display size of the grid.

- L: full width.
- M and S: small slots to show many clips (for small screens such as a MacBook).
- S also narrows the layer column and omits its lower line (blend mode and name).
