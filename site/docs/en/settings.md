# Settings

The contents of the settings window (`⌘,`). It holds values to set before a show.

## Output resolution and frame rate

Same as “Resolution / fps” at the top. → [Output, Resolution and Corner Pin](output.md)

## Blackout

Sets the fade time for the `Esc` blackout (0–5 seconds).

- Fade to black
- Fade back on release

Applies to both video and audio. Pressing again during a fade reverses from the current point.

The blackout fade time is a per-Mac setting and is not saved in the project.

## Display

### Language

- Same as Mac
- 日本語 (Japanese)
- English

Takes effect the next time the app opens. “Relaunch Now” relaunches immediately.

On a Mac set to English, the interface text appears in English (where translated; untranslated parts remain in Japanese).

### Flash indicators

- “Flash the edge briefly when the parameter panel switches”: flashes orange for the composition, blue for a layer and green for a clip, and shows what it switched to at the top right.
- “Flash the output monitor briefly when the output changes”: flashes green for a clip, purple for a scene and gray when stopped, and shows what changed at the top left (changes made by the autopilot show an airplane mark).

→ [Interface Overview](interface.md)
