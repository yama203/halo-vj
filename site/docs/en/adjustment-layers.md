# Adjustment Layers

Adjustment layers, which apply effects to the combined image of the layers below, and the “Effect Clips” placed in their slots.

## Adding an adjustment layer

“Add Adjustment Layer” adds an adjustment layer at the top.

- Effects added to it apply to the combined image of the layers below (not to layers above).
- Opacity sets how strongly it applies.
- You can also switch a layer to or from an adjustment layer by right-clicking the layer column or with the switch in the layer tab.
- An adjustment layer replaces the image below with the image passed through its effects (by the opacity ratio).

## Effect clips

The row of an adjustment layer has normal slots. Place an “Effect Clip” (a set of effects) in a slot, and clicking it applies those effects to all layers below.

- Switch with another slot in the same row; click an empty slot to remove it.
- Opacity sets how strongly it applies.
- Effects added to the layer itself always apply along with it.
- Scenes, cues, duplicating and saving work the same as for normal clips.

### Creating

- Click the “＋” at the top right of an empty slot, or right-click it (“Make Effect Clip With…”).
- Drag from the effect list to an empty slot.

### Editing

- Drag an effect onto a filled slot to add the effect.
- Click the name strip to edit the name and effects in the parameter panel.
