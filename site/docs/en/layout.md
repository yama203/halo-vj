# Workspaces and Panels

How to change the screen arrangement (dragging dividers, separate windows, workspaces, saving layouts), and how to close panels.

## Resizing

Drag a divider to resize. Double-click it for an automatic size.

- Between the grid and the output monitor
- Between the top and bottom
- Between the parameters and the bottom-right panel

## Separate windows

The bottom-right tabs, the output monitor, and the FX pads can be moved to a separate window with the ⧉ button (for the FX pads, right-click the header).

- A separate window can be set to “Always on Top”.
- Close it, or use “Return”, to put it back in the main window.

## Workspaces

The workspace selector in the top bar switches the screen arrangement.

- Standard: the usual arrangement.
- Show: for clip triggering.
- VJ: large FX pads.
- Ones you have saved.

When you switch, changes made in the current workspace are remembered (you get that arrangement when you come back). The first time you switch, the arrangement up to then is kept as “Previous Layout”.

From the selector you can:

- Save as a new workspace.
- Set the current layout as this workspace's default.
- Reset to the default (the default you set, or the app's original if there is none).
- Reset to the app's original (Standard, Show, VJ; your own default is also removed).
- Delete (your own workspaces).

## Saving layouts

With “Layout” in the menu, you can save the current arrangement (including separate window positions) under a name, switch to it, and delete it. Arrangements are kept in the app settings.

## Closing panels

Panels you don't use can be closed so they are not shown anywhere.

- To close: the × at the top right of the panel. In Free Layout, the × on the tab or the right-click menu. For the FX pads, right-click “FX” on the left.
- To restore: use the “Panels” mark in the top bar (it shows how many are closed), or check ✓ in “Layout” in the menu; the panel returns to its original place.
- In the usual arrangement, the panels that can be closed are the bottom-right tabs (Live, Scenes, Cues, Effects, Generators, Sources), the FX pads, and the output monitor.
- In Free Layout, any panel can be closed (except the last one).
- Closing a panel in a separate window also closes the window.
- Remembered per workspace.
