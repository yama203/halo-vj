# Keyboard Shortcuts

Halo VJ key commands and mouse actions with modifier keys.

## General

| Key | Action |
|---|---|
| `Esc` | Toggle blackout |
| `⇧Esc` | Stop all layers |
| `⌘Z` | Undo |
| `⌘⇧Z` | Redo |
| `⌘R` | Start / stop recording |
| `⌘,` | Settings |
| `⌘E` | Search window for effects and generators |
| `⌘⇧M` | Output mapping |

## File

| Key | Action |
|---|---|
| `⌘N` | New |
| `⌘O` | Open… |
| `⌘S` | Save |
| `⇧⌘S` | Save As… |

## Cues

| Key | Action |
|---|---|
| `Space` | Go (does nothing if there are no cues) |
| `⇧Space` | Re-trigger the previous cue |

## FX pads

| Key | Action |
|---|---|
| `1`–`9`, `0` | In pad order, active only while held (default assignment. Right-click → “Key” to reassign to `1`–`0` or `Q`–`M`, or none) |

## Grid and clips

| Action | Effect |
|---|---|
| `⌥`-click a name strip | Select the clip only (no output) |
| `⌘`-drag | Move a clip |
| `⌥`-drag | Duplicate a clip |
| `⇧`-click | Select multiple clips |
| `Delete` | Delete the selected clips |
| `⌘`-drag an FX pad | Reorder pads |

## Values and play range

| Action | Effect |
|---|---|
| `⇧`-drag a layer's volume | Fine adjustment |
| `Shift`-drag the speed control | Fine adjustment |
| `⇧` + In/Out ◀ ▶ | Move 10 frames at a time |
| `⌥`-click an effect's dice button | Randomize values just a little (→ [Parameter Panel](parameters.md)) |

## Search window

| Key | Action |
|---|---|
| `↑` `↓` | Select |
| `Enter` | Add |
| `Esc` | Close |

## Output mapping

| Action | Effect |
|---|---|
| `⇧`-click | Add and select a point |
| Arrow keys | Move a point by 1 output pixel (10 with `⇧`) |
| `Delete` | Delete a point |
| `⌥`-drag | Move the stage |

## MIDI and key assignment

| Key | Action |
|---|---|
| `Esc` | Cancel assignment (learn) |

Clips, FX pads, and actions such as cues, blackout, tap and recording can also be assigned to keyboard keys. → [MIDI Controllers and Keys](midi.md)
