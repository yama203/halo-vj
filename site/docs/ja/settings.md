# 設定

設定ウィンドウ（`⌘,`）の中身を説明する。ショーの前に決めておく値を置いている。

## 出力の解像度・フレームレート

上部の「解像度・fps」と同じもの。→ [出力先・解像度・四隅](output.md)

## ブラックアウト

`Esc` のブラックアウトのフェード時間を決める（0〜5 秒）。

- 暗くなるまで
- 解除して戻るまで

映像と音の両方にかかる。フェード中にもう一度押すと、その位置から引き返す。

ブラックアウトのフェード時間は Mac ごとの設定で、プロジェクトには入らない。

## 画面

### 言語

- Mac の設定に合わせる
- 日本語
- English

次に開いたときから切り替わる。「今すぐ開き直す」で、すぐに開き直せる。

英語の Mac では、画面の文言が英語で出る（訳のある所だけ。無い所は日本語のまま）。

### 光らせる表示

- 「パラメーターのパネルが切り替わったら、縁を一瞬光らせる」：コンポジションはオレンジ・レイヤーは青・クリップは緑で光り、何に切り替わったかが右上に出る。
- 「出力が切り替わったら、出力モニターを一瞬光らせる」：クリップは緑・シーンは紫・止めたときは灰色で光り、何に変わったかが左上に出る（自動操縦が変えたときは飛行機の印）。

→ [画面の見方](interface.md)
