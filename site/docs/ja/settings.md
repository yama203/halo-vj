# 設定

このページでは、設定ウィンドウ（`⌘,`）の内容を説明します。設定ウィンドウには、ショーの前に決めておく項目がまとめられています。

![設定ウィンドウ](shots/ja/settings.jpg)

## 出力の解像度・フレームレート

上部の「解像度・fps」と同じ設定です。→ [出力先・解像度・四隅](output.md)

## ブラックアウト

`Esc` で切り替えるブラックアウトのフェード時間を設定します（0〜5 秒）。

- 暗くなるまで
- 解除して戻るまで

フェードは映像と音の両方にかかります。フェード中にもう一度押すと、その時点から引き返します。

ブラックアウトのフェード時間は Mac ごとの設定で、プロジェクトには含まれません。

## 画面

### 言語

- Mac の設定に合わせる
- 日本語
- English

変更は次回の起動時から反映されます。「今すぐ開き直す」を押すと、すぐに再起動できます。

英語環境の Mac では、画面の文言が英語で表示されます（翻訳がある部分のみで、翻訳が無い部分は日本語のまま表示されます）。

### 光らせる表示

- 「パラメーターのパネルが切り替わったら、縁を一瞬光らせる」：コンポジションはオレンジ、レイヤーは青、クリップは緑で光り、何に切り替わったかが右上に表示されます。
- 「出力が切り替わったら、出力モニターを一瞬光らせる」：クリップは緑、シーンは紫、停止したときは灰色で光り、何に変わったかが左上に表示されます（自動操縦による変更には飛行機の印が付きます）。

→ [画面の見方](interface.md)
