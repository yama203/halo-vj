# 文字・時計のジェネレーター

このページでは、テキストのジェネレーターと、時計・カウントダウンのジェネレーターを説明します。

## テキスト

文字の入力欄に入力した文字を表示します（改行で行を分けます）。

### 動き

- 止める
- 横に流れる
- 縦に流れる
- 敷き詰め（行ごとに逆向きに流れる）
- 1 文字ずつ（タイプライター）
- 拍で弾む

### フォント

10 種類あります：ゴシック 極太／ゴシック 細・明朝・丸ゴシック・SF 極太・コンデンス・Futura・Didot・等幅・筆記体。日本語を含まない書体を選んでも、日本語は表示されます。

### 行の切り替え

1・2・4・8 拍ごとに次の行へ切り替えます（空の行は飛ばします）。

### そのほかの値

- 大きさ・速さ・字間。
- 横／縦の間隔：流す・敷き詰めるときの、文字どうしのすき間。1 行の高さが単位で、マイナスにすると重ねることもできます。動かすこともできます。
- 波。
- グリッチ（帯ずれ＋色ずれ）。
- 縁取りだけ。
- 塗り：色／パレットのグラデーション。

クリップの名前には最初の行が使われます。文字は変更したときだけ描き直し、動きは GPU で処理するので負荷は軽くなっています。

## 時計・カウントダウン

### モード

| モード | 内容 |
|---|---|
| 今の時刻 | 時計を表示 |
| カウントダウン | 目標の時・分・秒までを表示。すでに過ぎた時刻なら翌日のその時刻まで。0 になったあと 1 時間は終了の表示 |
| タイマー | クリップを再生した時点から、分・秒で決めた長さを計測 |
| ストップウォッチ | |

### 表示

- 自動：1 時間以上は 時:分:秒、それより短いときは 分:秒。カウントダウン・タイマーの最後の 10 秒は数字だけ。
- 時:分:秒・時:分・分:秒・秒。
- 秒より細かく（1/10・1/100）。

### そのほか

- 0 になったら出す文字：空欄なら 0 のまま表示します。画面の幅からはみ出すときは縮小します。
- 最後の 10 秒は、数字が変わるたびに弾みます（オフにできます）。
- 数字は幅をそろえて描くので、横にぶれません。
- フォント・動き・波・グリッチ・色などはテキストと同じです。
