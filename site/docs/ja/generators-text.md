# 文字・時計のジェネレーター

テキストと、時計・カウントダウンのジェネレーターを説明する。

## テキスト

文字を入れる欄に打った文字を出す（改行で行を分ける）。

### 動き

- 止める
- 横に流れる
- 縦に流れる
- 敷き詰め（行ごとに逆向きに流れる）
- 1 文字ずつ（タイプライター）
- 拍で弾む

### フォント

10 種：ゴシック極太／細・明朝・丸ゴシック・SF 極太・コンデンス・Futura・Didot・等幅・筆記体。日本語の無い書体でも日本語は出る。

### 行の切り替え

1・2・4・8 拍ごとに次の行へ（空の行は飛ばす）。

### そのほかの値

- 大きさ・速さ・字間。
- 横／縦の間隔：流す・敷き詰めるときの文字どうしのすき間。1 行の高さが単位で、マイナスで重ねることもできる。動かせる。
- 波。
- グリッチ（帯ずれ＋色ずれ）。
- 縁取りだけ。
- 塗り：色／パレットのグラデーション。

クリップの名前は最初の行。文字は変えたときだけ描き直し、動きは GPU なので軽い。

## 時計・カウントダウン

### モード

| モード | 内容 |
|---|---|
| 今の時刻 | 時計 |
| カウントダウン | 目標の時・分・秒まで。もう過ぎた時刻なら次の日のその時刻まで。0 のあと 1 時間は終わった表示 |
| タイマー | 分・秒の長さを、クリップを出した時から |
| ストップウォッチ | |

### 表示

- 自動：1 時間以上は 時:分:秒、それより短いと 分:秒。カウントダウン・タイマーの最後の 10 秒は数字だけ。
- 時:分:秒・時:分・分:秒・秒。
- 秒より細かく（1/10・1/100）。

### そのほか

- 0 になったら出す文字：空なら 0 のまま。画面の幅からはみ出すときは縮める。
- 最後の 10 秒は数字が変わるたびに弾む（オフにできる）。
- 数字は幅をそろえて描くので、横にぶれない。
- フォント・動き・波・グリッチ・色などはテキストと同じ。
