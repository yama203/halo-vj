# 重ね方

このページでは、レイヤーを下のレイヤーに重ねるときの重ね方（ブレンドモード）の種類を説明します。重ね方は、レイヤー欄の下の段のボタンか、レイヤータブで選びます。

## 値の無い重ね方

差分・オーバーレイ・ソフトライト・覆い焼き・色相だけ・明るさだけは、下の映像を読み取って混ぜる、値を持たない重ね方です。かかり具合は不透明度で調整します。

| 重ね方 | 見た目 |
|---|---|
| 差分 | 重なった部分が反転したような色になる（同じ色は黒） |
| オーバーレイ・ソフトライト | 明るい部分はより明るく、暗い部分はより暗くなる |
| 覆い焼き | 明るい部分が焼けたように光る |
| 色相だけ | 下の映像の明るさのまま、上の色になる |
| 明るさだけ | 下の映像の色のまま、上の明るさになる |

## マスク（白で見せる／白で隠す）

そのレイヤーの明るさで、下のレイヤー全体を切り抜きます。マスクにしたレイヤー自体は表示されません。単色や図形のジェネレーターと組み合わせると便利です。

## オーバードライブ加算

下のレイヤーに加算し、100% を超えた分（あふれ）を次のものに変換する特殊合成です。

- にじみ（ハレーション）
- 色相ずれ
- 波紋（あふれた部分から同心円の波が外側へ広がる。強さ・細かさ・速さ・広がりを調整可能）
- 白飛びの抑え

値はレイヤータブに表示されます（秒・BPM で動かせます）。下の映像を読み取ってシェーダーで混ぜる仕組みのため、同じ方式で特殊合成を追加できます。

## 絡み合う重ね方

レイヤーの重ね方のうち「絡み合う重ね方」は、このレイヤーの映像を使って、下の映像そのものを変化させます。値はレイヤータブに表示されます（秒・BPM で動かせます。重ね方を変えると、その種類の初期値になります）。

### 屈折

このレイヤーの明るさを高さとみなし、その傾きの向きに下の映像を曲げます。透明なガラスでできた文字や図形が映像の上を流れるような効果になります。

値：曲げる強さ・なめらかさ・色のずれ・ふちの光・上の絵も見せる

### 光で照らす

このレイヤーを光源として下の映像を照らし、それ以外の部分を暗く沈めます。ドット・ホタル・粘菌などと相性が良い重ね方です。

値：照らされない所の暗さ・光の広がり・光の強さ・光の色を付ける・光そのものを見せる

### 流し込む

このレイヤーで下の映像を絵の具のように押し流してかき混ぜます。かき混ぜた映像は徐々に元に戻ります。

- 押し方：動いた所（動きのある映像向け）／明るい所のまわり（文字などの大きな明るい形のまわりで渦を巻く）
- 値：かき混ぜる強さ・元に戻る速さ・渦・ねばり・上の絵も見せる
- 細く小さなものは押す力が弱くなります。

### 干渉

2 つの映像の明るさを波とみなして重ね、ずれた部分に動く縞模様（モアレ）を作ります。

値：縞の細かさ・流れる速さ・縞の濃さ・鋭さ・色（下の色／上の色／虹色）

### 色を借りる

下の映像の明るさ（形）に、このレイヤーの色を塗ります。

- 借り方：同じ場所の色／上の絵をパレットに（パレットにする行）
- 値：明るさのコントラスト・明るさでずらす・元の色を残す

### 溶け込む

下の映像の暗い部分（または明るい部分・ノイズ・上の明るさ）から順に、このレイヤーへ溶けるように切り替わり、境目が光ります。

値：溶ける量・溶け方・ふちのやわらかさ・ふちの光・ふちの色相・ノイズを混ぜる
