# 重ね方

レイヤーを下のレイヤーに重ねるときの重ね方の種類を説明する。重ね方はレイヤー欄の下の段のボタンか、レイヤータブで選ぶ。

## 値の無い重ね方

差分・オーバーレイ・ソフトライト・覆い焼き・色相だけ・明るさだけは、下の絵を読んで混ぜる、値の無い重ね方。不透明度でかかり具合を決める。

| 重ね方 | 見え方 |
|---|---|
| 差分 | 重なった所が反転したような色（同じ色は黒） |
| オーバーレイ・ソフトライト | 明るい所はより明るく、暗い所はより暗く |
| 覆い焼き | 明るい所が焼けたように光る |
| 色相だけ | 下の絵の明るさのまま上の色に |
| 明るさだけ | 下の絵の色のまま上の明るさに |

## マスク（白で見せる／白で隠す）

そのレイヤーの明るさで、下のレイヤー全部を切り抜く。そのレイヤー自体は見えない。単色・図形のジェネレーターと組み合わせると便利。

## オーバードライブ加算

下のレイヤーに加算して 100% を超えた分（あふれ）を、次のものに変える特殊合成。

- にじみ（ハレーション）
- 色相ずれ
- 波紋（あふれた所から同心円の波が外へ広がる。強さ・細かさ・速さ・広がり）
- 白飛びの抑え

値はレイヤータブに出る（秒・BPM で動かせる）。下の絵を読んでシェーダーで混ぜる仕組みなので、同じ形で特殊合成を増やせる。

## 絡み合う重ね方

レイヤーの重ね方の「絡み合う重ね方」は、このレイヤーの絵で、下の絵そのものを変える。値はレイヤータブに出る（秒・BPM で動かせる。重ね方を変えると、その種類のはじめの値になる）。

### 屈折

このレイヤーの明るさを高さにして、坂の向きに下の絵を曲げる。透明なガラスの文字や図形が映像の上を流れる。

値：曲げる強さ・なめらかさ・色のずれ・ふちの光・上の絵も見せる。

### 光で照らす

このレイヤーを光にして下の絵を照らし、ほかは暗く沈める。ドット・ホタル・粘菌などと合う。

値：照らされない所の暗さ・光の広がり・光の強さ・光の色を付ける・光そのものを見せる。

### 流し込む

このレイヤーで下の絵を絵の具のように押し流してかき混ぜ、だんだん元の絵に戻る。

- 押し方：動いた所（動きのある映像向き）／明るい所のまわり（文字などの大きな明るい形のまわりで渦を巻く）。
- 値：かき混ぜる強さ・元に戻る速さ・渦・ねばり・上の絵も見せる。
- 細く小さなものは押す力が弱い。

### 干渉

2 つの絵の明るさを波にして重ね、ずれた所に動く縞（モアレ）を出す。

値：縞の細かさ・流れる速さ・縞の濃さ・鋭さ・色（下の色／上の色／虹色）。

### 色を借りる

下の絵の明るさ（形）に、このレイヤーの色を塗る。

- 借り方：同じ場所の色／上の絵をパレットに（パレットにする行）。
- 値：明るさのコントラスト・明るさでずらす・元の色を残す。

### 溶け込む

下の絵の暗い所（明るい所・ノイズ・上の明るさ）から順にこのレイヤーへ溶け、境目が光る。

値：溶ける量・溶け方・ふちのやわらかさ・ふちの光・ふちの色相・ノイズを混ぜる。
