# ジェネレーター

このページでは、動画の代わりにクリップとして置く映像「ジェネレーター」の置き方・設定・画質と、種類の一覧を説明します。

![ジェネレーターの例](shots/generators.jpg)

## ジェネレーターとは

動画の代わりにクリップとして置く映像です。すき間やまわりは透明になります。設定はプロジェクトに保存されます。

## 置き方

ジェネレーターの一覧は、エフェクト一覧のいちばん上にあります。

- クリップのスロットへドラッグします。
- ダブルクリックすると、選択中のレイヤーの空のスロットに置きます。
- 空のスロットの右クリックメニューからも置けます。
- `⌘E` の検索ウインドウからも置けます（選択中のレイヤーの空のスロットに置きます）。→ [エフェクトの追加と並べ替え](effects.md)

## 設定

設定はクリップタブに表示されます。見出しは青緑です（エフェクトの紫と見分けられます）。値は秒・BPM に合わせて動かせます。→ [値の動かし方](animation.md)

いくつかのジェネレーターには「見た目」のボタンがあり、値をまとめて設定できます。

## 画質

ジェネレーターごとに「画質」を選べます。

- 高：そのまま
- 中：3/4
- 低：半分

小さい解像度で描いて引き伸ばすので、GPU の負荷が減ります（半分なら約 1/4）。そのぶん、線や細かい模様は少しぼやけます。

- 新しく置くジェネレーターは「低」から始まります（文字・時計は「高」）。以前から置いてあるものは変わりません。
- カメラ・Syphon・NDI の取り込みには、この設定はありません。
- 再生していないジェネレーターのプレビューは、常に小さめ（高さ 540 まで）で描きます。

## 一覧

一覧と空のスロットの右クリックメニューでは、分類ごとに並んでいます（色・グラデーション／線・模様／図形・粒／文字・時計 など）。

| ジェネレーター | 説明のページ |
|---|---|
| 単色・グラデーション（パレット・直線／円／回転） | このページ |
| ライン・ドット（粒）・トンネル・フィロタキシス・光の流れ・音の形 | [線・粒・光のジェネレーター](generators-lines.md) |
| 群れ（魚・鳥）・粘菌（フィジャルム）・パーティクル・ライフ・ホタルの同期・ストレンジ・アトラクター | [生き物・自然のジェネレーター](generators-nature.md) |
| ストライプ・チェッカー／格子／ドット・ノイズ（なめらか／砂嵐）・図形（円・リング・四角・枠・三角、並べられる） | このページ |
| 反応拡散・フラクタル・育つ線・メタボール・レーザーショー・シンセウェイブの地形・星空ワープ・水面の波紋・稲妻・放電・ロゴを粒に | [追加のジェネレーター](generators-more.md) |
| テキスト・時計／カウントダウン | [文字・時計のジェネレーター](generators-text.md) |
| カメラから・Syphon から・NDI から | [カメラ](camera.md)・[Syphon](syphon.md)・[NDI](ndi.md) |
