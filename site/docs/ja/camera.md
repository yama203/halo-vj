# カメラ

このページでは、ジェネレーター「カメラから」で、カメラやキャプチャ機器の映像をクリップとして置く方法を説明します。

## 使える機器

- Web カメラ
- HDMI キャプチャ
- iPhone（連係カメラ）

## 置き方

ジェネレーター「カメラから」（分類「ほかのアプリ・カメラから」）をスロットに置き、クリップタブの「カメラ」で機器を選びます。

- 機器を抜き差しすると、一覧が更新されます。
- 初回はカメラの使用許可を求められます。

## 値

- 合わせ方：収める・いっぱいに・引き伸ばす。
- 左右反転（鏡）。
- 濃さ。

## カメラの開き方

同じカメラを複数のスロットに置いても、カメラを開くのは 1 回だけです。10 秒間使われなければ閉じます。
