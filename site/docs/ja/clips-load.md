# クリップを読み込む

このページでは、グリッドのスロットに動画・静止画を配置する方法と、読み込める素材の形式を説明します。

## 配置する方法

- 空のスロットの右上の「＋」を押します。
- 空のスロットを右クリックします。
- 動画を空のスロットへドロップします。
- 「ソース」パネルからグリッドのスロットへドラッグします。

複数のファイルを選ぶと、右隣のスロットへ順番に配置されます（その行の右端まで）。

ジェネレーター（動画の代わりに配置する映像）の配置方法は [ジェネレーター](generators.md) を参照してください。

## 読み込める動画

- AVFoundation で読み込める動画
- HAP の動画：Hap・Hap Alpha・Hap Q・Hap Q Alpha・Hap R。AVFoundation では読み込めないため、圧縮されたまま取り出して Snappy をデコードし、GPU で映像に変換します。4K を何枚重ねても負荷は軽く済みます。

## 読み込める静止画

- PNG・JPEG・HEIC・TIFF・GIF・WebP
- PSD（レイヤーを統合した 1 枚の画像）
- PDF と AI（1 ページ目。AI は「PDF 互換ファイルを作成」を有効にして保存したもの）
- SVG

透明部分は透明のまま読み込みます。

### アニメーション画像

GIF・APNG・WebP のアニメーションは動いた状態で再生されます。

- 各コマの表示時間どおりにループします。
- クリップの速度とコンポジション速度が反映されます。
- サイズの大きいものは、メモリに収まるよう縮小して読み込みます。

## 「ソース」パネル

Mac のフォルダにある動画・静止画を一覧表示します。

- フォルダは上のメニューで追加・切り替えできます。サブフォルダもたどれます。
- 名前で検索できます。表示サイズは 大／中／小 から選べます。
- サムネイルを左右になぞると、内容を早送りで確認できます。
- ダブルクリックでプレビューします（音なし・ループ再生）。
- グリッドのスロットへドラッグして配置します。
- 登録したフォルダはアプリの設定に保存されます（プロジェクトには含まれません）。
