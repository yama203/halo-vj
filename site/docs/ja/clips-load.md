# クリップを読み込む

グリッドの枠に動画・静止画を置く方法と、読み込める素材の形式を説明する。

## 置き方

- 空きスロットの右上の「＋」を押す。
- 空きスロットを右クリックする。
- 動画を空きスロットへドロップする。
- 「ソース」パネルからグリッドの枠へドラッグする。

複数選ぶと右隣に順番に入る（その段の右端まで）。

ジェネレーター（動画の代わりに置く絵）の置き方は [ジェネレーター](generators.md) を見る。

## 読み込める動画

- AVFoundation で読める動画。
- HAP の動画：Hap・Hap Alpha・Hap Q・Hap Q Alpha・Hap R。AVFoundation では読めないので、圧縮されたまま取り出して Snappy をほどき、GPU で絵にする。4K を何枚も重ねても軽い。

## 読み込める静止画

- PNG・JPEG・HEIC・TIFF・GIF・WebP。
- PSD（重ねた結果の 1 枚）。
- PDF と AI（1 ページ目。AI は「PDF 互換ファイルを作成」で保存したもの）。
- SVG。

透明な所は透明のまま。

### 動く画像

GIF・APNG・WebP のアニメーションは動く。

- コマの表示時間どおりにくり返す。
- クリップの速度・コンポジション速度が効く。
- 大きいものはメモリに収まるよう縮めて読む。

## 「ソース」パネル

Mac のフォルダの動画・静止画を一覧にする。

- フォルダは上のメニューで追加・切り替えできる。中のフォルダもたどれる。
- 名前で検索できる。大きさは 大／中／小。
- サムネイルを左右になぞると中身を早送りで見られる。
- ダブルクリックでプレビュー（音なし・くり返し）。
- グリッドの枠へドラッグして置く。
- 登録したフォルダはアプリの設定に残る（プロジェクトには入らない）。
