# エフェクトの足し方・並べ替え

エフェクトをクリップ・レイヤー・コンポジションに付ける方法と、付けたエフェクトの並べ替え・調整・マスクを説明する。

## 「エフェクト」パネルから足す

「エフェクト」パネルにエフェクトの一覧がある（色・形・時間に分類、検索あり）。付けたい所へドラッグする。

| ドラッグ先 | 付く所 |
|---|---|
| クリップのサムネイル | クリップ |
| レイヤー欄 | レイヤー |
| 出力モニター | コンポジション |
| パラメーターパネルのエフェクト欄 | そのタブ |

ダブルクリックすると、今開いているタブに付く。

## ドラッグせずに足す

- 「＋ エフェクトを追加」ボタン（パラメーターパネルのエフェクト欄・FX パッドの設定）で探す窓が開く。
- 右クリックのメニュー（クリップの枠・レイヤー欄・出力モニター・FX パッド）に「エフェクトを探して追加…」と、分類ごとのメニュー「エフェクトを追加」がある。
- 調整レイヤーの空き枠は「エフェクトを選んでクリップを作る」。→ [調整レイヤー](adjustment-layers.md)
- 空の FX パッドはクリックで設定が開き、そこからも足せる。

足したカードは開いた状態になる。

## 探す窓（`⌘E`・「エフェクト」メニュー）

- 打つと絞り込む（名前・説明・英語名）。ひらがなでもカタカナの名前に当たる。空白で区切ると全部含むもの。
- ↑↓ で選んで Enter、クリックでも足す。Esc で閉じる。
- `⌘E` の窓はジェネレーターも出す。エフェクトは今のタブ（コンポジション・レイヤー・クリップ）へ、ジェネレーターは選択中のレイヤーの空き枠へ足す。
- 選んでいるものの見本が右に出る。

## 見本

「エフェクト」「ジェネレーター」パネルの一覧でカーソルを合わせると、そばに小さな窓が出て、動く見本と説明が見られる。

- エフェクトは、見本の絵（夕焼け・動く玉・文字・バー）に初めの値でかけたところ。
- カメラ・Syphon・NDI の取り込みは見本を動かさない。

## パラメーターパネルのエフェクト欄

付いているエフェクトが並ぶ。紫の見出しで、左端に紫の帯が付く（ジェネレーターの設定は青緑なので、ぱっと見で見分けられる）。

- 上から順にかかる。
- オン/オフ・並べ替え・削除・値の調整ができる。
- 数値には波形ボタンで秒・BPM の動きを付けられる。

### 不透明度

どのエフェクトにも「不透明度」（かかり具合）がある。

- 0% で元の絵、100% でいっぱい。
- 波形ボタンで動かせる。
- 下げていると、閉じた見出しにも % が出る。

### 最初の状態に戻す

↺ ボタンで値・動き・不透明度・色を最初の状態に戻す。ジェネレーターの文字・自由な形の点・オン／オフはそのまま。最初のままなら押せない。

### かかる順番

- クリップのエフェクトは、クリップのトランスフォーム（位置・スケール・角度）のあとにかかる。回したクリップにミラーをかけると、回った絵がミラーになる。
- 調整レイヤーは、エフェクトを通した絵で下の絵を置き換える（不透明度の割合で）。
- マスクを付けると下の絵全体をその形で切り抜き、外は黒になる。マスクは並び順に関係なく最後に切り抜く。

## マスク

- マスク（形）：四角・丸で切り抜く（位置・大きさ・角度・ぼかし・反転）。
- マスク（自由な形）：カードの「形を編集」で、左のプレビューの上で形を描く。
  - クリック：点を追加
  - ドラッグ：点を移動
  - 中をドラッグ：形ごと移動
  - 右クリック：点を削除

レイヤーの明るさで下を切り抜く重ね方「マスク（白で見せる／白で隠す）」は [重ね方](blend-modes.md) を見る。
