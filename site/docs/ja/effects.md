# エフェクトの追加と並べ替え

このページでは、エフェクトをクリップ・レイヤー・コンポジションに追加する方法と、追加したエフェクトの並べ替え・調整・マスクについて説明します。

## 「エフェクト」パネルから追加する

「エフェクト」パネルにはエフェクトの一覧があります（色・形・時間などに分類され、検索もできます）。追加したい場所へドラッグします。

| ドラッグ先 | 追加される場所 |
|---|---|
| クリップのサムネイル | クリップ |
| レイヤー欄 | レイヤー |
| 出力モニター | コンポジション |
| パラメーターパネルのエフェクト欄 | そのタブ |

ダブルクリックすると、今開いているタブに追加されます。

## ドラッグせずに追加する

- 「＋ エフェクトを追加」ボタン（パラメーターパネルのエフェクト欄、FX パッドの設定）で、検索ウインドウが開きます。
- 右クリックメニュー（クリップのスロット、レイヤー欄、出力モニター、FX パッド）に、「エフェクトを探して追加…」と、分類ごとのメニュー「エフェクトを追加」があります。
- 調整レイヤーの空のスロットでは「エフェクトを選んでクリップを作る」を使います。→ [調整レイヤー](adjustment-layers.md)
- 空の FX パッドはクリックすると設定が開き、そこからも追加できます。

追加したエフェクトのカードは、開いた状態で表示されます。

## 検索ウインドウ（`⌘E`・「エフェクト」メニュー）

![エフェクト・ジェネレーターを探すウィンドウ](shots/ja/search.jpg)

- 文字を入力すると、名前・説明・英語名で絞り込みます。ひらがなで入力してもカタカナの名前に一致します。空白で区切ると、すべての語を含むものに絞り込みます。
- ↑↓ で選んで Enter を押すか、クリックすると追加します。Esc で閉じます。
- `⌘E` のウインドウにはジェネレーターも表示されます。エフェクトは今のタブ（コンポジション・レイヤー・クリップ）に、ジェネレーターは選択中のレイヤーの空のスロットに追加します。
- 選択中の項目のプレビューが右側に表示されます。

## お気に入りと最近使ったもの

よく使うエフェクト・ジェネレーターは、お気に入りに入れておくとすぐ見つかります。

- 「エフェクト」「ジェネレーター」パネルの項目にカーソルを合わせると、右上に星が表示されます。クリックするとお気に入りに入ります（もう一度クリックで外れます）。右クリックの「お気に入りに入れる」「お気に入りから外す」でも切り替えられます。お気に入りの項目には、いつも小さな星が付きます。
- パネルのいちばん上に「お気に入り」（入れた順）、その下に「最近使った」（最近追加した順に 8 個まで）が表示されます。どちらも、ほかの項目と同じようにドラッグ・ダブルクリックで追加できます。検索中は表示されません。
- 検索ウインドウでも、何も入力していないときはいちばん上に「お気に入り」「最近使った」が表示されます。検索中は、同じくらい一致するものの中でお気に入りが先に並びます。行の右端の星や右クリックでも切り替えられます。
- 「最近使った」には、パネル・検索ウインドウ・メニューから追加したものが入ります（取り消し・シーンの呼び出し・プロジェクトを開いたときは入りません）。
- お気に入りと最近使ったものはアプリ全体の設定として保存され、どのプロジェクトでも同じです。

## 見本

「エフェクト」「ジェネレーター」パネルの一覧で項目にカーソルを合わせると、そばに小さなウインドウが開き、動くプレビューと説明が表示されます。

- エフェクトのプレビューは、見本の映像（夕焼け・動く玉・文字・バー）に初期値でかけたものです。
- カメラ・Syphon・NDI の取り込みでは、プレビューは動きません。

## パラメーターパネルのエフェクト欄

追加したエフェクトが並びます。見出しは紫で、左端に紫の帯が付きます（ジェネレーターの設定は青緑なので、ひと目で見分けられます）。

- 上から順にかかります。
- オン/オフ、並べ替え、削除、値の調整ができます。
- 数値には、波形ボタンで秒・BPM に合わせた動き（アニメーション）を付けられます。

### 不透明度

どのエフェクトにも「不透明度」（かかり具合）があります。

- 0% で元の映像のまま、100% で最大までかかります。
- 波形ボタンで動かせます。
- 100% 未満のときは、閉じた見出しにも % が表示されます。

### 最初の状態に戻す

↺ ボタンで、値・動き・不透明度・色を最初の状態に戻します。ジェネレーターの文字、自由な形の点、オン／オフは変わりません。最初の状態のままのときは押せません。

### かかる順番

- クリップのエフェクトは、クリップのトランスフォーム（位置・スケール・角度）のあとにかかります。回転させたクリップにミラーをかけると、回転した映像がミラーになります。
- 調整レイヤーは、エフェクトを通した映像で下の映像を置き換えます（置き換える割合は不透明度で決まります）。
- マスクを追加すると、下の映像全体をその形で切り抜き、外側は黒になります。マスクは並び順に関係なく、最後に切り抜きます。

## マスク

- マスク（形）：四角・丸で切り抜きます（位置・大きさ・角度・ぼかし・反転）。
- マスク（自由な形）：カードの「形を編集」を押し、左のプレビューの上で形を描きます。
  - クリック：点を追加
  - ドラッグ：点を移動
  - 内側をドラッグ：形全体を移動
  - 右クリック：点を削除

レイヤーの明るさで下を切り抜く重ね方（ブレンドモード）「マスク（白で見せる／白で隠す）」については、[重ね方](blend-modes.md) を参照してください。
