# 録画

コンポジションを動画ファイルに録る方法を説明する。

## 始める・止める

上部の「録画」、または `⌘R` で録画を始める／止める。

- 録画中はボタンが赤く点滅し、経過時間が出る。
- 止めると「保存しました」と Finder で表示が出る。
- 画面が隠れていても録れる。

## 録るもの

- 合成した絵：四隅の調整の前・パッドのエフェクト込み。ブラックアウトは入らない。
- クリップの音：音声ミキサーの出口。マスター音量・ミュートの手前。

## 設定

「録画」の右の ▾ で設定する。

| 項目 | 内容 |
|---|---|
| 形式 | H.264・HEVC・ProRes 422・ProRes 422 HQ |
| 大きさ | 出力と同じ・720p〜4K。縦横比は出力 |
| フレームレート | 24〜60 fps。決めた回数のコマ番号で時刻を付けるので、描画が遅れてもコマが飛ぶだけで時間はずれない |
| 音 | 音も録るか |
| 保存先 | はじめは ムービー/Halo VJ 録画。ファイル名は日時 |

設定は Mac ごとで、プロジェクトには入らない。

OSC `/halo/record [0/1]` や、MIDI・キーでも録画を切り替えられる。→ [OSC](osc.md)・[MIDI コントローラー・キー](midi.md)
