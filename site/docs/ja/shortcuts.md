# キーボードショートカット一覧

Halo VJ のキー操作と、キーを押しながらのマウス操作をまとめる。

## 全体

| キー | 操作 |
|---|---|
| `Esc` | ブラックアウトの切り替え |
| `⇧Esc` | 全レイヤーを停止 |
| `⌘Z` | 元に戻す |
| `⌘⇧Z` | やり直す |
| `⌘R` | 録画を始める／止める |
| `⌘,` | 設定 |
| `⌘E` | エフェクト・ジェネレーターを探す窓 |
| `⌘⇧M` | 出力のマッピング |

## ファイル

| キー | 操作 |
|---|---|
| `⌘N` | 新規 |
| `⌘O` | 開く… |
| `⌘S` | 保存 |
| `⇧⌘S` | 別名で保存… |

## キュー

| キー | 操作 |
|---|---|
| `スペース` | 次へ（キューが 1 つも無ければ何もしない） |
| `⇧スペース` | 1 つ前を出し直す |

## FX パッド

| キー | 操作 |
|---|---|
| `1`〜`9`・`0` | パッドの並びの順に、押している間だけ効く（最初の割り当て。右クリックの「キー」で `1`〜`0`・`Q`〜`M` に付け替え・なし） |

## グリッド・クリップ

| 操作 | 内容 |
|---|---|
| `⌥` を押しながら名前の帯をクリック | クリップを選ぶだけ（出力しない） |
| `⌘` を押しながらドラッグ | クリップを移動 |
| `⌥` を押しながらドラッグ | クリップを複製 |
| `⇧` を押しながらクリック | クリップを複数選択 |
| `Delete` | 選んだクリップをまとめて削除 |
| `⌘` を押しながら FX パッドをドラッグ | パッドの並び替え |

## 値・再生範囲

| 操作 | 内容 |
|---|---|
| `⇧` を押しながらレイヤーの音量をドラッグ | 微調整 |
| `Shift` を押しながら速度コントロールをドラッグ | 微調整 |
| `⇧` を押しながらイン・アウトの ◀ ▶ | 10 コマずつ動かす |

## 探す窓

| キー | 操作 |
|---|---|
| `↑` `↓` | 選ぶ |
| `Enter` | 足す |
| `Esc` | 閉じる |

## 出力のマッピング

| 操作 | 内容 |
|---|---|
| `⇧` クリック | 点を足して選ぶ |
| 矢印キー | 点を出力の 1 ピクセル動かす（`⇧` で 10） |
| `Delete` | 点を消す |
| `⌥` ドラッグ | 舞台を移動 |

## MIDI・キーの割り当て

| キー | 操作 |
|---|---|
| `Esc` | 割り当て（覚える）をやめる |

クリップ・FX パッドや、キュー・ブラックアウト・タップ・録画などの操作は、キーボードのキーにも割り当てられる。→ [MIDI コントローラー・キー](midi.md)
