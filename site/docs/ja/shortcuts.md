# キーボードショートカット一覧

このページでは、Halo VJ のキー操作と、キーを押しながら行うマウス操作をまとめて説明します。

## 全体

| キー | 操作 |
|---|---|
| `Esc` | ブラックアウトの切り替え |
| `⇧Esc` | 全レイヤーを停止 |
| `⌘Z` | 元に戻す |
| `⌘⇧Z` | やり直す |
| `⌘R` | 録画の開始／停止 |
| `⌘,` | 設定 |
| `⌘E` | エフェクト・ジェネレーターを探すウィンドウ |
| `⌘⇧M` | 出力のマッピング |

## ファイル

| キー | 操作 |
|---|---|
| `⌘N` | 新規 |
| `⌘O` | 開く… |
| `⌘S` | 保存 |
| `⇧⌘S` | 別名で保存… |

## キュー

| キー | 操作 |
|---|---|
| `スペース` | 次へ（キューが 1 つも無い場合は何もしない） |
| `⇧スペース` | 1 つ前のキューを最初から再生し直す |

## FX パッド

| キー | 操作 |
|---|---|
| `1`〜`9`・`0` | パッドの並び順に、押している間だけエフェクトがかかる（初期の割り当て。右クリックの「キー」で `1`〜`0`・`Q`〜`M` への割り当て変更、または割り当てなしにできる） |

## グリッド・クリップ

| 操作 | 内容 |
|---|---|
| `⌥` を押しながら名前の帯をクリック | クリップの選択のみ（出力しない） |
| `⌘` を押しながらドラッグ | クリップの移動 |
| `⌥` を押しながらドラッグ | クリップの複製 |
| `⇧` を押しながらクリック | クリップの複数選択 |
| `Delete` | 選択したクリップをまとめて削除 |
| `⌘` を押しながら FX パッドをドラッグ | パッドの並べ替え |

## 値・再生範囲

| 操作 | 内容 |
|---|---|
| `⇧` を押しながらレイヤーの音量をドラッグ | 微調整 |
| `Shift` を押しながら速度コントロールをドラッグ | 微調整 |
| `⇧` を押しながらイン・アウトの ◀ ▶ を押す | 10 コマずつ移動 |
| `⌥` を押しながらエフェクトのサイコロを押す | 値を少しだけランダムに変える（→ [パラメーターパネル](parameters.md)） |

## 探すウィンドウ

| キー | 操作 |
|---|---|
| `↑` `↓` | 選択 |
| `Enter` | 追加 |
| `Esc` | 閉じる |

## 出力のマッピング

| 操作 | 内容 |
|---|---|
| `⇧` クリック | 点を追加で選択 |
| 矢印キー | 点を出力の 1 ピクセル分移動（`⇧` で 10 ピクセル） |
| `Delete` | 点を削除 |
| `⌥` ドラッグ | 舞台を移動 |

## MIDI・キーの割り当て

| キー | 操作 |
|---|---|
| `Esc` | 「覚える」（ラーン）による割り当てを中止 |

クリップ・FX パッドや、キュー・ブラックアウト・タップ・録画などの操作は、キーボードのキーにも割り当てられます。→ [MIDI コントローラー・キー](midi.md)
