# 自由レイアウト（試験中）

このページでは、パネルを区画に自由に配置できる「自由レイアウト」について説明します。この機能はまだ試験中です。

## オンにする

メニューの「レイアウト」→「自由レイアウト（試験中）」でオンにします。オフにすると、元の固定された配置に戻ります。

## 配置できるもの

画面が区画に分かれ、どの区画にも次のパネルを配置できます。

- グリッド
- 出力モニター
- FX パッド
- プレビュー
- パラメーター（プレビューと設定は別々のパネルで、それぞれ区画いっぱいに広がる）
- ライブ
- シーン
- エフェクト
- ジェネレーター
- ソース

## 移動する

区画の上のタブをドラッグして、ほかの区画へドロップします。

| ドロップする場所 | 結果 |
|---|---|
| 区画の中央 | タブとしてまとめる |
| 区画の端 | 区画を分割して、その側に配置する |
| 区画の境界（ドラッグ中に橙色の配置先が表示される） | その境界に 1 列（1 行）差し込む（境界の長さいっぱい） |
| 画面の四辺（細い配置先が表示される） | その辺いっぱいに配置する（グリッドを左端に縦いっぱい、FX パッドを下に横いっぱい など） |

- 区画の境界をドラッグすると、大きさを変更できます。
- 空になった区画は閉じます。
- 別ウィンドウやレイアウトの保存も、そのまま使えます。

パネルの閉じ方は [ワークスペース・パネル](layout.md) を参照してください。
