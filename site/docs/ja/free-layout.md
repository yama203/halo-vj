# 自由レイアウト（試験中）

このページでは、パネルを区画に自由に配置できる「自由レイアウト」について説明します。この機能はまだ試験中です。

## オンにする

メニューの「レイアウト」→「自由レイアウト（試験中）」でオンにします。オフにすると、元の固定された配置に戻ります。

## 配置できるもの

画面が区画に分かれ、どの区画にも次のパネルを配置できます。

- グリッド
- 出力モニター
- FX パッド
- プレビュー
- パラメーター（プレビューと設定は別々のパネルで、それぞれ区画いっぱいに広がる）
- ライブ
- シーン
- エフェクト
- ジェネレーター
- ソース

## 移動する

パネルのタブをつかんで、置きたい所へドラッグします。

- タブバーの中で横に動かしている間は、タブの並べ替えです。ほかのタブが横にずれて、入る場所を空けます。
- タブバーから外へ出すと、パネルの移動になります。置ける場所が 1 つだけ青く光り、マウスの横にパネルの名前が出ます。
- タブバーの何もない所（タブの右の空き）をつかむと、いま表示しているパネルを動かします。
- ドラッグ中に Esc を押すと、何も変えずに取り消します。

| 離す場所 | 結果 |
|---|---|
| ほかの区画のタブバー | その位置にタブとして入る（青い縦線の所） |
| 区画の真ん中 | 最後のタブとしてまとめる |
| 区画の端（端から 4 分の 1 くらい） | 区画を分割して、その側に置く |
| 区画の境界の線の上 | その境界に 1 列（1 行）差し込む（境界の長さいっぱい） |
| 画面の四辺のすぐ内側 | その辺いっぱいに置く（グリッドを左端に縦いっぱい、FX パッドを下に横いっぱい など） |
| メインのウィンドウの外 | 別ウィンドウに出す（別ウィンドウにできるパネルだけ） |

置いても形が変わらない所（自分だけの区画の真ん中など）は光らず、離しても何も変わりません。

- タブを右クリックすると「左へ」「右へ」「別ウィンドウに出す」「閉じる」も選べます。
- 区画が狭くてタブの名前が入りきらないときは、選んでいないタブはアイコンだけになります（マウスを乗せると名前が出ます）。
- タブ（またはタブバーの空き）をダブルクリックすると、その区画を一時的に画面いっぱいに広げます。もう一度ダブルクリックするか、右上の戻すボタンで元に戻ります（この状態は保存しません）。
- 区画の境界をドラッグすると、大きさを変更できます。
- 空になった区画は閉じます。
- 別ウィンドウやレイアウトの保存も、そのまま使えます。

パネルの閉じ方は [ワークスペース・パネル](layout.md) を参照してください。
