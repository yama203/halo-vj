# 自由レイアウト（試験中）

パネルを区画に自由に置ける「自由レイアウト」を説明する。まだ試験中の機能。

## オンにする

メニューの「レイアウト」→「自由レイアウト（試験中）」でオンにする。オフにすると、元の決まった並べ方に戻る。

## 置けるもの

画面が区画に分かれ、どの区画にも次のものを置ける。

- グリッド
- 出力モニター
- FX パッド
- プレビュー
- パラメーター（プレビューと設定は別々のパネルで、それぞれ区画いっぱいに広がる）
- ライブ
- シーン
- エフェクト
- ジェネレーター
- ソース

## 動かす

区画の上のタブをドラッグして、ほかの区画へ落とす。

| 落とす所 | 結果 |
|---|---|
| 区画の真ん中 | タブとしてまとめる |
| 区画の端 | 区画を分けて、その側に置く |
| 区画の境目（ドラッグ中に橙の置き場所が出る） | その境目に 1 列（1 段）差し込む（境目の長さいっぱい） |
| 画面の四辺（細い置き場所が出る） | その辺いっぱいに置く（グリッドを左端に縦いっぱい、FX パッドを下に横いっぱい など） |

- 区画の境目はドラッグで大きさを変える。
- 空になった区画は閉じる。
- 別ウィンドウ・レイアウトの保存も、そのまま使える。

パネルの閉じ方は [ワークスペース・パネル](layout.md) を見る。
