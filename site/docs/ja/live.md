# ライブパネル・テンポ

「ライブ」パネルの進行バーとテンポ（BPM・タップ・拍の頭）を説明する。

## 進行バー（スクラブ）

「ライブ」パネルの進行バーをドラッグするとスクラブする。離すとその位置から再生する。音声も付いてくる。

## テンポ

「ライブ」パネルの「テンポ」には次のものがある。

- BPM：ドラッグで変更。
- TAP：拍に合わせて何回か押す。押した瞬間が拍の頭になる。
- 頭：今を 1 拍目にする。
- 拍の表示。

BPM の欄の「自動」で、音から BPM と拍の頭を合わせ続けることもできる。→ [音の入力・BPM](audio-input.md)

BPM は、元に戻すの歩には数えない（本番中に動かす値なので）。

OSC では `/halo/bpm 数`・`/halo/tap`・`/halo/resync` を受け取る。→ [OSC](osc.md)
