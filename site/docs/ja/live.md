# ライブパネル・テンポ

このページでは、「ライブ」パネルの進行バーとテンポ（BPM・タップ・拍の頭）について説明します。

![「ライブ」パネル。テンポとコンポジション速度](shots/ja/live.jpg)

## 進行バー（スクラブ）

「ライブ」パネルの進行バーをドラッグするとスクラブできます。離すと、その位置から再生します。音声も映像に合わせてスクラブします。

## テンポ

「ライブ」パネルの「テンポ」には、次の項目があります。

- BPM：ドラッグで変更します。
- TAP：拍に合わせて何回か押します。押した瞬間が拍の頭になります。
- 頭：現在の位置を 1 拍目にします。
- 拍の表示：現在の拍を表示します。

BPM の欄の「自動」を使うと、音から BPM と拍の頭を検出して合わせ続けることもできます。→ [音の入力・BPM](audio-input.md)

BPM の変更は、取り消しの履歴に記録しません（本番中に動かす値のため）。

OSC では `/halo/bpm 数`・`/halo/tap`・`/halo/resync` を受け付けます。→ [OSC](osc.md)
