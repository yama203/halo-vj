# 光・形・グリッチのエフェクト

このページでは、「光・ぼかし」「形」「グリッチ・デジタル」の分類にあるエフェクトの値を説明します。

## 光・ぼかし

### 光のにじみ（ブルーム）

しきい値より明るい部分を取り出し、1/4・1/8 に縮小して広くぼかしてから重ねます。

値：しきい値・やわらかさ・強さ・色み（下の映像の色で光らせる）・元の絵・広がり。

### 輪郭ネオン

輪郭を取り出して、ネオン管のように光らせます。

値：強さ・太さ・色（元の色・1 色・虹色）・元の絵・光の広がり・しきい値。

### ズームぼかし

中心から外へ流れるようなぼかしをかけます。

値：強さ・中心・回るぼかし・なめらかさ。

### ぼかし

ふつうのぼかしです。広くぼかすときは、映像を半分ずつ縮めてからぼかすので軽く済みます。

値：量（1080p での px。0 で元の映像のまま）・種類（ふつう・横だけ・縦だけ）・明るい所を残す（ぼかした映像と元の映像の明るい方を混ぜて、やわらかいソフトフォーカスにする）・端（のばす・透明）。

### ミニチュア風

ピントの合う帯の外をぼかして、ミニチュア写真のようにします。帯から離れるほど強くぼけます。

値：ぼかし（1080p での px）・帯の位置・帯の幅・ぼけ始めのやわらかさ・角度（帯を傾ける）・形（帯・丸（中心のまわりだけはっきり））・彩度・コントラスト。ぼかし 0・彩度 100%・コントラスト 100% で元の映像のままです。

### 浮き彫り

明るさの傾きから、光が当たった浮き彫りにします。

値：強さ・光の向き（135° で左上から）・光の回る速さ・太さ（1080p での px）・色の残し方（灰色の浮き彫り・元の色に重ねる・金属）・元の絵・なめらかに（先に少しぼかす）。強さ 0 で「元の色に重ねる」なら元の映像のままです。

## 形

### 万華鏡

映像を扇形に切り出し、鏡のように並べて回転させます。

値：枚数・回る速さ・角度・中心・ズーム・取る所のずれ・鏡にする・取る所の角度と回る速さ。

### ガラス片

映像を細胞のような形のガラス片に割り、片ごとにずらします。

値：片の数・ずれ・動く速さ・縁の線・屈折・色ずれ・縁の明るさ。

### レンズ

中心からの距離で映像をゆがめます。

種類：魚眼（ふくらむ）・へこむ（糸巻き）・渦（中心ほど強く回る）・虫めがね（丸の中だけ拡大）・波打つレンズ。

値：強さ（0 で元の映像のまま）・大きさ（効く半径）・中心・色のにじみ（赤と青で強さを少し変える）・端（のばす・折り返す・透明）。

### 極座標

映像を輪に巻きます（横が角度、縦が半径。はじめは下の端が中心に来る「小さな惑星」）。ほどくにすると、逆に輪をまっすぐにします。

値：向き（輪にする・ほどく）・回す・回る速さ・巻く回数・半径のずれ・半径の流れる速さ（流すとトンネルになる）・中心・つなぎ目を鏡に・内と外を入れ替える。

### タイル

映像を縮めて並べます。

値：横の数・縦の数（小数にすると途中で切れる）・そろえる（縦の数＝横の数）・鏡にする（しない・横・縦・両方）・段のずれ（れんが積み）・流れる速さ（横・縦。1 秒に何枚ぶん）・すき間（間は透明）・1 枚ずつ回す。横と縦の数が 1 なら元の映像のままです。

### ゆれ

映像全体を揺らします。手持ちカメラの揺れ・地震・ズームの脈。

値：ゆれ（1080p での px）・速さ（1 秒に何回）・種類（なめらか・がたがた・横だけ・縦だけ）・回る・ズームの脈・ぶれ（動いた向きにぼかす）・端（のばす・折り返す・透明・少し拡大して隠す）。

ゆれを 0 にすると、回る・ズームの脈も含めて止まり、元の映像のままになります（回る・ズームの脈は、ゆれが 0〜20 px の間で強くなります）。ゆれを音や拍の動きに割り当てると、キックで画面が揺れます。

### 明るさでずらす

映像自身の明るさ（か色・輪郭）で、映像をずらします。明るい所が飛び出して見えます。

値：ずれ（1080p での px。0 で元の映像のまま）・角度・何でずらす（明るさ・赤と緑（赤が横、緑が縦）・輪郭（明るさの傾きの向きへ））・ぼかしてから（ずらす地図を先にぼかして、なめらかにゆがめる）・真ん中の明るさ（この明るさの所はずれない）・色のずれ（赤・緑・青でずれの量を変える）・端（のばす・折り返す・透明）。

### 入れ子

映像の中に、縮めた同じ映像が入れ子に続きます（合わせ鏡）。

値：縮む割合・数（1〜12。それより奥は最後の段の映像が続く）・回す（1 段ごとの角度）・回る速さ・寄っていく速さ（入れ子の中へ吸い込まれる・出てくる。1 段進むと元の形に戻るので、ずっとつながる）・中心・枠（各段のふちの線。色は「色」）・形（四角・丸）・外も埋める（中心をずらしたとき、外側も拡大した映像で埋める）。数 1・寄っていく速さ 0 で元の映像のままです。

## グリッチ・デジタル

### 色ずれ

赤・緑・青の各チャンネルをずらします。

値：ずれ・角度・形（まっすぐ・放射・揺れる）・揺れ・揺れる速さ。

### モザイク・網点

四角・丸い点・網点（明るいほど大きい点）・横線で映像を描きます。

値：大きさ・角度・点の大きさ・すき間を透明に。

### ピクセルソート

明るさがしきい値の範囲内で続いている部分（帯）ごとに、ピクセルを明るさの順に並べ替え、縦または横に溶け流れるように見せます。

値：しきい値の上下・流れる長さ・向き・逆・細かさ。

### データモッシュ風

前のフレームとの間でブロックごとの動きを検出し、保持している映像を動きの向きに引きずります。今の映像は少しずつしか混ぜません。拍で元に戻します。

値：かたまり・動きの強さ・今の絵を混ぜる・色にじみ・何拍ごと。

### 文字モザイク（ASCII）

明るさを文字に置き換えます。

値：字の大きさ・字（記号・ブロック・0 と 1・カタカナ）・色（元の色・1 色・緑の画面）・コントラスト・背景。

### ディザ

色数を 2〜8 色に減らし、点の密度で明るさを表現します。

値：色の組（白黒・ゲーム機の緑・4 色の昔のパソコン・元の色を減らす・パレット）・点の大きさ・並び（規則正しく・ざらざら）・コントラスト。

### LED パネル

映像を LED の粒の壁にします。近くで見ると粒、離れると映像に見えます。色はマスの中心から取ります。

値：マスの大きさ（1080p での px）・形（丸い粒・RGB の縦 3 本・四角）・粒の大きさ（マスに対する割合）・明るさ（粒の間が黒くなって暗くなるぶんを持ち上げる）・にじみ（粒のまわりの光）・パネルの継ぎ目（8×8 粒ごとに明るさが少し違い、さかい目に細い線）・すき間を透明に。

### スライス

映像を帯に切って、帯ごとに横（縦の帯なら縦）へずらします。拍で動かすと気持ちいいです。

値：向き（横の帯・縦の帯）・帯の数・ずれ（画面の幅に対して。0 で元の映像のまま）・ずらす形（ランダム・互い違い・波・階段）・変わる速さ（1 秒に何回組み替えるか。0 で止まる）・なめらかに（組み替えをなめらかにつなぐ）・帯の幅をばらばらに・色もずらす・端（折り返す・のばす・透明）。

### 引き伸ばし

ある線の所の画素を、そこから端まで引き伸ばします（スキャナーで動かしたような絵）。

値：向き（右へ・左へ・下へ・上へ・両側へ）・位置（線の場所。両側へのときは、真ん中に残す幅）・位置の揺れ（行ごとに位置がずれて、のこぎりのようになる）・揺れの細かさ・揺れの流れる速さ・なじませ（線の手前で元の映像と混ぜる幅）・筋を足す（伸ばした所に細い筋）。伸ばす所が無い位置（右へなら 100%）で元の映像のままです。
