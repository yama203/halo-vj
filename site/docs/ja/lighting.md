# 照明（Art-Net / DMX）

出力メニュー「照明（Art-Net / DMX）…」で、コンポジションの色で照明・LED テープを光らせる方法を説明する。

## 送り方

- Art-Net（ArtDmx・UDP 6454）で 40 回/秒送る。
- 送り先は、はじめ 255.255.255.255 へのブロードキャスト。ノードの IP も指定できる。
- 合成を 128×72 に縮めて色を取る。

## 灯体

灯体ごとに次のものを決める。

- 種類：RGB（1 点）・RGBW（1 点、白い分は W へ）・明るさだけ（1 点）・LED テープ（線・RGB、粒の数）。
- ユニバース。
- 先頭のチャンネル。
- 取る所：コンポジションの上の点・線の端をドラッグする。

512 を超えた分は次のユニバースへ送る。

## 全体の設定

全体の明るさ・ガンマ。

プロジェクトに保存され、元に戻すも効く。
