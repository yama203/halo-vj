# 照明（Art-Net / DMX）

このページでは、出力メニューの「照明（Art-Net / DMX）…」で、コンポジションの色に合わせて照明や LED テープを光らせる方法を説明します。

## 送信の仕組み

- Art-Net（ArtDmx・UDP 6454）で、毎秒 40 回送信します。
- 送信先の初期設定は 255.255.255.255 へのブロードキャストです。ノードの IP アドレスを指定することもできます。
- 合成した映像を 128×72 に縮小して色を取得します。

## 灯体

灯体ごとに、次の項目を設定します。

- 種類：RGB（1 点）・RGBW（1 点、白の成分は W へ）・明るさだけ（1 点）・LED テープ（線・RGB、粒の数）。
- ユニバース。
- 先頭のチャンネル。
- 取る所：コンポジションの上で、点または線の端をドラッグして指定。

512 チャンネルを超えた分は、次のユニバースへ送信します。

## 全体の設定

全体の明るさとガンマを設定できます。

設定はプロジェクトに保存され、取り消し（元に戻す）にも対応しています。
