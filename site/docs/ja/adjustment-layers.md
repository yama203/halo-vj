# 調整レイヤー

このページでは、下のレイヤーを重ねた映像全体にエフェクトをかける調整レイヤーと、そのスロットに配置する「エフェクトのクリップ」を説明します。

## 調整レイヤーを追加する

「調整レイヤーを追加」で、一番上に調整レイヤーを追加します。

- 調整レイヤーに付けたエフェクトは、下のレイヤーを重ねた映像全体にかかります（上のレイヤーにはかかりません）。
- 不透明度でかかり具合を調整します。
- レイヤー欄の右クリックや、レイヤータブのスイッチでも、通常のレイヤーと調整レイヤーを切り替えられます。
- 調整レイヤーは、エフェクトを通した映像で下の映像を置き換えます（置き換える割合は不透明度で決まります）。

## エフェクトのクリップ

調整レイヤーの行も、通常と同じスロットで構成されています。スロットに「エフェクトのクリップ」（エフェクトのセット）を配置して押すと、そのエフェクトが下のレイヤー全体にかかります。

- 同じ行の別のスロットを押すと切り替わり、空のスロットを押すと外れます。
- 不透明度でかかり具合を調整します。
- レイヤー自体に付けたエフェクトは常に一緒にかかります。
- シーン・キュー・複製・保存の扱いは通常のクリップと同じです。

### 作成する

- 空のスロットの右上の「＋」を押すか、右クリックの「エフェクトを選んでクリップを作る」を選びます。
- エフェクト一覧から空のスロットへドラッグします。

### 編集する

- クリップが入っているスロットへエフェクトをドラッグすると、エフェクトを追加します。
- 名前の帯をクリックすると、パラメーターパネルで名前とエフェクトを編集できます。
