# 調整レイヤー

下のレイヤーを重ねた絵全体にエフェクトをかける調整レイヤーと、その枠に置く「エフェクトのクリップ」を説明する。

## 調整レイヤーを足す

「調整レイヤーを追加」で、一番上に調整レイヤーを足す。

- そこに付けたエフェクトが、下のレイヤーを重ねた絵全体にかかる（上のレイヤーにはかからない）。
- 不透明度がかかり具合。
- レイヤー欄の右クリックや、レイヤータブのスイッチでも切り替えられる。
- 調整レイヤーは、エフェクトを通した絵で下の絵を置き換える（不透明度の割合で）。

## エフェクトのクリップ

調整レイヤーの行も普通の枠。枠に「エフェクトのクリップ」（エフェクトのセット）を置いて、押すとそのエフェクトが下のレイヤー全体にかかる。

- 同じ段の別の枠で切り替え、空き枠を押すと外れる。
- 不透明度がかかり具合。
- レイヤー自体に付けたエフェクトはいつも一緒にかかる。
- シーン・キュー・複製・保存も普通のクリップと同じ。

### 作り方

- 空き枠の右上の「＋」、または右クリック（「エフェクトを選んでクリップを作る」）。
- エフェクト一覧から空き枠へドラッグする。

### 編集

- 入っている枠へエフェクトをドラッグすると、エフェクトを足す。
- 名前の帯をクリックすると、パラメーターパネルで名前とエフェクトを編集できる。
