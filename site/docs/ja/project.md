# プロジェクト

プロジェクトファイル（.halovj）の保存・開き方、見つからない動画の付け直し、素材をまとめて保存する方法、自動保存を説明する。

## プロジェクトファイル

プロジェクトファイルの拡張子は .halovj。以前の .vjproj も開ける。

「ファイル」メニューから操作する。

| 項目 | キー |
|---|---|
| 新規 | `⌘N` |
| 開く… | `⌘O` |
| 最近使ったプロジェクト | |
| 保存 | `⌘S` |
| 別名で保存… | `⇧⌘S` |

Finder ではプロジェクトファイルに専用のアイコンが付き、ダブルクリックで Halo VJ が開く。

### 入るもの・入らないもの

- 入る：グリッド・クリップ（範囲・速度・エフェクト・動き・ミュート）・レイヤー・コンポジション・BPM・四隅。
- 入らない：出力先・音声の出力先・ブラックアウトのフェード時間（Mac ごとの設定）。

ほかに Mac ごとでプロジェクトに入らないものは、音の入力・OSC・MIDI の設定、録画の設定、「ソース」パネルに登録したフォルダ。

### 動画の場所

プロジェクトファイルと同じフォルダ（またはその下）の動画は、そこからの場所でも記録するので、フォルダごと動かしても開ける。

## 見つからない動画

動画が見つからないときは、「見つかりません」のクリップとして設定ごと置かれる。フォルダを選ぶと、同じ名前のファイルを探して付け直す。

- 「見つからない動画を探す…」
- クリップを右クリック →「動画ファイルを付け直す…」

## 素材をまとめて保存

ファイルメニュー「素材をまとめて保存…」で、選んだ場所にその名前のフォルダを作り、プロジェクトと「素材」フォルダ（使っている動画・画像のコピー）を入れる。

- フォルダごと別の Mac へ持っていける（プロジェクトには素材の場所を「素材/名前」で書く）。
- 同じ素材は 1 回だけコピーする。
- 別の場所の同じ名前の素材は「名前 2」のように番号を付ける。
- もう一度同じ所にまとめると、前にコピーした（大きさが同じ）ものは使い回す。
- 見つからない素材は知らせる。
- コピーは裏で進め、終わったら、まとめた方を開き直す。

## 自動保存

設定とスロットの中身は `~/Library/Application Support/Halo VJ/state.json` に自動保存される（以前の VJPlayer フォルダは初回起動時に引き継ぐ）。

自動保存はプロジェクトファイルを使っていてもそのまま続くので、次に起動したときは前回の状態（開いていたプロジェクトも）から始まる。
