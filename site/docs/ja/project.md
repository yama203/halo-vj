# プロジェクト

このページでは、プロジェクトファイル（.halovj）の保存と開き方、見つからない動画の再リンク、素材をまとめて保存する方法、自動保存について説明します。

## プロジェクトファイル

プロジェクトファイルの拡張子は .halovj です。以前の .vjproj も開けます。

「ファイル」メニューから操作します。

| 項目 | キー |
|---|---|
| 新規 | `⌘N` |
| 開く… | `⌘O` |
| 最近使ったプロジェクト | |
| 保存 | `⌘S` |
| 別名で保存… | `⇧⌘S` |

Finder ではプロジェクトファイルに専用のアイコンが付き、ダブルクリックすると Halo VJ で開きます。

### 保存されるもの・されないもの

- 保存されるもの：グリッド・クリップ（範囲・速度・エフェクト・動き・ミュート）・レイヤー・コンポジション・BPM・四隅。
- 保存されないもの：出力先・音声の出力先・ブラックアウトのフェード時間（Mac ごとの設定）。

このほか、音の入力・OSC・MIDI の設定、録画の設定、「ソース」パネルに登録したフォルダも Mac ごとの設定で、プロジェクトには保存されません。

### 動画の場所

プロジェクトファイルと同じフォルダ（またはその中のフォルダ）にある動画は、プロジェクトファイルからの相対的な場所も記録します。そのため、フォルダごと移動しても開けます。

## 見つからない動画

動画が見つからないときは、「見つかりません」のクリップとして設定ごと配置されます。フォルダを選ぶと、同じ名前のファイルを探して再リンクします。

- 「見つからない動画を探す…」
- クリップを右クリック →「動画ファイルを付け直す…」

## 素材をまとめて保存

ファイルメニューの「素材をまとめて保存…」を使うと、選んだ場所に指定した名前のフォルダを作成し、プロジェクトと「素材」フォルダ（使用中の動画・画像のコピー）を保存します。

- フォルダごと別の Mac へ持っていけます（プロジェクトには素材の場所を「素材/名前」の形で記録します）。
- 同じ素材は 1 回だけコピーします。
- 別の場所にある同じ名前の素材には、「名前 2」のように番号を付けます。
- 同じ場所にもう一度まとめると、以前にコピーしたもの（サイズが同じもの）を再利用します。
- 見つからない素材があれば通知します。
- コピーはバックグラウンドで行い、終わるとまとめた方のプロジェクトを開きます。

## 自動保存

設定とスロットの内容は `~/Library/Application Support/Halo VJ/state.json` に自動保存されます（以前の VJPlayer フォルダは、初回起動時に引き継ぎます）。

自動保存はプロジェクトファイルを使っている間も続くため、次に起動したときは前回の状態（開いていたプロジェクトを含む）から始まります。
