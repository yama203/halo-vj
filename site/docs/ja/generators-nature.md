# 生き物・自然のジェネレーター

このページでは、群れ・粘菌・パーティクル・ライフ・ホタルの同期・ストレンジ・アトラクターのジェネレーターの値を説明します。どれもまわりは透明です。

## 群れ（魚・鳥）

イワシやムクドリのような群れ（ボイド）を描きます。魚を 1 匹ずつ GPU 上で動かし、まわりに寄る（まとまる）・向きをそろえる・近づきすぎたら離れる（間をあける）というルールだけで、群れ全体がうねって形を変えます。

- 数（〜4000 匹）・大きさ。
- 形：魚・鳥（羽ばたく）・粒・線。
- 速さ・まわりを見る広さ。
- 動き回る：群れが画面の中をゆっくり回ります。
- 天敵から逃げる：見えない天敵が群れの中を出入りし、群れが割れたり穴があいたりしたあと、また集まります。
- ゆらぎ。
- きらめき：向きによって明るさが変わり、群れがそろって向きを変えると一斉に光ります。
- 奥行き：遠くの魚を小さく暗く描きます。
- 画面の端：戻ってくる／反対側へ抜ける。
- 色。
- 厚み（3D）：上げると箱の中を立体的に泳ぎ、カメラ（回る速さ・向き・視点の高さ・距離・画角）から遠近をつけて描きます。こちらを向いた魚は短く見え、横腹が光を反射する向きで光り、手前の魚が奥の魚を隠します。厚みが 0 なら平面で、奥行きは遠くの魚を小さく暗くして見せているだけです。
- 渦を巻く：群れが中心のまわりを輪になって回ります（3D では上ほど輪が大きい竜巻になります）。
- 「見た目」のボタン：イワシ・ムクドリ・ばらばら・トルネード。
- 停止するとその場で止まり、再開するとそこから続きます。

## 粘菌（フィジャルム）

粘菌の動き方を再現した、最大 100 万個の点です。1 つずつの点が前・左・右のにおい（自分や仲間が通った跡）を感知して濃い方へ曲がって進み、跡を残します。それだけで、葉脈・神経・川の地図のような網目を自ら作っては組み替えます。

- 数：720p の格子での数。小さなプレビューでは、同じ密度になるよう数を減らします。
- 速さ・においをかぐ角度と距離・曲がる角度・跡の残る長さ・にじみ・明るさ。
- 色の付け方：1 色・パレット（跡の濃さで）。
- えさ：なし・動く点・輪（えさの間を網目がつなぐ）。えさの強さも設定できます。
- ゆらぎ。
- 始まりの形：ばらばら・円・真ん中から（変更すると最初から作り直します）。
- 「見た目」：葉脈・細かい網・細胞・太い川・えさをつなぐ。

## パーティクル・ライフ

色（種類）ごとに「どの色に寄り、どの色から逃げるか」を決めた表だけで動く粒です（最大 6000 個）。近すぎると離れ、少し離れた所では表のとおりに引き合ったり押し合ったりするだけで、細胞のように集まる・追いかける・回るかたまりが生まれます。

- 数・種類の数（〜8 色）。
- たね（性格。表が変わります）。
- 力の届く広さ・力の強さ・ブレーキ・速さ・粒の大きさ・光のにじみ。
- 色の付け方：虹色・パレット。
- 性格を入れ替える：1〜32 拍ごとに次のたねへ切り替えます。切り替わる前の 1 拍でなめらかに移行します。
- 明るさ・残像。
- 画面の端はつながっています。
- 「見た目」：生き物・光の跡・拍で変身・大きな細胞。

## ホタルの同期

1 匹ずつが自分の周期で光り、見える範囲にいるホタルの光るタイミングに少しずつ合わせていきます（蔵本モデル）。はじめはばらばらでも、近いものどうしから同期していき、やがて全体が一斉に光るようになります。

- 数。
- そろう強さ（0 ならばらばらのまま）。
- 見える広さ（100% で画面全体）。
- 光る速さ・速さのばらつき・光の長さ・大きさ・光のにじみ・ふらふら。
- 拍に合わせる：½〜4 拍に 1 回、拍の頭へ引き寄せます（拍への引き）。
- 明るさ・色のばらつき。
- 「見た目」：ばらばら・だんだんそろう・一斉・拍で光る。

## ストレンジ・アトラクター

簡単な式をくり返して点を動かし、点が通った所の密度（1 フレームに最大 400 万点）を光の濃さで描きます。

- 種類：クリフォード・デ・ヨング（平面）、トーマス・アイザワ（3D。少し上から見下ろして回転します）。種類を変えると、前の形の残りを消去します。
- 係数 a〜d。
- 変身：係数をゆっくり揺らす速さと大きさ。
- 濃さ・残り方・大きさ・回る速さ。
- 色の付け方：1 色・パレット（濃さで）・動きの向き（虹色）。
- 点の数。
- 「見た目」：絹・煙・迷路の糸・リンゴの芯。
