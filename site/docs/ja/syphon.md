# Syphon

上部の「連携」の Syphon で、同じ Mac のほかのアプリと映像をやりとりする方法を説明する。

## 出す

コンポジションを Syphon で公開する。

- 出すのは、四隅の調整の前・パッドのエフェクト込みの絵。
- 名前は変えられる。はじめは「Halo VJ」。
- 大きさは、出力・コンポジションの画面と同じ（画面が無ければ 1920×1080 か、決めた解像度）。
- 受け取られているかが出る。

TouchDesigner では Syphon Spout In TOP で受け取る。

## 受け取る

ジェネレーター「Syphon から」（分類「ほかのアプリから」）を枠に置き、クリップタブの「映像」で、公開されている映像を選ぶ。

- アプリ名とサーバー名で覚える。いなくなっても、また公開されれば続きから出る。
- 合わせ方：収める・いっぱいに・引き伸ばす。
- 濃さ。
- 透明はそのまま。
- 自分の出力は一覧に出さない。
