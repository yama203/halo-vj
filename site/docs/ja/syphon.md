# Syphon

このページでは、上部の「連携」の Syphon で、同じ Mac 上のほかのアプリと映像をやりとりする方法を説明します。

## 送信する

コンポジションを Syphon で公開します。

- 送信するのは、「四隅」（コーナーピン）の調整前で、FX パッドのエフェクトを含む映像です。
- 名前は変更できます。初期設定は「Halo VJ」です。
- 解像度は、出力・コンポジションの画面と同じです（画面が無いときは 1920×1080、または設定した解像度）。
- 受信されているかどうかを表示します。

TouchDesigner では、Syphon Spout In TOP で受信します。

## 受信する

ジェネレーター「Syphon から」（分類「ほかのアプリ・カメラから」）をスロットに置き、クリップタブの「映像」で、公開されている映像を選びます。

- アプリ名とサーバー名で記憶します。送信元がいなくなっても、再び公開されると続きから表示します。
- 合わせ方：収める・いっぱいに・引き伸ばすから選べます。
- 濃さを調整できます。
- 透明部分は透明のまま扱います。
- 自分の出力は一覧に表示しません。
