# デッキ・グリッドの表示

グリッドを何枚も持つ「デッキ」と、グリッドの表示の大きさを説明する。

## デッキ

グリッド上の「デッキ」タブで、グリッドを何枚も持てる（Resolume のデッキのようなもの）。

- タブのクリックで、表示するデッキを切り替える。再生中のクリップはそのまま続く。
- 別のデッキのクリップを再生中のレイヤーには橙のマークが出る。
- 「＋」で空のデッキを足す。
- 右クリックで名前・複製・削除。

### シーンとデッキ

- シーンは保存したときのデッキを覚えていて、呼び出すとそのデッキの表示になる（シーンの右クリック「デッキ」で変えられる）。
- 同じデッキを何個のシーンで使ってもよい。

## 表示の大きさ（大／中／小）

デッキのタブの右の「大／中／小」で、グリッドの表示の大きさを変える。

- 大：幅いっぱい。
- 中・小：小さな枠でたくさんのクリップを見せる（MacBook など画面が小さいとき）。
- 小ではレイヤー欄も詰めて、下の段（重ね方・名前）を省く。
