# 音の入力・BPM

このページでは、上部の「音の入力」で選ぶ音と、BPM・拍の合わせ方を説明します。

## 音の入力

上部の「音の入力」で、反応させる音を選びます。

- アプリの音：クリップの音です。マスター音量やミュートに関係なく届きます。
- 入力デバイス：マイクやライン入力です。DJ ミキサーやほかのアプリの音は、ライン入力や BlackHole などの仮想デバイスを使って入力します。初回はマイクの使用許可を求められます。

### 音の分け方

音を次の 5 つの項目に分けて解析します。

| 項目 | 内容 |
|---|---|
| 音量 | 全体の音の大きさ |
| 低音 | 〜150 Hz |
| 中音 | 150〜2500 Hz |
| 高音 | 2500 Hz〜 |
| アタック | 低音が急に大きくなった瞬間（キックの頭）に 1 になり、なめらかに戻る |

- レベルは自動で合わせます（最近いちばん大きかった音を 100% とするため、入力の音量に関係なく動きます）。
- 音が止んだときに戻る速さを設定できます。
- ボタンの横と設定画面の中に、現在の値がバーで表示されます。

音の入力の設定は Mac ごとに保存され、プロジェクトには含まれません（動かし方はプロジェクトに含まれます）。値を音で動かす方法は [値の動かし方](animation.md) を参照してください。

## BPM の自動検出

BPM の欄の「自動」を使うと、音（上部の「音の入力」で選んだ音）から BPM と拍の頭を検出し、合わせ続けます。

- 立ち上がりの強さ（低音と全体）を 1 秒に約 190 回取得します。
- 直近 8 秒間の周期（自己相関）から BPM を求め、その周期ごとに足し合わせていちばん強くなる位置から拍の頭を求めます。
- 1 秒ごとに判定し、3 回続けて 2% 以内に収まったら合わせます（緑の数字は合っていることを示します）。
- わずかな差（0.4 BPM・30 ms 未満）では変更しません。
- 78〜160 BPM の範囲で検出します。それより速い曲は半分の値で検出します（DnB の 174 は 87 になります）。
- 自動で変わった BPM は、保存や「元に戻す」の対象になりません。
- タップや「頭」はいつでも使えます。→ [ライブパネル・テンポ](live.md)
