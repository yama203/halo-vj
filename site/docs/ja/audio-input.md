# 音の入力・BPM

上部の「音の入力」で選ぶ音と、BPM・拍の合わせ方を説明する。

## 音の入力

上部の「音の入力」で、反応させる音を選ぶ。

- アプリの音：クリップの音。マスター音量・ミュートに関係なく届く。
- 入力デバイス：マイク・ライン入力。DJ ミキサーやほかのアプリの音は、ライン入力や BlackHole などの仮想デバイスで入れる。はじめてのときマイクの使用の許可を聞かれる。

### 音の分け方

音を次の 5 つに分ける。

| 部分 | 中身 |
|---|---|
| 音量 | 全体の大きさ |
| 低音 | 〜150 Hz |
| 中音 | 150〜2500 Hz |
| 高音 | 2500 Hz〜 |
| アタック | 低音が急に大きくなった瞬間（キックの頭）に 1 になって、すっと戻る |

- 自動で合わせる（最近いちばん大きかった音を 100% に。入力の音量に関係なく動く）。
- 音が止んだときに戻る速さを決められる。
- ボタンの横と設定の中に今の値の棒が出る。

音の入力の設定は Mac ごとで、プロジェクトには入らない（動かし方は入る）。値を音で動かす方法は [値の動かし方](animation.md) を見る。

## BPM の自動

BPM の欄の「自動」で、音（上部の「音の入力」で選んだ音）から BPM と拍の頭を合わせ続ける。

- 立ち上がりの強さ（低音と全体）を 1 秒に約 190 回取る。
- 最近 8 秒のくり返し（自己相関）から BPM を、その長さごとに足していちばん強くなる位置から拍の頭を求める。
- 1 秒ごとに見て、3 回続けて 2% 以内なら合わせる（緑の数字＝合っている）。
- 少しの違い（0.4 BPM・30 ms 未満）は動かさない。
- 78〜160 BPM の間で探す。それより速い曲は半分で取る（DnB の 174 は 87）。
- 自動で変わった BPM は保存・元に戻すには数えない。
- タップ・「頭」はいつでも使える。→ [ライブパネル・テンポ](live.md)
