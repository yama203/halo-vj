# 線・粒・光のジェネレーター

このページでは、ライン・ドット・トンネル・フィロタキシス・光の流れ・音の形のジェネレーターの値を説明します。

## ライン

Arena の Lines のような等間隔の線を描きます。すき間は透明です。

- 本数：画面の高さに収まる本数。0° で縦の線になります。
- 線の太さ：px（1080p での大きさ。1 px より細いときは、線を薄くして表現します）。
- 角度・速さ（本/秒）・ぼかし・色。
- 波（大きさ・細かさ・速さ・線ごとのずれ）：線が波形のようにうねります。
- 奥への傾き（縦・横）：線を描いた板を、遠近をつけて倒します（縦をプラスにすると、床のように上が奥になります）。「遠くを暗く」も設定できます。
- 波の高さ（3D）：横の線を地形のように上へ持ち上げます（手前の山が奥の線を隠します）。
  - 山の形：波・なめらかな山・とがった山。
  - 真ん中を平ら（道のように）／真ん中だけ山に。
  - 山の下を黒く塗る。
  - 傾きが 0° なら正面から見た山並みに、縦の傾きを付けると奥へ続く地形になり、速さを付けると手前へ流れてきます。

## ドット（粒）

ラインの粒版です。すき間は透明です。

- 数（画面の高さに収まる数）・粒の大きさ（px）。
- 形：円・四角・ひし形・十字。
- 並び：格子・互い違い・ばらばら。
- 角度・速さ・位置のばらつき・大きさのばらつき・明滅。
- 波（横・中心から・ノイズ）：粒の大きさが網点のように波打ちます。
- 奥への傾きで床や壁のようになり、波の高さ（3D）で粒が持ち上がって、点群の地形になります。
- 遠くを暗く・ぼかし・色。
- ふらふら（自由に飛ぶ）：粒が 1 つずつ別々の軌道でゆっくり飛び回ります（速さも設定できます）。
- 光のにじみ：粒のまわりがぼんやり光ります（重なると明るくなります）。
- ふらふらと光のにじみは、平らなときだけ使えます。
- 「見た目」のボタン：ほたる・舞う粒・格子。

## トンネル

奥へ奥へと進んでいく筒の内側を描きます。まわりは透明です。

- 形：円・四角・六角・三角。
- 模様：輪・格子・チェッカー・光の筋（奥から光が飛んでくる）・もや。
- 速さ（マイナスで逆方向に進む）・輪の数。
- 線の太さ：100% でどの模様もすき間なく埋まります。チェッカーは 50% を超えると、すき間のマスが中心から埋まっていきます。
- 回る速さ・ねじれ（奥ほど回る）・奥の暗さ（奥は暗く透ける）。
- うねり（トンネルが曲がる）とその速さ・中心の位置・まわりの区切り。
- 色の付け方：1 色・パレット（奥行きで色が変わる）・虹色。
- 明るさ・光のにじみ（線のまわりの光）。
- 「見た目」のボタン：ワープ・ネオン・格子の筒・渦・もやの洞窟。
- 奥の細かすぎる部分は、ちらつかないようになめらかにします。

## フィロタキシス

粒が黄金角（137.5°）ずつ回りながら中心から生まれ、外へ広がります（resolume_generator/phyllotaxis と同じ計算です）。まわりは透明です。

- 生まれる速さ・広がる速さ・粒の大きさ・育つ時間・外ほど大きく・光のにじみ・回転・線の長さ（粒が棒になる）・色のばらつき・色。
- クリップを再生した時点から粒が生まれ始めます。

## 光の流れ

抽象的な光の表現です。やわらかい光の帯が、ゆったりうねりながら流れます。帯の外側はなめらかに消え、内側は白 → ベージュ → 青緑 → 深い青と色が広がります。まわりは透明です。

- 速さ・ぼけ・帯の数・帯の太さ・うねり・色のにじみ（ふちの青・橙）・虹色・粒子感（フィルムのざらつき）・角度・明るさ・色相ずらし・まわりの光・大きさ・色。
- スペクトルの複雑さ・細かさ：光の中に次のものを重ねます。
  - 分光（6 つの波長で少しずつずらし、ふちの外側へ青くにじませる）。
  - ゆっくり動く、ぼんやりした色の光（青・青緑・琥珀・橙）。
  - 交差するやわらかい光のひだ（縞模様にならないよう、くり返さない形）。

## 音の形

音（上部の「音の入力」）の周波数ごとの大きさ（スペクトラム）と波形を、そのまま映像にします（分類は「線・模様」）。まわりは透明です。

- スペクトラムは 30 Hz〜16 kHz を、聴感に近い間隔で 128 の帯に分けます。
- 形：棒・線（なめらかな曲線）・波形・円（棒）・円（波形）。
- 帯の数・高さ・太さ。
- 色の付け方：1 色・虹色・パレット（高さで）。
- 上下対称・明るさ・円の大きさ。
- なめらかさ：帯は上がるときも下がるときもなめらかに動き、波形は前の形へ少しずつ寄せます。
- 自動で合わせる場合は、直近でいちばん大きかった音を 100% にします。

### 描き方

- 描画のたびに、音の「今」の部分を切り出します。音のデータは 20〜100 ms ごとにまとめて届くので、その間も時間に合わせて進めます。
- 波形はオシロスコープと同じく、上がりながら 0 を横切る位置を先頭にそろえます（表示が跳ねません）。
- 点と点の間は曲線でつなぎ、線は傾いた部分も同じ太さで描きます。
- 円の波形は一周でつながります（虹色の色もつながります）。
