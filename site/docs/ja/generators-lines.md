# 線・粒・光のジェネレーター

ライン・ドット・トンネル・フィロタキシス・光の流れ・音の形のジェネレーターの値を説明する。

## ライン

Arena の Lines のような等間隔の線。すき間は透明。

- 本数：画面の高さに入る数。0° で縦の線。
- 線の太さ：px（1080p での大きさ。1 px より細いと薄くして出す）。
- 角度・速さ（本/秒）・ぼかし・色。
- 波（大きさ・細かさ・速さ・線ごとのずれ）：波形のようにうねる。
- 奥への傾き（縦・横）：線を描いた板を遠近付きで倒す（プラスの縦で床のように上が奥）。遠くを暗く。
- 波の高さ（3D）：横の線を地形のように上へ持ち上げる（手前の山が奥の線を隠す）。
  - 山の形：波・なめらかな山・とがった山。
  - 真ん中を平ら（道のように）／真ん中だけ山に。
  - 山の下を黒く塗る。
  - 傾き 0° なら正面から見た山並み、縦の傾きを付けると奥へ続く地形、速さで手前へ流れてくる。

## ドット（粒）

ラインの粒版。すき間は透明。

- 数（画面の高さに入る数）・粒の大きさ（px）。
- 形：円・四角・ひし形・十字。
- 並び：格子・互い違い・ばらばら。
- 角度・速さ・位置のばらつき・大きさのばらつき・明滅。
- 波（横・中心から・ノイズ）：粒の大きさが波打つ（網点のように）。
- 奥への傾きで床・壁に、波の高さ（3D）で粒が持ち上がって点の雲の地形になる。
- 遠くを暗く・ぼかし・色。
- ふらふら（自由に飛ぶ）：粒が 1 つずつ別々の道すじでゆっくり飛び回る（速さも決められる）。
- 光のにじみ：粒のまわりがぼんやり光る（重なると明るく）。
- ふらふらと光のにじみは、平らのときだけ。
- 「見た目」のボタン：ほたる・舞う粒・格子。

## トンネル

奥へ奥へと進んでいく筒の内側。まわりは透明。

- 形：円・四角・六角・三角。
- 模様：輪・格子・チェッカー・光の筋（奥から光が飛んでくる）・もや。
- 速さ（マイナスで戻る）・輪の数。
- 線の太さ：100% でどの模様もすき間なく埋まる。チェッカーは 50% より上で、すき間のマスが真ん中から埋まっていく。
- 回る速さ・ねじれ（奥ほど回る）・奥の暗さ（奥は暗く透ける）。
- うねり（曲がる）とその速さ・中心の位置・まわりの区切り。
- 色の付け方：1 色・パレット（奥行きで色が変わる）・虹色。
- 明るさ・光のにじみ（線のまわりの光）。
- 「見た目」のボタン：ワープ・ネオン・格子の筒・渦・もやの洞窟。
- 奥の細かすぎる所は、ちらつかないようにならす。

## フィロタキシス

粒が黄金角（137.5°）ずつ回りながら中心から生まれて、外へ広がる（resolume_generator/phyllotaxis と同じ計算）。まわりは透明。

- 生まれる速さ・広がる速さ・粒の大きさ・育つ時間・外ほど大きく・光のにじみ・回転・線の長さ（棒になる）・色のばらつき・色。
- クリップを出した時から粒が生まれ始める。

## 光の流れ

アブストラクトな光。やわらかい光の帯が、ゆったりうねりながら流れる。ふちの外はすっと消え、内側は白 → ベージュ → 青緑 → 深い青と広がる。まわりは透明。

- 速さ・ぼけ・帯の数・帯の太さ・うねり・色のにじみ（ふちの青・橙）・虹色・粒子感（フィルムのざらつき）・角度・明るさ・色相ずらし・まわりの光・大きさ・色。
- スペクトルの複雑さ・細かさ：光の中に次のものを重ねる。
  - 分光（6 つの波長で少しずつずらして、ふちの外へ青くにじむ）。
  - ゆっくり動くぼんやりした色の光（青・青緑・琥珀・橙）。
  - 交わるやわらかい光のひだ（縞にならないよう、くり返さない形）。

## 音の形

音（上部の「音の入力」）の、周波数ごとの大きさ（スペクトラム）と波形を、そのまま絵にする（分類「線・模様」）。まわりは透明。

- スペクトラムは 30 Hz〜16 kHz を、耳に近い間隔で 128 の帯に分ける。
- 形：棒・線（なめらかな曲線）・波形・円（棒）・円（波形）。
- 帯の数・高さ・太さ。
- 色の付け方：1 色・虹色・パレット（高さで）。
- 上下対称・明るさ・円の大きさ。
- なめらかさ：帯は上がるのも下がるのもなめらかに、波形は前の形へ少しずつ寄せる。
- 自動で合わせるなら、最近いちばん大きかった所を 100% にする。

### 描き方

- 音は描くたびに「今」の所を切り出す。届くかたまりは 20〜100 ms ごとなので、その間も時間に合わせて進める。
- 波形はオシロスコープのように、上がりながら 0 を横切る所を頭にそろえる（跳ねない）。
- 点のあいだは曲線でつなぎ、線は傾いた所も同じ太さ。
- 円の波形は一周でつながる（虹色の色も）。
