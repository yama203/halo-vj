# インストール・アップデート

このページでは、Halo VJ を Mac にインストールする方法と、新しいバージョンにアップデートする方法を説明します。

## 動作環境

- Apple シリコンの Mac
- macOS 14 以降

## インストール

1. [Releases](https://github.com/yama203/halo-vj/releases) から `Halo-VJ-x.y.z.zip` をダウンロードして展開します。
2. 「Halo VJ」をアプリケーションフォルダに移動します。

### 初めて開くとき

Apple の公証を受けていないため、初めて開くときは macOS にブロックされます。システム設定 →「プライバシーとセキュリティ」→「このまま開く」で一度だけ許可してください。

## アップデート

- アプリが新しいバージョンを自動で確認します（1 日 1 回）。アプリのメニューの「アップデートを確認…」でも確認できます。
- 起動時に新しいバージョンが見つかると、ウィンドウが表示されます。
- 使用中に見つかった場合は、上部に「新しい版」の小さなボタンが表示されるだけです（本番中に突然ウィンドウが開くことはありません）。
- ボタンを押すと変更点を確認でき、アップデートするかどうかを選べます。アップデートすると、アプリを置き換えて再起動します。
- 設定の「アップデート」で、自動で確認するかどうかを切り替えられます。
- アップデートは Sparkle が行い、公開鍵（Info.plist の SUPublicEDKey）で署名を検証してからインストールします。

## バージョン番号を確認する

上のバーの左端のアイコンを押すと「Halo VJ について」が開き、バージョン番号が表示されます。

- 開発中のソフトです（バージョン 1.0 未満）。
- AI（Claude）と対話しながらコードを書く「バイブコーディング」で作っています。動作の検証は十分ではありません。
- **大事な本番での使用は控えてください。** 使う場合は、必ず事前に手元で十分に試し、ほかの VJ ソフトなどの予備を用意してください。
