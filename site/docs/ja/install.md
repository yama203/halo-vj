# インストール・アップデート

Halo VJ を Mac に入れる方法と、新しい版に入れ替える方法を説明する。

## 動く Mac

- Apple シリコンの Mac。
- macOS 14 以上。

## インストール

1. [Releases](https://github.com/yama203/halo-vj/releases) から `Halo-VJ-x.y.z.zip` を落として開く。
2. 「Halo VJ」をアプリケーションに入れる。

### 初めて開くとき

Apple の公証を通していないので、初めて開くときは止められる。システム設定 →「プライバシーとセキュリティ」→「このまま開く」で一度許可する。

## アップデート

- アプリが自分で新しい版を確かめる（1 日 1 回）。アプリのメニュー「アップデートを確認…」でも確かめられる。
- 起動したときに見つけたら窓が出る。
- 動いている途中に見つけたら、上部に「新しい版」の小さなボタンが出るだけ（本番中に急に窓は出ない）。
- 押すと変更点を見て、入れるか決められる。入れると入れ替えて開き直す。
- 設定の「アップデート」で、自動で確かめるかを切り替えられる。
- 中身は Sparkle が、公開鍵（Info.plist の SUPublicEDKey）で署名を確かめてから入れる。

## 版の番号を見る

上のバーの左端のアイコンを押すと「Halo VJ について」が開き、版の番号が出る。
