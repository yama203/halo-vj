# 自動操縦

上部の「オート」で、決めたルールに沿ってシーン・クリップを回し続ける方法を説明する。席を離れるときなどに使う。

## オン・オフ

上部の「オート」を押すと、オン・オフが切り替わる。

- ルールが無ければ「おまかせ」で作る。シーンが 2 つ以上なら 3 分ごとにシーン、無ければ絵のあるレイヤーを 32 小節ごと。
- オンのあいだは、次の切り替えまでの時間が出る。
- OSC `/halo/auto`、右クリックで MIDI・キーにも割り当てられる。

## 設定

右の ▾ で設定を開く。

- 大きなボタンで、オン・オフと次の切り替えまでの時間。
- ルールごとに「いま → つぎ」：今出ているものと、次に出すもの（前もって決める）のサムネイル、そのあいだに残り時間のバー。操作して休み中は手の印とオレンジ。

### ルール

| 項目 | 内容 |
|---|---|
| 何を回すか | シーン／L1〜のクリップ |
| 間隔 | 小節・秒・分。小節は区切りのよい所で |
| ゆらぎ | 秒・分のとき、間隔を前後させて機械的に見えないように |
| 選び方 | ばらばら（今のもの・最近出したものを避ける）／順に |
| 切り替えの長さ | シーン・レイヤーの設定どおり／すぐ／秒 |
| 使うシーン・使うクリップ | サムネイルのタイル。押して外す・入れる |

ルールごとに、オン・オフ・今すぐ次へ・消す。

## 人が操作したとき

人がシーン・クリップを出したら、そのルールは決めた時間（はじめ 1 分）休む。

## 元に戻す・保存

- 自動の切り替え（とそのフェード）は、元に戻すの記録に入れない。席に戻って `⌘Z` を押すと、自分の操作が戻る。
- ルールはプロジェクトに保存する。オン・オフは保存しない（開いたらいつもオフ）。
- 自動操縦が出力を変えたときは、出力モニターに飛行機の印が出る。
