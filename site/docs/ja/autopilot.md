# 自動操縦

このページでは、上部の「オート」で、決めたルールに沿ってシーンやクリップを自動で切り替え続ける方法を説明します。席を離れるときなどに使います。

## オン・オフ

上部の「オート」を押すと、オンとオフが切り替わります。

- ルールが無いときは「おまかせ」でルールを作成します。シーンが 2 つ以上あれば 3 分ごとにシーンを、無ければ映像のあるレイヤーを 32 小節ごとに切り替えます。
- オンの間は、次の切り替えまでの時間を表示します。
- OSC `/halo/auto` や、右クリックから MIDI・キーにも割り当てられます。

## 設定

右の ▾ で設定を開きます。

- 大きなボタンで、オン・オフの切り替えと次の切り替えまでの時間の確認ができます。
- ルールごとに「いま → つぎ」を表示します。現在出力しているものと次に再生するもの（あらかじめ決まっています）のサムネイルが並び、その間に残り時間のバーが表示されます。手動の操作で休止中のときは、手の印が付いてオレンジ色になります。

### ルール

| 項目 | 内容 |
|---|---|
| 何を回すか | シーン／L1〜のクリップ |
| 間隔 | 小節・秒・分。小節の場合は区切りのよい位置で切り替える |
| ゆらぎ | 秒・分のとき、間隔を前後にずらして機械的に見えないようにする |
| 選び方 | ばらばら（今のもの・最近再生したものを避ける）／順に |
| 切り替えの長さ | シーン・レイヤーの設定どおり／すぐ／秒 |
| 使うシーン・使うクリップ | サムネイルのタイル。押すと対象から外す・対象に戻す |

ルールごとに、オン・オフ、今すぐ次へ、削除を操作できます。

## 手動で操作したとき

手動でシーンやクリップを再生すると、そのルールは決めた時間（初期設定は 1 分）休止します。

## 元に戻す・保存

- 自動の切り替え（とそのフェード）は、取り消しの履歴に記録しません。席に戻って `⌘Z` を押すと、自分の操作が取り消されます。
- ルールはプロジェクトに保存します。オン・オフの状態は保存しません（開いたときは常にオフです）。
- 自動操縦が出力を切り替えたときは、出力モニターに飛行機の印が表示されます。
