# FX パッド

押している間だけ効くエフェクトを並べる「FX パッド」パネルの使い方を説明する。

## 登録する

「エフェクト」パネルからパッドへドラッグして登録する（1 つのパッドに何個でも）。空の FX パッドはクリックで設定が開き、そこからも足せる。

## 効き方

- 押した瞬間に、出力のいちばん最後（コンポジションのエフェクトの後）にかかり、離すと消える。
- シーン・コンポジションとは別なので、シーンを切り替えても関係なく使える。
- 時間で動くエフェクト（ストロボなど）は、押した瞬間から始まる。

### 効き始めと離したとき

パッドごとに、右クリックまたは設定で選べる。

- 「効き始め」：押してから全開になるまで（すぐ〜4 秒）。
- 「離したとき」：消え切るまで（すぐ〜4 秒）。

パッドの右上の形で分かる。縦の線 = いきなり、斜め = だんだん。消えている途中に押し直すと、その効き具合から続けて上がる。

## キーボードで押す

- 最初はパッドの並びに `1`〜`9`・`0`。
- 押している間だけ効き、何個でも同時に押せる。
- パッドの左上にキーを表示する。
- 右クリックの「キー」で `1`〜`0`・`Q`〜`M` に付け替え・なし。

MIDI のボタンにも割り当てられる。→ [MIDI コントローラー・キー](midi.md)

## 並べ替え・編集

- `⌘` ドラッグ（または右クリックの「左へ」「右へ」）で並び替える。
- 右クリックで、設定（値・並び）・名前・空にする・削除。
- 「＋」で足す（16 個まで）。

プロジェクトに保存される。
