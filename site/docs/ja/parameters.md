# パラメーターパネル

下のパラメーターパネルのタブの中身と、値の変え方を説明する。

## タブ

パネルには「コンポジション」「レイヤー」「クリップ」のタブがあり、それぞれプレビューが付く。

| タブ | 中身 |
|---|---|
| コンポジション | マスター：音量・速度 |
| レイヤー | ミックス：調整レイヤー・重ね方・音量・切り替えフェード |
| クリップ | 音・再生：音量・速度、再生範囲（イン点・アウト点）、終わったら（ループ／往復／最後で停止／ブラックアウト） |

クリップタブの再生範囲・速度・ジャンプは [再生範囲・速度・ジャンプ](clips-range.md) を見る。

## トランスフォーム

どのタブも「トランスフォーム」に位置・スケール・角度・不透明度をまとめる。今の状態が値の左に絵で出る。

- 位置：小さな画面の上の点
- スケール：画面の枠とクリップの四角
- 角度：文字盤

## 値を変える

- ドラッグで調整する。
- ダブルクリック／右クリックで初期値に戻す。
- 数値欄の右の波形ボタンで、値を時間・拍・音などで動かせる。→ [値の動かし方](animation.md)

数値欄の色の意味は [画面の見方](interface.md) を見る。

### px の値

にじみ・波紋の広がり、ドットなどの px の値は、1080p の出力での大きさ。プレビューやほかの解像度では絵の大きさに比例させるので、どこで見ても同じ見え方。

### 色の見本

エフェクト・ジェネレーターの「色」やパレットの色の見本をクリックすると、その場に色を選ぶ窓が出る（Mac の色パネルの代わり）。

- 四角の横で色相、縦で鮮やかさ（下ほど白）。
- 下のバーで明るさ（左ほど黒）。
- #RRGGBB を打っても選べる。
- よく使う色のボタン付き。
- ドラッグしている間も出力に反映される。

## エフェクト欄

付いているエフェクトはパネルのエフェクト欄に並ぶ。→ [エフェクトの足し方・並べ替え](effects.md)

## パネルを細くしたとき

パネルを細くすると 1 列に並び替わる。横スクロールなしで使える。

- タブ名は短くなる（コンポ／L1／クリップ）。
- イン点・アウト点は 2 段になる。
- 「終わったら」はアイコンだけになる。
- ジャンプのボタンは 2 段になる。

## 切り替わったとき

クリップ・レイヤーを選ぶなどで中身が切り替わると、パネルの縁が一瞬光る。→ [画面の見方](interface.md)
