# 画面の見方

このページでは、Halo VJ の画面の主な構成と、グリッド・レイヤー・数値欄などの表示のルールを説明します。

## グリッドとレイヤー

- グリッドの 1 行が 1 つのレイヤーです。初期状態は 4 行 × 8 列で、レイヤーは 16 行、列は 64 列まで増やせます。収まらない場合はスクロールします。
- 各行で 1 つずつクリップを同時に再生でき、上の行ほど手前に重なります。
- 同じ行の別のクリップを再生すると、その行のクリップだけが切り替わります。
- レイヤーや列を途中に追加・削除しても、再生中のクリップは停止しません（削除した行・列のクリップだけが停止して外れます）。

## 主な領域

| 場所 | 内容 |
|---|---|
| 左端のレイヤー欄 | 不透明度、停止、重ね方（ブレンドモード）と再生中のクリップ名を表示。クリックすると下のレイヤータブの対象になる。→ [レイヤー](layers.md) |
| グリッド | クリップを並べるスロット。上に「デッキ」のタブと列番号。→ [デッキ・グリッドの表示](decks.md) |
| 出力モニター | 出力される映像。 |
| 下のパラメーターパネル | コンポジション・レイヤー・クリップの値。→ [パラメーターパネル](parameters.md) |
| 右下のタブ | 「ライブ」「シーン」「キュー」「エフェクト」「ジェネレーター」「ソース」。 |
| 「FX パッド」パネル | 押している間だけかかるエフェクト。→ [FX パッド](fx-pads.md) |
| 上のバー | ワークスペース、「音の入力」、「連携」、「オート」、「録画」、「出力」、「解像度・fps」、「音声」、「パネル」など。 |

上のバーの左端のアイコンを押すと「Halo VJ について」（バージョン番号）が表示されます。

## グリッドのサムネイルの表示

- 出力と同じく黒地に描画します。
- 透明部分のある素材には、右下に市松模様の印が付きます。
- 暗い色で透明部分のある素材（黒いロゴなど）は、見やすいように灰色の地に表示します。
- 広い透明部分の中に小さく描かれた素材は、描かれた範囲に合わせて拡大表示します（虫めがねの印）。
- サムネイルにマウスを乗せている間は、市松模様の上に全体を表示して透明の範囲を確認できます。

## クリップのスロットにマウスを乗せたとき

- 上のサムネイル部分：▶ が表示されます。押すと出力に再生します。再生中のクリップでは ↺（最初から再生し直す）になります。
- 下の名前の帯：帯が明るい灰色になり、上に線が表示されます。押すと選択だけを行います（出力しません）。
- 選択中の帯は青のまま少し明るくなります。

## 数値欄の色

- 初期値から変更した値は橙で表示します。
- プラスにもマイナスにもなる値（位置・角度・速さ・傾きなど）は、プラスを橙、マイナスを水色で表示します。欄の下には 0 から現在の値まで細い線が表示され、どちら向きにどれだけ動いているかがわかります。

## 切り替わりを知らせる表示

### パラメーターのパネルが切り替わったとき

クリップやレイヤーを選ぶなどしてパネルの内容が切り替わると、パネルの縁が一瞬光ります（コンポジション：オレンジ、レイヤー：青、クリップ：緑）。何に切り替わったか（「クリップ ○○」など）が右上に表示され、1 秒で消えます。

### 出力が切り替わったとき

- クリップを再生する・シーンを呼び出す・停止すると、出力モニターの縁が一瞬光ります（クリップ：緑、シーン：紫、停止：灰色）。
- 何に変わったか（「L3 森」「シーン 4」など）が左上に表示され、しばらくすると消えます。
- 同時に複数が変わった場合は「3 つのクリップを出した」のように 1 つにまとめて表示します。
- シーンの中で再生されるクリップや停止されるレイヤーは数に含めません。
- 自動操縦による変更には飛行機の印が付きます。

どちらの表示も設定の「画面」でオフにできます。→ [設定](settings.md)
