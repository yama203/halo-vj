# 画面の見方

Halo VJ の画面の大きな区分と、グリッド・レイヤー・数値欄などの見え方の決まりを説明する。

## グリッドとレイヤー

- グリッドの 1 段が 1 レイヤー。最初は 4 段 × 8 列。レイヤーは 16 段、列は 64 列まで増やせる。入りきらなければスクロールする。
- 段ごとに 1 クリップずつ同時に再生でき、上の段ほど手前に重なる。
- 同じ段の別のクリップを再生すると、その段のクリップだけが切り替わる。
- レイヤーや列を途中に足したり消したりしても、再生中のクリップは止まらない（消した段・列のクリップだけ止まって外れる）。

## 主な場所

| 場所 | 中身 |
|---|---|
| 左端のレイヤー欄 | 不透明度、停止、重ね方・再生中のクリップ名の表示。クリックで下のレイヤータブの対象になる。→ [レイヤー](layers.md) |
| グリッド | クリップを並べる枠。上に「デッキ」のタブと列番号。→ [デッキ・グリッドの表示](decks.md) |
| 出力モニター | 出力される絵。 |
| 下のパラメーターパネル | コンポジション・レイヤー・クリップの値。→ [パラメーターパネル](parameters.md) |
| 右下のタブ | 「ライブ」「シーン」「キュー」「エフェクト」「ジェネレーター」「ソース」。 |
| 「FX パッド」パネル | 押している間だけ効くエフェクト。→ [FX パッド](fx-pads.md) |
| 上のバー | ワークスペース、「音の入力」、「連携」、「オート」、「録画」、「出力」、「解像度・fps」、「音声」、「パネル」など。 |

上のバーの左端のアイコンを押すと「Halo VJ について」（版の番号）が出る。

## グリッドのサムネイルの見え方

- 出力と同じ黒地に描く。
- 透明のある素材は右下に市松の印。
- 暗い透明の素材（黒いロゴなど）は灰色の地にして見えるようにする。
- 大きな透明の中に小さく描かれた素材は、描かれた範囲に寄せて大きく見せる（虫めがねの印）。
- サムネイルの上にマウスを乗せている間は、市松模様の上に全体を出して透明の範囲を見せる。

## クリップの枠にマウスを乗せたとき

- 上の絵の所：▶ が出る。押すと出力に出す。再生中のクリップは ↺（頭から出し直す）。
- 下の名前の帯：帯が明るい灰色になり、上に線が出る。押すと選ぶだけ（出力しない）。
- 選択中の帯は青のまま少し明るくなる。

## 数値欄の色

- 初期値から変えた値は橙。
- プラスにもマイナスにもなる値（位置・角度・速さ・傾きなど）は、プラスが橙・マイナスが水色。欄の下に 0 の所から今の値まで細い線が出る（どちら向きにどれだけか）。

## 切り替わったことを知らせる表示

### パラメーターのパネルが切り替わったとき

クリップ・レイヤーを選ぶなどで中身が切り替わると、パネルの縁が一瞬光る（コンポジション：オレンジ・レイヤー：青・クリップ：緑）。何に切り替わったか（「クリップ ○○」など）が右上に出て、1 秒ですっと消える。

### 出力が切り替わったとき

- クリップを出す・シーンを呼ぶ・止めると、出力モニターの縁が一瞬光る（クリップ：緑・シーン：紫・止めた：灰色）。
- 何に変わったか（「L3 森」「シーン 4」など）が左上に出て、すっと消える。
- 同じ瞬間にいくつも変わったら「3 つのクリップを出した」のように 1 つにまとめる。
- シーンの中で出すクリップ・止めるレイヤーは数えない。
- 自動操縦が変えたときは飛行機の印。

どちらも設定の「画面」で切れる。→ [設定](settings.md)
