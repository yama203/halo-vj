# 値の動かし方

このページでは、数値欄の右の波形ボタンを使って、値を自動で動かす方法（アニメーション）を説明します。動かし方は、固定・秒・BPM・音・OSC/MIDI から選べます。

## 動かし方の種類

| 動かし方 | 内容 |
|---|---|
| 固定 | 動かさない |
| 秒 | 1 周の秒数を指定 |
| BPM | 1 周の拍数を指定 |
| 音 | 「音の入力」の音で動かす |
| OSC・MIDI | OSC のアドレスや MIDI のつまみで動かす |

## 動き方と範囲

- 動き方は、順・逆・往復・ランダムから選べます。
- 範囲（「から」・「まで」）を指定します。
- 動かしている間、数値欄には現在の値が表示され続けます。

## 動かせる値

- 位置・スケール・角度・不透明度（クリップ・レイヤー・コンポジション）とマスター不透明度
- エフェクト・ジェネレーターの値
- 重ね方（ブレンドモード）の値

## 音で動かす

動かし方を「音」にすると、選んだ項目 × 感度に応じて「から」〜「まで」の間で値が動きます（逆にすると、音が大きいほど「から」に近づきます）。

選べる項目は、音量・低音・中音・高音・アタックです。音の入力の設定方法は [音の入力・BPM](audio-input.md) を参照してください。

## OSC で動かす

動かし方を「OSC」にしてアドレスを入力するか、「覚える」を押してフェーダーを動かして割り当てる（ラーン）と、受け取った値（0〜1）に応じて「から」〜「まで」の間で動きます。

- 逆向きにもできます。
- 値をまだ受け取っていない間は、元の値のままです。

→ [OSC](osc.md)

## MIDI のつまみ・フェーダーで動かす

動かし方を「OSC・MIDI」にして「覚える」を押し、つまみを回すと、その値で動くようになります（アドレスは /midi/チャンネル/cc/番号 です）。

→ [MIDI コントローラー・キー](midi.md)

## 保存

動かし方はプロジェクトに保存されます。音の入力・OSC・MIDI の設定自体は Mac ごとに保存され、プロジェクトには含まれません。
