# 値の動かし方

数値欄の右の波形ボタンで、値を自動で動かす方法を説明する。固定・秒・BPM・音・OSC/MIDI から選べる。

## 動かし方の種類

| 動かし方 | 内容 |
|---|---|
| 固定 | 動かさない |
| 秒 | 1 周の秒数 |
| BPM | 1 周の拍数 |
| 音 | 「音の入力」の音で動かす |
| OSC・MIDI | OSC のアドレスや MIDI のつまみで動かす |

## 動き方と範囲

- 動き方は 順・逆・往復・ランダム。
- 範囲（「から」・「まで」）を決める。
- 動かしている間、欄は今の値を表示し続ける。

## 付けられる値

- 位置・スケール・角度・不透明度（クリップ・レイヤー・コンポジション）とマスター不透明度。
- エフェクト・ジェネレーターの値。
- 重ね方の値。

## 音で動かす

動かし方を「音」にすると、選んだ部分 × 感度で「から」〜「まで」の間を動く（逆：大きいほど「から」へ）。

選べる部分は、音量・低音・中音・高音・アタック。音の入力の決め方は [音の入力・BPM](audio-input.md) を見る。

## OSC で動かす

動かし方を「OSC」にしてアドレスを入れるか、「覚える」を押してフェーダーを動かすと、その値（0〜1）で「から」〜「まで」を動く。

- 逆もできる。
- まだ届いていなければ元の値のまま。

→ [OSC](osc.md)

## MIDI のつまみ・フェーダーで動かす

動かし方を「OSC・MIDI」にして「覚える」を押し、つまみを回すと、その値で動く（アドレスは /midi/チャンネル/cc/番号）。

→ [MIDI コントローラー・キー](midi.md)

## 保存

動かし方はプロジェクトに入る。音の入力・OSC・MIDI の設定そのものは Mac ごとで、プロジェクトには入らない。
