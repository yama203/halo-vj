# レイヤー

左端のレイヤー欄の操作と、レイヤーの足し方・並べ替え・名前・音量、クリップの切り替え方を説明する。

## レイヤー欄

左端のレイヤー欄には、不透明度、停止、重ね方・再生中のクリップ名が出る。クリックすると、下のパラメーターパネルのレイヤータブの対象になる。

| 操作 | 内容 |
|---|---|
| ◐ の印のバーを左右にドラッグ | 不透明度（ダブルクリックで 100%） |
| 「S」 | ソロ。ソロのレイヤーだけが出る（映像と音。いくつでも）。ほかは薄く表示。確認用で保存しない |
| 下の段の「通常」などのボタン | 押すと重ね方をその場で選べる（通常以外は紫）。→ [重ね方](blend-modes.md) |
| 目のボタン | ミュート。→ [再生・停止・ブラックアウト](clips-play.md) |
| 右の縦のバー | そのレイヤーの音量（上下ドラッグ、`⇧` で微調整、ダブルクリックで 100%）。上のスピーカーで音だけミュート |

## 名前を付ける

レイヤー欄の「L1」をダブルクリックすると、レイヤーに名前を付けられる（右クリック「名前を変える…」でも）。

- 番号 L1 などはそのまま目印に使う。
- 名前はレイヤー欄の下の段と、パラメーターパネルのタブに出る（名前が無ければ下の段は再生中のクリップ名）。
- レイヤーを動かしても名前は付いていく。
- シーンには入らない。プロジェクトに保存される。

## 順番を変える

レイヤー欄を上下にドラッグすると、レイヤーの順番が変わる（右クリックの「上へ移動」「下へ移動」でも）。

- クリップ・再生中のもの・設定ごと動く。
- シーンの中身も一緒に並べ替わる（レイヤーを足す・消すときも）。

## レイヤー・列を足す・消す

- 「レイヤーを追加」で一番下にレイヤー、列番号の右の「＋」で右端に列を足す。
- レイヤー欄・列番号を右クリックすると、上下（左右）に足す・削除ができる（クリップが入っていれば確認）。
- 途中に足したり消したりしても、再生中のクリップは止まらない（消した段・列のクリップだけ止まって外れる）。

## 切り替え方

レイヤータブの「切り替え方」で、そのレイヤーでクリップを切り替えるときの現れ方を選ぶ。

- クロス：だんだん重ねる（今まで）
- ワイプ：左から右へ
- 円：真ん中から
- ノイズ：ところどころから溶ける
- 明るさ：新しいクリップの明るい所から
- グリッチ：ブロックがばらばらに入れ替わり、途中は行が横にずれる

「切り替えフェード」の時間をかけて切り替わる（0 ならカット）。クロス以外は、前のクリップをそのまま下に残し、新しいクリップを形で出していく（重ね方が「通常」のとき。ほかの重ね方ではクロス）。プロジェクトに保存される。
