# レイヤー

このページでは、左端のレイヤー欄の操作と、レイヤーの追加・並べ替え・名前・音量、クリップの切り替え方（トランジション）を説明します。

![レイヤー欄](shots/ja/layers.jpg)

## レイヤー欄

左端のレイヤー欄には、不透明度、停止、重ね方（ブレンドモード）と再生中のクリップ名が表示されます。クリックすると、下のパラメーターパネルのレイヤータブの対象になります。

| 操作 | 内容 |
|---|---|
| ◐ の印のバーを左右にドラッグ | 不透明度を調整します（ダブルクリックで 100%） |
| 「S」 | ソロにします。ソロのレイヤーだけが出力されます（映像と音。複数のレイヤーをソロにできます）。ほかのレイヤーは薄く表示されます。確認用の機能で、保存はされません |
| 下の段の「通常」などのボタン | 押すと重ね方をその場で選べます（通常以外は紫で表示）。→ [重ね方](blend-modes.md) |
| 目のボタン | ミュートします。→ [再生・停止・ブラックアウト](clips-play.md) |
| 右の縦のバー | そのレイヤーの音量を調整します（上下にドラッグ、`⇧` で微調整、ダブルクリックで 100%）。上のスピーカーで音だけをミュートできます |

## 名前を付ける

レイヤー欄の「L1」をダブルクリックすると、レイヤーに名前を付けられます（右クリックの「名前を変える…」でも付けられます）。

- L1 などの番号はそのまま目印として残ります。
- 名前はレイヤー欄の下の段と、パラメーターパネルのタブに表示されます（名前が無い場合、下の段には再生中のクリップ名が表示されます）。
- レイヤーを移動しても名前は引き継がれます。
- 名前はシーンには含まれず、プロジェクトに保存されます。

## 順番を変える

レイヤー欄を上下にドラッグすると、レイヤーの順番が変わります（右クリックの「上へ移動」「下へ移動」でも変えられます）。

- クリップ・再生中の状態・設定はレイヤーと一緒に移動します。
- シーンの内容も一緒に並べ替えられます（レイヤーを追加・削除したときも同様です）。

## レイヤー・列を追加・削除する

- 「レイヤーを追加」で一番下にレイヤーを、列番号の右の「＋」で右端に列を追加します。
- レイヤー欄や列番号を右クリックすると、上下（左右）への追加と削除ができます（クリップが入っている場合は確認が表示されます）。
- 途中に追加・削除しても、再生中のクリップは停止しません（削除した行・列のクリップだけが停止して外れます）。

## 切り替え方

レイヤータブの「切り替え方」で、そのレイヤーでクリップを切り替えるときの現れ方を選びます。

- クロス：徐々に重ねて切り替える（従来の動作）
- ワイプ：左から右へ切り替える
- 円：中央から広がる
- ノイズ：ところどころから溶けるように切り替える
- 明るさ：新しいクリップの明るい部分から現れる
- グリッチ：ブロックがばらばらに入れ替わり、途中で行が横にずれる

「切り替えフェード」で指定した時間をかけて切り替わります（0 ならカット）。クロス以外では、前のクリップをそのまま下に残し、新しいクリップを各形状で現していきます（重ね方が「通常」のときの動作で、ほかの重ね方ではクロスになります）。設定はプロジェクトに保存されます。
